# Chinese subtitle generation

Generated by:

```powershell
py -3.12 tools\generate_cn_subtitle.py
```

Current text:

```text
你好，欢迎进入选歌环节
```

Files:

| File | Meaning |
|---|---|
| `glyph_index.csv` | Character, Unicode code point, and assigned `glyph_id` |
| `text_ids.bin` | Subtitle glyph IDs, each stored as 16-bit little-endian |
| `font_bitmap.bin` | Each glyph is 16 rows x 16 bits, 2 bytes per row, row 0 first |
| `font_preview.png` | Human-readable enlarged bitmap preview |
| `subtitle.txt` | Source subtitle text |

The generated synthesizable module is:

```text
src/display/vinyl_cn_subtitle_overlay.v
```

Bitmap row bit order:

```text
bit 15 = leftmost pixel
bit 0  = rightmost pixel
```

The overlay is horizontally centered and uses `SUBTITLE_Y=450` for a
640x480 frame.
