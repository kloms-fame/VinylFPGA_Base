# D3 EC2 与唯一音量源人工验收单

> 本轮未生成 bitstream，以下验收使用用户自行从 prj/VinylFPGA.al 生成的固件。建议先使用 D2 测试音卡或稳定音频曲目，固定 HDMI 接收设备与音量，逐步记录现象。当前 D3 不提供音量浮窗。

## A. 启动与基础行为

- [ ] 用已确认可启动的 SD 卡冷启动；确认画面、音频和已有 D1 轮播功能正常。
- [ ] 启动动画、媒体未挂载、DIP/输入动作尚未就绪期间快速旋转 EC2；就绪后不得出现累积的意外音量连跳。
- [ ] 在 BROWSE 中转动 EC2，图片焦点、选中项和缩略图浏览位置不应改变。EC2 只更新隐藏音量状态。
- [ ] 在缩略图界面转动 EC2，不得触发 EC1 的确认、选曲或 Seek 路径。

## B. EC2 状态与每步调节

建议先开始播放可重复的测试音，在稳定输出下听每次音量变化。

- [ ] 隐藏超过 1.8 秒后，顺时针转 EC2 一格：应立即调整音量一步，不需要先按键。
- [ ] 继续转动数格：音量逐步增大；反向转动：音量逐步减小。确认当前曲目、播放位置和 EC1 Seek 位置没有被 EC2 改动。
- [ ] 从隐藏态按下 EC2 进入 SELECT；转动一格时音量不应变化。
- [ ] 再按下进入 ADJUST；转动一格时音量应变化。
- [ ] 在 ADJUST 按下返回 SELECT；再转动一格时音量不应变化。
- [ ] 在 SELECT 停止操作约 1.8 秒；之后第一格旋转应像隐藏态一样立即调整音量。
- [ ] 在 PLAY 中快速连续同向旋转，再快速反向旋转；确认不会只按最终净位移更新且无明显丢步。16 位计数回绕需靠 RTL 定向验证，人工转动不作为此项验收方法。

## C. 音量范围与唯一来源

VOL 默认值为 200，单步为 16，范围为 0～255。

- [ ] 从默认音量向上调整 4 格：目标应饱和到 255；继续向上不得回绕到小音量。
- [ ] 从高音量向下连续调整至 0：应平滑进入现有静音目标；继续向下保持静音，不得回绕到高音量。
- [ ] 从 0 向上调整，确认每格都恢复音量；从 255 向下调整，确认每格都降低音量。
- [ ] 暂停/恢复、切曲、播放结束策略切换后，音量状态应保持；暂停时的原有静音行为仍保持。
- [ ] 媒体移除并重新挂载后，已经设定的音量应保留；恢复期间旋转 EC2 不应在重新就绪后产生幽灵调节。
- [ ] FPGA 完整复位后，音量回到默认 200。

## D. KEY / IR 与 EC2 混合操作

- [ ] 在 BROWSE 中按 KEY04/KEY05，原来的浏览导航行为保持；不得因这两个键改动音量。
- [ ] 在 PLAY 中按 KEY04/KEY05，音量按同一 16 级步进规则增减。
- [ ] 若当前遥控器已配置现有 IR 音量上/下命令，在 PLAY 中逐项验证它们也调整同一音量；BROWSE 中保留原语义。
- [ ] 在 PLAY 中同时或交错操作 EC2、KEY04/05 和 IR 音量键；所有被接受的调节最终按顺序生效，不互相覆盖或回退。
- [ ] 观察无播放、暂停、STOP、曲目切换、Seek 等场景下的 KEY/IR 接受条件，确认仍由原播放状态门控。

## E. 通过标准与记录

- [ ] 每项操作记录：固件文件名/SHA-256、SD 卡镜像、板卡与显示器、操作步骤、实际现象。
- [ ] 音量 0 静音、255 不回绕；EC2 不改变画面导航、选曲、播放位置与 Seek。
- [ ] KEY/IR 与 EC2 调节最终听到一致的音量变化；媒体恢复无幽灵事件。
- [ ] 若发现异常，记录发生时的播放状态、输入来源、方向/速度及是否刚经历启动、消隐、重启确认或媒体恢复。
