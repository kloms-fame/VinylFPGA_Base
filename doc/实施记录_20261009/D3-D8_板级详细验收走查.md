# D3–D8 板级详细验收走查（EC2 参数系统）

> 覆盖提交：
> - `257123c` D3 EC2 音量控制与统一音量源
> - `792e982` D4 亮度 / D5 对比度 / D6 EC2 浮窗
> - `011435c` D7 ROT 轮播周期调节
> - `cd879e0` D8 WSL 灯条亮度调节
> 器件 EG4S20BG256 / TD；HDMI 640×480@60；音频 48kHz/16bit 单声道。
> 用法：**从上到下顺序执行**，每条"结果"处打勾或记录；建议全程录屏 + 手机秒表。

---

## 0. 验收前准备

### 0.1 物料
| 物料 | 要求 |
|---|---|
| bit 文件 | TD 打开 `prj/VinylFPGA.al`，综合→布局布线→生成 bit；**完整布线后 WNS 必须为正、无 hold 违例**（综合快照的 −0.28ns 不算签核） |
| 卡A（主验） | 写卡脚本菜单 `6` = card_S6.img（曲目1带 MV、曲目2/3/4 无 MV、4 张封面） |
| 卡B（测试音） | 写卡脚本菜单 `7` = card_test_tone.img（曲目1=5 秒 1kHz 单音），用于精确听音量 |
| 外设 | 带音箱/音频的 HDMI 显示器（或独立功放）、EC1（左旋钮）、EC2（右旋钮）、12 键、6 位 DIP、8 颗 WS2812、蜂鸣器 |
| 工具 | 手机秒表（测 1.8s / 各周期）、纸笔、记录 bit 与卡 SHA-256 |

### 0.2 出厂默认值（上电/完整复位后必须是这些）
| 参数 | 默认 | 说明 |
|---|---|---|
| VOL | **200** | 音量，步进 16，范围 0~255 饱和 |
| BRI | **1X**（档位3） | 亮度五档 |
| CON | **1X**（档位2） | 对比度五档 |
| ROT | **3S**（档位2） | 轮播周期六档 |
| WSL | **100%**（档位4） | 灯条亮度五档 |

### 0.3 参数总表（验收时对照）
| 参数 | 档位（索引:显示） | 调整方向 |
|---|---|---|
| VOL(0) | 连续值：0,16,32,…,200,…,255 | 顺转+ / 逆转− |
| BRI(1) | 0:1/4X 1:1/2X 2:3/4X 3:1X 4:5/4X | 顺转增亮 / 逆转减暗 |
| CON(2) | 0:1/2X 1:3/4X 2:1X 3:5/4X 4:3/2X | 顺转增强 / 逆转减弱 |
| ROT(3) | 0:OFF 1:2S 2:3S 3:5S 4:10S 5:20S | 顺转周期变长 / 逆转变短 |
| WSL(4) | 0:0% 1:25% 2:50% 3:75% 4:100% | 顺转变亮 / 逆转变暗 |

## 1. EC2 状态机走查（D3/D6 核心，先练熟操作）

> 三种状态：**HIDDEN（隐藏）/ SELECT（选参数）/ ADJUST（调数值）**；停止操作 **约 1.8 秒**自动回 HIDDEN。

### 1.1 冷启动与"不重放"
| # | 操作 | 预期现象 | 结果 |
|---|---|---|---|
| 1.1.1 | 上电，Boot Logo 期间快速乱转 EC2、按 EC2 | 浮窗**不覆盖 Boot**；Boot 结束后**不会重放**这些旋钮动作（不出现音量连跳） | □ |
| 1.1.2 | 进入主界面后先不碰 EC2 | 屏幕**默认无浮窗**；轮播/画面正常 | □ |

### 1.2 HIDDEN 态旋转 = 立即调音量
| # | 操作 | 预期现象 | 结果 |
|---|---|---|---|
| 1.2.1 | 静置 ≥2 秒确认隐藏，顺转 EC2 一格 | **无需先按键**，立即出现浮窗：标题 `VOL`、右上 `ADJ`，音量数值 +16，听到响度增大 | □ |
| 1.2.2 | 继续顺转数格 | 数值与响度逐格增大；逆转逐格减小 | □ |
| 1.2.3 | 观察画面焦点/选中项/缩略图位置 | **完全不变**（EC2 不触发选曲、Seek、焦点移动） | □ |

### 1.3 按键进入 SELECT（选参数，不改值）
| # | 操作 | 预期现象 | 结果 |
|---|---|---|---|
| 1.3.1 | 隐藏态**按下 EC2 一次** | 浮窗显示标题 `VOL`、右上 `SEL` | □ |
| 1.3.2 | SELECT 下顺转一格 | 标题变 `BRI`，**数值/画面/音量都不变** | □ |
| 1.3.3 | 继续顺转 | 依次 `CON → ROT → WSL → VOL` 循环；逆转反向循环；全程只改标题、不改值 | □ |
| 1.3.4 | 停在任意参数，逆转验证回绕 | WSL→ROT→CON→BRI→VOL，顺序正确 | □ |

### 1.4 SELECT → ADJUST（调当前参数）→ 返回
| # | 操作 | 预期现象 | 结果 |
|---|---|---|---|
| 1.4.1 | SELECT 下**再按 EC2 一次** | 右上 `SEL` 变 `ADJ` | □ |
| 1.4.2 | ADJUST 下转一格 | **只改当前选中参数**（标题对应那个），其余参数不变 | □ |
| 1.4.3 | ADJUST 下**再按 EC2** | 回到 `SEL`；此时旋转只切换参数、不改值 | □ |
| 1.4.4 | 在 VOL/BRI/CON/ROT/WSL 各自 ADJ 各试一次 | 每次按键都在 SEL↔ADJ 间切换，行为一致 | □ |

### 1.5 自动隐藏计时
| # | 操作 | 预期现象 | 结果 |
|---|---|---|---|
| 1.5.1 | 任意状态停止操作，手机计时 | **约 1.8 秒**后浮窗消失、回 HIDDEN | □ |
| 1.5.2 | 1.8 秒内再操作（转或按） | 计时重新开始，浮窗保持；每次操作都重置 1.8s | □ |
| 1.5.3 | 隐藏后第一格旋转 | 像 1.2.1 一样立即调音量（HIDDEN 旋转直达 VOL/ADJ） | □ |

### 1.6 快速正反转压力
| # | 操作 | 预期现象 | 结果 |
|---|---|---|---|
| 1.6.1 | 连续快速顺转 10+ 格再猛逆转 | 按**累计步数**逐格重放，**不是只按最终净位移跳一次**；无明显丢步、不卡死 | □ |
| 1.6.2 | 快速操作后停手等 1.8s | 不会在超时后把积压动作一次性重放出来 | □ |
