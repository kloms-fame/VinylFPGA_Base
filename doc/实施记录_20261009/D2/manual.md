## 验收步骤

1. 准备一张可擦写的备用 SD 卡，确认卡内无需保留的数据；将本记录所指测试镜像写入备用卡并回读，确认镜像哈希与上表一致。不要把该测试镜像写到唯一的日常曲库卡上。
2. 首次播放前把功放/显示器音量调低。测试素材为纯 1 kHz 音，约 -12 dBFS，不是音乐。
3. 插入测试卡，确认曲目数为 4，选界面曲目 1（索引 entry 0）。播放时应听到稳定、无明显爆音/断续的单音；视频/封面应正常显示。
4. 暂停：音频应静音且 UI 状态切换正确；恢复：音调应继续播放，HDMI 音频锁定不丢失。切换几个音量档，响度应随档位变化且无异常噪声。
5. 这段音频时长约 5 秒。播放到文件末尾，检查 EOF 后播放器状态正常，没有卡死、持续读错或异常重启。
6. 关闭设备后取出测试卡，换回原始曲库卡；确认真实曲目可播放、暂停/恢复正常，画面和 HDMI 音频同时正常。
