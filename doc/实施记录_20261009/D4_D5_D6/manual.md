# D4 亮度、D5 对比度、D6 参数浮窗人工验收

## 验收前准备

1. 在安路 TD 中打开主工程 `prj/VinylFPGA.al`，综合并生成 bit 文件，再按现有烧录流程写入开发板。
2. 使用正常 HDMI 显示器、编码器和已有播放介质。建议准备一张亮暗区域明显的封面图，以及持续播放的音频。
3. 记录 TD 版本、板卡编号、显示器型号、bit 文件 SHA-256、播放介质和实际现象。bit 文件由用户本地生成，本记录不包含 bitgen 结果。
4. 参数出厂值：VOL=200；BRI=1X（级别3）；CON=1X（级别2）。浮窗默认隐藏。

## 1. 启动、Boot 与画面优先级

1. 冷启动板卡，确认 Boot 启动画面及其原有节奏、文字和颜色没有变化。
2. Boot 期间旋转或按下 EC2。浮窗不得覆盖 Boot，也不应在 Boot 完成后重放启动期间的旋钮动作。
3. 进入正常图片播放后，确认默认没有浮窗；等待自动轮播时，图片仍按既有节奏正常切换。
4. 触发已有消隐功能，确认屏幕全黑；此时打开 EC2 浮窗或改变图像参数，消隐期间仍应保持纯黑。解除消隐后再显示正常画面。
5. 进入诊断彩条模式，确认彩条不出现 EC2 浮窗，诊断图案也不被亮度/对比度修改。

## 2. EC2 操作状态与浮窗

EC2 状态流程为：隐藏态旋转直接调节 VOL 并显示 ADJ；隐藏态按下进入 SEL；SEL 旋转在 VOL、BRI、CON 间循环选择但不改值；SEL 按下进入 ADJ；ADJ 旋转调当前参数；ADJ 按下返回 SEL。停止交互约 1.8 秒后浮窗隐藏。

1. 隐藏时轻转旋钮，确认浮窗显示 `VOL` 与 `ADJ`，音量值随旋转变化。
2. 隐藏时按下旋钮，确认出现 `VOL` 与 `SEL`。旋转一格应选择下一个参数，依次可到 BRI、CON；反向旋转也应循环，且 SEL 状态下数值不改变。
3. 在 SEL 状态按下，确认状态变为 `ADJ`；旋转后只修改当前选中的参数。再按一次回到 `SEL`。
4. 在 VOL/BRI/CON 各自的 ADJ 状态检查标题、档位和进度条都与当前实际值一致。改变参数后画面变化在下一帧边界整体生效，画面中不应出现半帧新旧参数混用。
5. 每次操作都会重新开始隐藏计时。停止操作后约 1.8 秒浮窗隐藏；重新操作时应再次显示。
6. 连续快速正转、反转并交替操作，检查编码器事件没有卡住或累积到超时后重放。VOL 到上下限、BRI/CON 到各自档位上下限后继续旋转，值应饱和且不回绕。
7. 在播放期间通过已有 KEY/IR 音量加减途径改变音量，确认浮窗切到 VOL/SEL 并显示更新后的音量；之后用 EC2 改音量，确认音频实际响度也使用同一个 VOL 值。

## 3. D4 亮度验收

BRI 档位为 1/4X、1/2X、3/4X、1X、5/4X，默认 1X。每档按上一帧采纳的新参数从下一帧开始生效。

1. 在固定封面或静态图片上依次选中 BRI 并调过五档。观察暗部和中间调随档位降低而变暗、升高而变亮；1X 应接近原画面。
2. 检查最高档的高亮区域：结果不能绕回暗色，应在 255 处饱和。最低档检查接近黑色区域没有负数回绕。
3. 观察彩色图像中 RGB 三个通道均有变化，边缘和几何位置不移动；切换 BRI 不应改变同步、图像大小或图片选择。
4. 在全屏图片和缩略图模式各检查一次，确认两种媒体显示都经过同一组帧锁存参数。

## 4. D5 对比度验收

CON 档位为 1/2X、3/4X、1X、5/4X、3/2X，默认 1X。计算以每个颜色通道的 128 为中心，档位变动不应造成正负翻转。

1. 在包含暗部、中灰和高亮的图片上依次检查五档。低对比度时暗部靠近中灰、高亮也靠近中灰；高对比度时暗部更暗、高亮更亮；1X 接近原画面。
2. 确认中灰附近基本保持中灰，画面没有整体反相或颜色通道互换。
3. 高对比度时检查最暗和最亮像素分别饱和到 0 和 255，不出现回绕条纹。
4. 连续切换 CON 档位时，参数在整帧边界更新，没有画面撕裂或行间亮度跳变。

## 5. D6 浮窗外观与像素位置

浮窗区域是 640x480 视频坐标中的 x=360..623、y=16..111，深色不透明底、单像素边框。参数标题位于左上，SEL/ADJ 状态位于右侧；VOL 显示三位十进制数，BRI/CON 显示比例文字，底部进度条显示当前值/档位。

1. 在 SEL 与 ADJ 两种状态分别检查标题和状态字可读、完整；逐档检查比例文字和进度条同步。
2. 检查 0、最小、中间、最大值下进度条边界，确认空条和满条位置合理，浮窗尺寸没有越界。
3. 观察屏幕边缘、首行和末行，确认浮窗位置固定、不抖动、不横向/纵向偏移一像素，文字没有被截断。
4. 播放视频和歌词时打开浮窗，确认浮窗位于媒体/歌词之上；Boot 仍盖在浮窗之上，消隐仍强制纯黑。
5. 打开浮窗时持续播放音频并操作旋钮，确认 HDMI 音频无爆音、中断或节拍变化，板载蜂鸣提示仍正常。
