# O3 与 O4 实施计划

> **For agentic workers:** 按阶段逐项执行；O3、O4 分别形成独立提交与验证证据。

**Goal:** 保持蜂鸣器听感逐周期不变并测量减负候选；移除动态黑胶几何、复用当前图片流并保留 MV；以物理报告判断读地址路径是否需要减负。

**Architecture:** O3 测量后保留 `24b680f` 蜂鸣器原实现，因为候选未带来可接受的资源及时序收益。O4a 旁路 S6 黑胶 renderer 并清除专属状态，沿用当前图片/封面像素流、MV 调度和窗口。O4b 只有在 O4a final 的关键读请求路径仍处于 top setup 路径且相对父版 slack 变差时，才单独实施；本轮报告不满足条件。

**Tech Stack:** Verilog-2005、Icarus Verilog、Anlogic TD 6.2.168116、EG4S20BG256、seed 5 / `area_prior`。
