# D8 WSL 与 D7 ROT 人工验收单

本轮没有生成 bitstream。使用用户自行从 `prj/VinylFPGA.al` 生成的固件。建议记录 TD 版本、固件 SHA-256、板卡、LED 灯条型号/方向、SD 介质和显示器型号；逐项记录结果，异常时保留视频。

## A. 启动与参数菜单

- [ ] 冷启动后确认 Boot、HDMI 画面、静音/播放音频、EC2、DIP 与原有灯效正常。
- [ ] 进入 EC2 SELECT，确认参数顺序为 VOL、BRI、CON、ROT、WSL；每次按下在 SELECT/ADJUST 状态间切换的行为与 D4–D6 一致。
- [ ] 进入 WSL，确认默认显示 100% 档；依次调到 75%、50%、25%、0%、100%，浮窗的百分比、档位条与实测档位一致。
- [ ] 进入 ROT，确认默认 `3S`，六档 OFF/2S/3S/5S/10S/20S 均可选；DIP2 开启时按周期轮播，OFF 时停止自动切图。

## B. WSL 灯条亮度与帧边界

- [ ] DIP6 打开，KEY10 处于 VU 模式，使用静音、低音量和较高音量输入，分别观察五个 WSL 档位。亮度应单调递增；100% 应与原默认颜色亮度相同，0% 应全黑。
- [ ] 反复在音乐变化期间调整 WSL。每个 WS2812 帧内亮度应保持一致，只能在后续帧切换档位；不得出现半帧亮度撕裂、异常闪色或灯珠数量变化。
- [ ] 在 KEY10 全灭模式验证各档均保持全灭；再切回 VU 模式，WSL 值应保留。
- [ ] 在 VU 模式下把 WSL 设为非零，关闭 DIP6；确认完整黑帧后灯条保持全黑，期间调整 WSL 也不能重新点亮灯条。重新打开 DIP6 后，灯条按当前模式和新档位恢复。
- [ ] 观察灯条数据时序稳定，无随机颜色、锁存错误或持续刷新引起的闪烁；连续运行至少 5 分钟。

## C. ROT 轮播与仲裁

- [ ] 使用至少两张可切换图片的介质，浏览全屏模式下打开 DIP2。分别测量 2S、3S、5S、10S、20S 至少三个切换周期；OFF 等待 20 秒不应自动切图。
- [ ] 修改 ROT 档位后，新周期应从头计时，不应立即兑现旧周期。DIP2 关闭再打开后也应从完整新周期开始。
- [ ] 在自动切图前后快速手动切换，确认手动操作方向正确、优先于自动请求且不会同拍重复跳图。
- [ ] 在导航 busy 时让自动周期到期，确认只保留一个 pending 请求；导航结束后只执行一次。手动操作打断后旧 pending 应被取消。
- [ ] 在单图、缩略图、播放和媒体未就绪状态确认自动切图门控不变；每次成功自动切图仍只响一声提示音。

## D. 系统回归

- [ ] 验证 VOL/BRI/CON/ROT/WSL 浮窗显示当前实际参数和档位；旋钮操作对正在播放的音频、画面、KEY/IR 操作没有串扰。
- [ ] 检查 Boot、显示消隐/恢复、HDMI、音频链、KEY10、DIP2、DIP6 和 SD 卡访问均保持正常。
- [ ] 灯条关闭与恢复期间，确认音频播放和自动切图不受影响；LED 操作不会改变蜂鸣器/音频链优先级。
