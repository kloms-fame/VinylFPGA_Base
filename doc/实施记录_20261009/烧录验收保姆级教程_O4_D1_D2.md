# VinylFPGA 烧录验收保姆级教程（O4 + D1 + D2）

> 适用提交：`df3f6fa`（O4 简化黑胶显示）+ `b9a04a1`（D1 定时轮播）+ `d9d4648`（D2 测试音）
> 器件：安路 EG4S20BG256；工具：TD 6.2；显示：HDMI 640×480@60；音频：48kHz/16bit 单声道
> 一句话总流程：**做两张 SD 卡 → TD 综合出 bit → JTAG 烧录 → 按 10 个阶段逐项看现象**。

---

## 总览（先有个全局印象）

```
[PC] 写卡脚本 write_card.bat
        ├── 卡A 选 6 = card_S6.img      （日常主验：有MV、4张封面）
        └── 卡B 选 7 = card_test_tone.img（D2 测试音：曲目1=5秒1kHz）
[PC] TD 打开 prj/VinylFPGA.al → Run 综合/布线/出 bit（确认无黑盒）
[板] USB-JTAG 下载 bit（SRAM，掉电丢失，验收用）
[板] 阶段1~10 逐项验收 → 全过后再 Flash 固化
```

# 第一部分：SD 卡制作（用你熟悉的脚本）

## 1.1 准备物料

| 物料 | 说明 |
|---|---|
| TF 卡 ×2 | 一张"日常主验卡"，一张"测试音卡"。**务必两张**，因为 D2 测试镜像会把曲目1换成测试音，别覆盖唯一曲库卡 |
| USB 读卡器 | 插电脑 USB；镜像只有 27.7MB（S6 卡 74.5MB），任意 ≥128MB 旧卡都能用 |
| 脚本目录 | `D:\Data_Backup\VinylFPGA_Workspace_Base\VinylFPGA\doc\资源\sd卡\` |

> 写卡是**整盘镜像裸写**（不是把文件拖进卡里），会清掉卡上原有内容，提前确认卡里没有要留的东西。

## 1.2 关键前提：读卡器盘符必须是 `E:`

脚本里写死了设备路径 `\\.\E:`，所以**插卡后必须让它变成 E 盘**，否则会写错盘或报错。

1. 插入读卡器，打开"此电脑"，看新盘符是什么。
2. 如果不是 E：右键开始菜单 → **磁盘管理** → 找到读卡器那个分区 → 右键 **更改驱动器号和路径 → 更改 → 指派为 E:** → 确定。
3. 关掉所有打开 E 盘的资源管理器窗口（占用会导致锁盘失败）。

## 1.3 菜单与镜像对照（脚本已更新为 1–7）

双击 `write_card.bat`（自动弹 UAC，点"是"），出现菜单：

| 选项 | 镜像 | 内容 | 本次用途 |
|---|---|---|---|
| 1 | card_A.img | 好索引 + PIC1~4，仅曲目1有音频 | 一般功能 |
| 2 | card_A_broken.img | 坏索引 + PIC1~4 | 坏索引回退 |
| 3 | card_SONG.img | 好索引 + SONG1~4，无 PIC | 索引供图 |
| 4 | card_B_broken.img | 坏索引 + SONG1~4，无 PIC | 双坏报错 |
| 5 | card_S5.img | 4 首共用同一 AUDIO.PCM | 多曲播放 |
| **6** | **card_S6.img** | **曲目1带 MV；曲目2/3/4 无 MV；4 张封面** | **日常主验卡（推荐）** |
| **7** | **card_test_tone.img** | **曲目1=5秒 1kHz 测试音，其余封面保留** | **D2 测试音卡** |

## 1.4 本次推荐写卡方案

- **卡A（主验）**：菜单输入 `6` 回车。它同时满足：
  - KEY08 验 MV：曲目1有 MV；
  - 无 MV 回退：曲目2/3/4 没有 MV；
  - D1 轮播：有 4 张封面（≥2 张）。
- **卡B（测试音）**：菜单输入 `7` 回车，写 D2 测试镜像。

## 1.5 写卡操作步骤（每张卡一样）

1. 双击 `write_card.bat` → UAC 点"是"。
2. 看菜单，输入数字（`6` 或 `7`）回车。
3. 窗口先打印 `Writing ... (27.7 MB)`，随后出现 `LOCK_OK`（锁盘成功）。
4. 进度条按 4MB 一块刷新：`... (xx%) xxMB xx MB/s`。
5. 完成出现 `WRITE_OK xxx bytes in x.x s` → `UNLOCK_OK`。
6. 最后绿字 `=== DONE, safe to eject ===`，并列出 E 盘内容（容量应显示约 27MB，而不是卡的原始容量）。
7. **安全弹出 E 盘**（任务栏右下角"安全删除硬件"），再拔卡，插到板子 TF 卡座。

## 1.6 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 没有 `LOCK_OK`，WriteFile 直接报错 | E 盘被资源管理器/杀毒软件占用；关掉所有 E 盘窗口，重跑 bat |
| 提示 `image not found`（选7时） | 测试镜像相对路径失效；确认 `prj\resource_opt_verified_20261005\d2_testtone_20261010\card_test_tone.img` 存在 |
| 写完 E 盘仍显示原始容量（如 31GB） | 没刷下去；安全弹出再插回，应显示约 27MB |
| 提示 `Not Administrator` | 没走 bat；务必双击 `write_card.bat` 让它自动提权 |
| 找不到 E 盘 | 读卡器没插好，或按 1.2 重新指派盘符为 E |

# 第二部分：TD 综合并生成 bit

## 2.1 打开工程

1. 启动 TD（Tang Dynasty）。
2. File → Open Project，选择 `D:\Data_Backup\VinylFPGA_Workspace_Base\VinylFPGA\prj\VinylFPGA.al`。
3. 在 Sources 里确认**顶层模块为 `top`**（文件 `src/top_tf_hdmi_audio.v`），器件为 **EG4S20BG256**。

## 2.2 全流程编译

- 方法一（省事）：工具栏点 **Run（或 F9）**，自动跑 综合 → 映射 → 布局布线 → 生成 bit。
- 方法二（分步，便于定位）：在 Flow/Processes 面板依次双击
  **Run Synthesis → Run Place & Route → Generate Bitstream**。
- 建议先在 Synthesis 上右键 Clean，再重新跑，避免旧结果残留。

## 2.3 关键检查：不能有黑盒错误

在 Transcript / Console 里确认：

- **没有 `vinyl_renderer` 的 black box / unresolved module / missing module 报错**；
- **没有 `cdc_bundle_latest` 的黑盒报错**；
- 没有 ERROR。已知并登记的告警（PLL 本地反馈、CDC、I/O 未完整约束）可以放行。

> 原理：O4 已从顶层删掉 vinyl_renderer 的 `` `include `` 和例化，`.al` 也没列它；`src/display/vinyl_renderer.v` 留在磁盘只作参考，不参与编译，所以不应再报黑盒。

## 2.4 记录 bit 与资源

1. bit 生成后，从 bitgen 日志或输出目录找到 `.bit` 文件，记录完整路径。
2. PowerShell 计算 SHA-256（把路径换成实际路径）：
   ```powershell
   Get-FileHash 'D:\...\VinylFPGA.bit' -Algorithm SHA256
   ```
3. final 资源对照（O4 基线）：slices ≈ **7510**、RAM9K = **42**、DSP ≈ **13**（比父版 7541/42/15：slices −31、DSP −2）。
4. 时序：完整布局布线后确认 **WNS（最差建立裕量）为正、无 hold 违例**。

> 注意：D1 报告里"综合快照"曾出现 SWNS −0.316ns，最差路径在**既有 FAT32 音量扫描器**，不在轮播控制器。综合通过 ≠ 时序签核；务必以主工程完整 place/route 后的 WNS 为准，若为负先不要烧录验收，把时序报告发回分析。

# 第三部分：烧录（下载）到板子

## 3.1 接线

| 连接 | 说明 |
|---|---|
| 板载 USB-JTAG（USB 口） | 用 USB 线连电脑，供下载用（HX4S20 板载下载，无需外置下载器） |
| HDMI | HDMI 线连显示器/带音箱的显示器 |
| TF 卡 | 插入写好的卡A（菜单6） |
| 电源 | 接好供电 |
| DIP 初始 | 建议先全部拨到 ON（上拨），确认 DIP1 在场使能已开 |

## 3.2 JTAG/SRAM 下载（本次验收推荐，掉电丢失、迭代快）

1. TD 菜单 **Tools → Download**（或工具栏下载图标）。
2. 下载器连接：点连接/自动连接（对应命令 `connect_cable -open -auto_start`），应能识别到器件。
3. 可先 **Auto Detect / Read ID**，确认返回目标含 **EG4S20BG256**。
4. 模式选 **JTAG / SRAM**，选择刚生成的 `VinylFPGA.bit`。
5. 点 **Start / Run / Download**，进度走完提示成功（对应命令 `download -mode jtag -bit {...bit}`）。
6. 成功后 FPGA 立即开始运行：显示器应进入开机 Logo。

> 命令行等价（GUI 连不上时可用 Tcl Console）：
> ```
> import_device eagle_s20.db -package EG4S20BG256
> connect_cable -open -auto_start
> read_device_id -level 1
> download -mode jtag -bit {D:/.../VinylFPGA.bit}
> ```

## 3.3 Flash 固化（**验收全部通过后再做**，掉电自启动）

1. 同样 Tools → Download，模式改为 **External / SPI Flash**。
2. 选择板载 Flash 型号（常见 W25Q64，以板卡丝印/原理图为准）。
3. 勾选 Program 与 Verify，选 `.bit`，Start 烧写，提示 Success。
4. 断电、拔掉下载线、重新上电：FPGA 自动从 Flash 加载并显示画面，即固化成功。

## 3.4 烧录成功标志

显示器出现带呼吸效果的开机 Logo（不是黑屏、不是花屏），即说明 bit 已正确运行。
