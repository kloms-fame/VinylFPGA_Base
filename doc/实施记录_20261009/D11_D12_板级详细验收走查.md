# D11 / D12 五行歌词与平滑滚动验收走查

## 实现内容

- D11 以一个同步歌词 ROM 读口扫描当前时间，并维护 `[当前行-2 … 当前行+3]` 六槽窗口。五行显示和下一行入场共用该窗口，没有新增五套扫描器或字库。
- 右侧信息面板显示 16×16 字形，行距 48px，完整宽度 256px，可显示每行最多 16 字。静止时当前行为白色，邻行为浅灰，其余行深灰；面板边缘裁切滑出区域。
- D12 仅在同曲、同代次的相邻歌词行间启动滚动。位移按帧推进，等效位置为 0、3、6、…、45、48px；新当前行在动画开始时成为白色高亮，结束时六槽窗口前移一行。
- 暂停保持滚动位置；Seek、重播、切曲和多行跳跃会取消当前动画并定位到最新歌词，不排队播放旧动画。
- 歌词字形由播放页既有同步字库读口统一仲裁；播放页、波形、EC2 浮窗、Boot 和消隐的图层顺序未调整。

- SynthPilot 使用当前 `prj/VinylFPGA.al`、`constraints/timing.sdc` 完成 `read_design → opt_rtl → opt_gate`，结果为 **BUILD SUCCEEDED through opt_gate**。未运行布局布线或 bitgen。
- 门级摘要：Setup WNS `+0.148ns`、TNS `0`、违例端点 `0`；Hold WNS `+0.471ns`、TNS `0`、违例端点 `0`。当前最差 setup 路径位于 SD 卡卷扫描逻辑（`audio_active_reg` 到 `fs_error_reg[0]`）。
- 资源报告：LUT 器件利用量 `15,921 / 19,600 (81.23%)`，寄存器 `10,035 / 19,600`，BRAM9K `42 / 64 (65.62%)`，DSP `10 / 29`。QoR 报告的 LUT 单元计数为 `10,371`，与器件利用量是不同统计口径。
- 当前 LUT 利用量比方案中的 `15,500` 预算基准高 `421`，但低于 90% 停止线。由于空歌词表使 D11/D12 有效数据路径被裁剪，非空素材接入后的真实增量尚未测出，需重新做资源评估。

- 因正式歌词表目前为 0 行，综合会裁掉歌词窗口和滚动的有效数据路径。本次结果证明工程可读入并通过当前素材配置的综合，不代表非空歌词配置的资源或板级行为已验收。接入真实素材后需重新综合并生成 bit。

## 板级验收准备

1. 在 `doc/资源/lyrics/songs_manifest.json` 中填入四首真实曲目的标题、歌手与 LRC 相对路径；每首最多 128 行，每行最多 16 个字形。
2. 生成中文字库和行 ROM：

   ```powershell
   python tools/gen_lrc_assets.py --songs-manifest doc/资源/lyrics/songs_manifest.json
   ```

3. 在 TD 对当前 `prj/VinylFPGA.al` 重新综合、布局布线并生成 bit；记录 bit 的 SHA-256、板卡和显示器。完整布线需检查 setup/hold，再下载验收。

## 人工验收步骤

| 序号 | 操作 | 预期结果 |
|---|---|---|
| 1 | 正常播放一首有歌词的曲目 | 右侧面板显示五个独立时间行；当前行居中白色、上一行和下一行浅灰、更远行深灰；每行最多 16 字完整显示。 |
| 2 | 从第一句开始播放 | 上方两个越界槽为空；第一句在面板中心，不出现负索引文字或上一首残留。 |
| 3 | 播放到中间的正常相邻换行 | 新当前行从中心下方入场；位置每帧上移 3px，16 个帧间隔后落在中心；旧当前行变为浅灰邻行。 |
| 4 | 在滚动中暂停并保持至少 2 秒 | 行位置和颜色保持不变；恢复后从原位置继续，不重启或跳帧。 |
| 5 | 在滚动中分别 Seek 前进、后退并重播 | 旧动画立即取消，显示目标时间对应的窗口；不闪现旧曲行、不重复滚动。 |
| 6 | 滚动过程中切换到另一首有歌词的曲目 | 新曲窗口整体更新；不混入上一曲字形、长度或时间索引。 |
| 7 | Seek 跨过两行以上，再连续操作旋钮 | 直接定位最新行，不逐行补播过去的动画，也不积累滚动队列。 |
| 8 | 播到末句和无歌词曲目 | 末尾越界槽为空；空素材曲目仍显示 `NO LYRICS`。 |
| 9 | 同时观察底部波形、播放页、EC2 浮窗、Boot 和 DIP 消隐 | 波形仍覆盖在不透明播放页画布上；浮窗、开机画面和消隐优先级不变。 |

验收时至少记录 50 次正常换行，并在动画中覆盖暂停、Seek、切曲和多行跳跃；保存录屏、bit 哈希及逐项结果。未完成完整 route 与人工上板前，不标记 D11/D12 硬件验收通过。
