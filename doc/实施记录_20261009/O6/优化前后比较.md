## 约束、布线与保留告警

- final timing 覆盖率 99.95%；no_clock=0、invalid_constraint=0、combinational_loop=0。
- final timing 对 6 个派生/输入时钟完成 slow/fast 检查；setup/hold 均无负 slack 端点。
- check_timing 报告 3 个 dummy node、2 项 PLL/clock-buffer 本地反馈告警；native_build.log 记录 sys_pll 与 video_pll 的 feedback path 在 local network，补偿延迟不可预测。
- 布局阶段有 2 条 PHY-7002：U3/sdram 初始位置 (12,12) 与 (164,288) 不合法，已由布局器移动。
- 布线阶段有 1 条 PHY-5079：一条 clock net 使用 local routing resources；日志没有给出 net 名与 sinks，待板级时钟/约束复核。
- 33 个输入端口和 38 个输出端口没有数值 I/O delay。当前缺少 SD 卡、HDMI 与 PCB 走线/器件时序参数；不能凭空填零，也不能称为已完成外部时序约束。
- 综合日志含 RAM 初始化值在 eram_init=off 时被忽略、加密 SDRAM IP 模型若干 undriven pin 警告。它们不导致本轮 route 失败，但仍是保留告警，不能当作已消失。
- final.qor 与 route.status 没有提供可用的最终 route overflow 字段。虽然 build 成功且时序 clean，overflow 仍记录为 null/UNVERIFIED，不推断为 0。
