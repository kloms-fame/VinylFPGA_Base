# O4 黑胶与读地址减负范围

## 目标

从稳定基线移除播放画面中的动态黑胶几何计算，用现有封面像素流作为封面显示；保留可用 MV 播放。用完整物理实现报告决定是否另做读地址优化。

## 设计

- S6 的 `rgb_in` 已连接到当前已选图片/封面的视频像素流，包含已有 160×120 缩略图视图。静态图片模式直接显示这条现有像素流；旁路黑胶只去除覆盖其上的盘面图形，不增加图像缩放、SDRAM 读口、帧缓冲或背景层。用户之后替换现有图片资产即可使用专辑封面。
- 保留 KEY08 的静态封面/MV 切换、帧边界提交、MV 元数据有效门控和现有 MV 320×240 窗口/FIFO读节拍。MV 不可用时回退封面。
- 移除仅为黑胶动画使用的坐标/相位/帧快照状态和生产 renderer 实例；参考模块和既有单元测试留作历史基准。
- O4b 触发条件统一为：O4a 与精确父版本同配置比较后，`ext_mem_clk` 的关键读请求路径仍位于 top setup 路径，且该路径 slack 变差；若 WNS 变负则先停阶段定位，不据此直接修改地址链。只出现其他路径变差不触发 O4b。
- 父版本的读请求路径端点为 `frame_fifo_read/App_rd_en_r`，起点映射在 `u_s6_video_layer/renderer`，中间还经过 `frame_fifo_read` FIFO 水位逻辑；这是读使能/节拍路径，并非已证实的地址选择 mux 问题。O4a 后以新路径报告复核。

## 验收

- S6 定向检查覆盖封面透传、MV ready/不可用回退、KEY08帧边界切换、MV窗口读/显示计数、Seek/暂停/EOF与插拔回归。
- O4a 同配置完整 gate/place/route/fix_hold/final；实测 DSP/LUT/寄存器及最差 setup/hold 路径。
- 依据 O4a 报告决定 O4b 实施或记录不触发。不开 bitgen。
- 人工板级验收步骤：烧录用户自行生成的 bit；启动播放后确认原唱片覆盖消失且当前图片正常显示；通过 KEY08 在静态图片和有效 MV 间切换，确认切换只发生在帧边界；检查 MV 画面窗口、暂停/Seek/播放结束，以及 MV 不可用时回退到图片；确认旋钮/DIP 蜂鸣反馈听感与基线一致。

## 文件边界

预计生产 RTL：`src/video/s6_video_layer.v`；回归测试：`sim/tb_s6_video_layer.v` 与新增 cover/MV 定向检查。O4b 未触发前不改 `src/SD/frame_read_write.v`、`src/SD/frame_fifo_read.v`。
