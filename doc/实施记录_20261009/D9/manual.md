# D9 板级人工验收

## 烧录前准备

1. 使用 SynthPilot 通过 `opt_gate` 后的源码生成 bit 固件。此提交不自动生成或烧录 bit。
2. 如需验收真实标题/歌词，先取得确认过的 UTF-8 素材，编辑 `doc/资源/lyrics/songs_manifest.json`：四项 `song_id` 必须是 0、1、2、3；每项的 `lrc` 是相对 manifest 的路径。之后执行：

   ```powershell
   python tools/gen_lrc_assets.py --songs-manifest doc/资源/lyrics/songs_manifest.json
   ```

3. 每曲最多 128 行，每行最多 16 个 Unicode 字形；长句需由素材侧按真实时间拆行。重复时间取文件中最后一条。不要用 `demo.lrc` 代替歌曲歌词。

## 操作步骤与预期

1. 上电并进入播放页，确认当前歌词区在无歌词素材时显示 `NO LYRICS`，没有乱码或演示说明文本。
2. 依次播放四个 `song_id`，确认曲目切换后歌词状态重新采纳；快速切曲时，上一曲末句不能残留到下一曲。
3. 加入已核验的真实 LRC 后重新烧录：确认每曲显示各自歌词，且曲目标题/歌手由提供的真实资料显示（D9 单行阶段暂不显示标题/歌手）。
4. 暂停后等待至少两句歌词间隔，确认当前句不继续推进；继续播放后从原音频位置继续。
5. Seek 到首句时间之前，确认歌词行留空；Seek 到某句时间后确认该句出现；越过多句后确认选中时间不晚于当前音频时刻的最后一句。
6. 使用重复时间素材：确认相同毫秒时间只显示最后一行。确认超 128 行、超 16 字/行、非法秒字段、u32 毫秒溢出会在生成阶段报错，不会静默截断。
7. 长时间播放并观察 10 分钟以上：歌词应持续与音频同步；暂停、重播和切曲后不得出现旧代次歌词。
8. 同时检查 MV、画质调节、EC2 浮窗、Boot 和消隐优先级无回归；检查 HDMI 声音不受歌词切换影响。

记录实际 bit 哈希、板卡/显示器、使用的素材版本、每项结果与现象；没有真实歌词素材时，仅能验收四曲空文本、`NO LYRICS` 与切曲清空行为。
