# 阶段二：选歌浏览界面人工验收

## 本阶段改动

- 浏览页继续显示完整封面，只在底部信息栏对封面像素做 50% 暗化。
- 信息栏显示曲号、歌名、歌手和总时长；歌名与歌手共用现有 16×16 字库读取通路。
- 四首曲目指示条跟随浏览焦点变化。
- 播放页沿用阶段一界面。播放态与浏览态在视频帧边界切换。
- 没有新增字库 ROM、帧缓存或总时长转换模块。

## 烧录前检查

候选工程快照：`prj/resource_opt_verified_20261005/stage2_browse_release`。

1. 等待 `release_driver.log` 出现 `BITGEN_COMPLETE`，并确认同目录存在 `VinylFPGA_optimized.bit` 和 `bitstream.sha256`。
2. 查看 `native_build.log` 中的 `VERIFIED_ROUND_COMPLETE`，核对 `final.qor` 的 Setup/Hold WNS 均为正、TNS 为 0；`final.constraints` 中 no-clock、invalid-constraint、combinational-loop 计数均为 0。
3. 在 `final.area` 核对 BRAM9K 为 47 块，并与阶段一原生报告 `stage1_ui_clean_release/final.area` 对比总 `#lut`；目标增量不超过 100。阶段一该项基线为 15,589 LUT。
4. 若日志出现 `BUILD_FAILED`、`BITGEN_FAILED`、`ERROR` 或 `FATAL`，先停止，不要用旧固件代替本阶段固件。

固件路径：`prj/resource_opt_verified_20261005/stage2_browse_release/VinylFPGA_optimized.bit`。

## 准备开发板和 SD 卡

1. 使用项目现有 S6 验收卡。需要重写测试卡时，`doc/资源/sd卡/write_card.bat` 菜单选择 **6**，对应 `doc/资源/sd卡/card_S6.img`；确认目标盘符确为 TF 卡，写入完成后安全弹出。
2. `card_S6.img` 的四个曲目共用同一个 `AUDIO.PCM`（约 4 分 05 秒），因此四首显示相同的 `04:05` 总时长是预期现象；本阶段用曲号、封面及歌名/歌手的对应关系检查切歌同步。
3. 连接开发板电源、HDMI、J2 扩展板和 TF 卡。沿用当前稳定版本的拨码设置。
4. 在 Tang Dynasty 下载工具中选择 EG4S20BG256，加载上面路径的 `VinylFPGA_optimized.bit`，执行 JTAG/SRAM 下载。不要写入 Flash。

## 人工验收步骤

| 项目 | 操作 | 通过标准 |
|---|---|---|
| 冷启动浏览 | 下载后复位，上电并等待启动 Logo 结束 | HDMI 稳定显示封面；底部信息栏出现 `TRACK 01/04`、`Never Gonna`、`Rick Astley` 和 `04:05`，没有黑屏或花屏 |
| 底栏层次 | 观察底部栏及上下边缘 | 栏目覆盖封面底部，背景明显变暗但仍看得见封面；上下边线和两条竖分隔线连续、无漏像素 |
| 四曲切换 | 用 EC1 旋转或方向键依次切到第 2、3、4 首，再切回第 1 首 | 曲号依次为 `02/04`、`03/04`、`04/04`；对应歌名/歌手依次为“山湖之间/山野唱片”“森林漫步/绿野唱片”“玫瑰心语/花语唱片”；封面与文字同步刷新，没有上一首残留、乱码或半帧撕裂 |
| 焦点标记 | 每切一首观察屏幕下方四个标记 | 当前曲显示 16 像素金色条，其余三首为短灰色块；焦点顺序与曲号、封面一致 |
| 快速切换 | 连续转动 EC1，多次来回选择 | 底栏文字始终对应最终停留的封面；无卡死、持续闪烁或错位 |
| 进入播放 | 在任一浏览曲目上按 EC1 确认 | 底部浏览栏消失，出现阶段一播放页；进度条、曲目信息、歌词和波形按原播放行为工作，没有浏览字符叠留 |
| 返回浏览 | 播放时按 KEY7 或 KEY11 返回 | 浏览栏恢复，显示返回后的当前曲目；封面和高亮标记相符，无黑帧或明显闪屏 |
| 视频消隐 | 观察 HDMI 有效画面边缘及切换过程 | 有效画面外保持黑色，没有彩色杂点；切换期间画面持续稳定 |
