## S3:展示基础功能和拓展功能

### S3-00基础功能

插入SD卡出图（标注TF卡BMP读取）



### S3-01图片轮播与转场

1. 直切：选模式后真实换图，拍旧图、切换和新图稳定。
2. 水平擦入：完整拍过渡的所有阶段。
3. 淡出淡入：完整拍淡出、过渡和淡入。
4. 三种模式分别录 2 条，每条 30–45 秒。
5. 打开 DIP2，录至少两次自动轮播；关闭 DIP2 后继续录过一个周期，证明停止。
6. 自动轮播录 2 条，每条 75–100 秒。

**必须拍到：** 模式选择、真实换图、完整过渡、新图稳定。只按模式键不算完成演示。

### S3-02 图层叠加与字幕（重点）

1. 选歌界面：拍清封面、曲名、曲号和选中状态
2. 播放界面：拍清曲名、艺人、歌词、进度和时间等多个图层
3. 歌词五行动效：连续录到至少两次换句、高亮和滚动。
4. KEY6 单行/五行切换：拍五行→单行→五行，并补暂停、切曲和 Seek。
5. 三种播放背景：每种背景都拍操作、切换过程和新背景稳定结果。
6. 中文歌词和英文歌词

**必须拍到：** 文字清楚，换句真实，图层次序正确，暂停后歌词冻结。  



### S3-03实时参数调节与 OSD（重点）

1. EC2 进入 SELECT，依次展示 VOL、BRI、CON、ROT、WSL 的参数名和当前值。
2. 调低音量，拍真实声音和 J2 VU 变化。
3. 调高亮度，再调高对比度，相机全程锁定曝光。
4. 修改五个参数为非默认值，镜头内记录修改后的值。
5. 按母板 KEY3 保存，拍清忙灯、完成灯和成功三音。
6. 不再修改参数，真实断电，再复电。
7. 复电后再次进入参数界面，核对五项恢复值，并进入播放页确认实际生效。
8. 最后执行参数恢复默认，拍清默认值和画面变化。

**必须拍到：** 非默认值、保存动作、完成反馈、断电、复电、恢复和重置默认在同一证据组。  
**禁止表述：** 不称断电续播；参数保存不等于保存歌曲和播放位置。



### S4-04 音频可视化

1. 播放内容强弱变化明显的歌曲，完全不操作录 20 秒。
2. 拍 PCM 幅度波形，拍 WS2812B 电平反馈。
3. 静音 3–5 秒再恢复，保持屏幕时间继续；拍 J2 VU 的真实响应。
4. 调一档音量，拍真实声音、屏幕波形和灯带变化。
5. KEY10 切换 J2 全灭/VU，确认唱片灯和电机不受影响，再恢复。

**准确口径：** PCM 幅度/电平波形和最终输出 VU。  
**禁止表述：** 不称 FFT/DFT 频谱分析。



### S3-05图像缩放、封面与 MV

1. 先拍浏览页的完整 640×480 封面。
2. 进入播放页，拍同一封面在左侧 320×240 窗口中的固定 2:1 缩小结果。
3. KEY7 返回浏览页，再进入播放页，重复一次。
4. KEY8 切换 MV

**准确口径：** 这是同一封面固定 2:1 点采样缩小。  
**禁止表述：** 不称任意分辨率自适应，不称双线性缩放。





## S4:功能逐项展示（一笔带过，不需要全部演示）

### S4-01 播放模式

1. 播完暂停：完整拍到最后、暂停状态和进度图标。
2. 单曲循环：拍模式图标、播放结束和重新开始。
3. 自动下一首：拍模式图标、曲目结束、下一首进入播放。
4. 可以调整进度来查看效果
5. 重点拍进度条下方图标的变化，手离开后结果再停 5 秒。

### S4-02 拓展板功能

逐项拍摄并保留动作与结果：

1. WS2812B 总开关。
2. 红外接收和遥控响应。
3. 自动息屏和唤醒。
4. LED 指示灯状态。
5. 自动切图开启和关闭。
6. 拓展板其他已核验开关。

### S4-03 板载功能

逐项拍摄：

1. 蜂鸣器按键反馈。
2. 数码管总控。
3. 开机动画。
4. 自动保存。
5. 一键静音和恢复。
6. 参数保存和参数复位。
7. 系统重启。
8. SD 卡拔出警报和重新插入恢复。

SD 卡操作采用现场已验证的安全流程；如果需要重启才能恢复，就完整保留过程，不能剪成“热插拔立即恢复”。

### S4-04 红外遥控器

**第一组：播放控制**

1. 上一首、下一首。

4. 重播。

**第二组：系统控制**

1. 音量加、音量减。
2. 息屏和唤醒。
3. 参数保存、恢复默认、系统重启。
4. 静音、返回主界面。
5. 转场效果切换、背景更换。
6. 上下左右操作。

## S5:一镜到底完整流程（剪辑特别标注一镜到底，无分次烧录固件，无倍速）（主题化完整演示）

1. 接通电源，手离开，录完整 Boot 开机动画。
2. 进入封面浏览页，旋转旋钮选择第四首歌曲。
3. 确认播放，录屏幕进入播放页和真实音乐开始。
4. 拨动唱针落针，录针、盘面、灯光和屏幕状态响应。
5. 展示播放页的 MV、歌词、进度条和 PCM 波形。
6. 暂停，保持 5 秒，确认声音停止、进度和歌词冻结。
7. 恢复播放，确认声音、进度和歌词从同一位置继续。
8. 旋转旋钮快进，播放 5–10 秒，再快退。
9. 最后回到正常播放状态，继续录 10 秒再停。











## S6:总结收尾：核心亮点，资源占用数据，可控性指标提一下

实际应用价值:



1. 工程难点是让共享存储中的音频、图像和MV互不干扰。系统采用音频储备优先、多级缓存和MV三缓冲，等待完整帧写入后再提交，并在切曲或定位时隔离旧事 务。

2. 作品的优势是完整的本地媒体链路、共同进度驱动的音画联动，以及有辨识度的实体交互。它既提供桌面听音原型，也把国产FPGA的缓存、时序和控制协作变成可观察的系统。

3. 本项目选择FPGA，是为了让媒体读取、音频消费、画面合成和实体控制并行协作。缓存与握手隔离不同节奏，再用实际播放进度组织歌词和MV，形成专用的硬件媒体链路。





可以强调低功耗（自动息屏，关闭数码管，蜂鸣器等一切外部因素，只进行播放音乐）

WS总开关，红外接收，自动息屏，LED指示，蜂鸣器反馈，数码管总控，低功耗
