# 赛题要求与项目对应

依据随提交保留的 [2026 安路选题指南](reference/contest_topic_2026_anlogic.pdf)物理第 14–15 页，以及 [赛题解析一](reference/topic1_explanation.pptx)第 5、6、15–21 张。原资料用来核对比赛要求，资料中的示例步骤不是本次自动执行的操作指令。

选题为“基于安路 EG4S20 的 HDMI 多媒体播放系统”，面向本地音视频展示。指南将扩展列为加分项，解析课件第 6 张进一步提出至少实现一项扩展；项目按基础功能整合和已实现扩展进行展示，不推测评委最终评分。

## 基础功能

| 赛题要求 | 当前实现与证据入口 | 展示方式 |
| --- | --- | --- |
| 指定平台 | HX4S20C / EG4S20BG256；[工程](../prj/VinylFPGA.al)、[引脚约束](../constraints/pin.adc) | 展示实际板卡和工程器件信息 |
| TF 卡 BMP 读取、SDRAM 缓存、HDMI 显示 | [SD 媒体通路](../src/SD/)、[顶层](../src/top_tf_hdmi_audio.v) | 读取 640×480、24-bit 非压缩 BMP，并输出图像 |
| 手动切换与轮播 | [slideshow_controller.v](../src/io/slideshow_controller.v)、浏览/播放页面 | 手动切换、自动展示及返回浏览 |
| HDMI 音频输出 | [audio/](../src/audio/)、HDMI 音频桥接和发送通路 | 48 kHz PCM、播放/暂停、音量及画面联动 |
| 完整设计整合 | 单一顶层、同一工程与固件 | 不以反复更换不同镜像拼接展示功能 |
| 固化后上电运行 | 官方解析第 21 张要求；现场确认项见 [演示与验收](demo_acceptance.md) | 从断电状态启动，不依靠现场 PC 临时下载 |

用户已于 2026-10-30 确认当前项目人工验收无问题。该确认按项目整体记录，未提供的逐项时长、设备型号或测量数据不补写为已执行。尤其不能用源码存在或仿真通过替代现场冷启动与固化方式的展示。

## 扩展功能与范围

| 扩展方向 | 当前能力 | 说明 |
| --- | --- | --- |
| 图层叠加与字幕 | 歌词/标题 ROM、五行歌词及单行专注、页面与参数叠加 | KEY6 切换歌词显示；对应 `display/` 与 `ui_event_bridge.v` |
| 图片轮播与转场 | 轮播控制、淡化与页面/背景切换 | 对应 `slideshow_controller.v`、`video_transition_apply.v`、`video_fade_transition.v` |
| 图片缩放适配 | 固定媒体尺寸、固定比例或窗口显示路径 | 不宣称任意分辨率自适应缩放；保留插值模块未接入当前顶层 |
| 实时参数与 OSD | 亮度/对比度等参数调节、数值反馈与参数保存 | 对应 `brightness_contrast_steps.v`、`ec2_param_osd.v`、参数持久化模块 |
| 音频可视化 | PCM 幅度波形、与音频联动的显示/灯效 | 波形属于赛题列出的可视化形式；不是 FFT/DFT 频谱 |
| 项目自主扩展 | 本地 PCM/MV、seek、歌词专注、背景缓存、实体交互及 Flash 参数 | 以真实效果、代码及测试说明展示，不以功能数量代替完成质量 |

## 提交口径

当前工程的运行时音视频与控制流程在 FPGA 中实现。媒体文件的尺寸、编码和布局在准备阶段按约定整理；系统不在板上解码 MP4。官方原文还要求外围模块不得带额外处理器，最终硬件组合应由参赛者按实物确认。此文不替代赛事方对外围模块、离线素材准备或第三方 IP 使用范围的解释。

厂商加密 HDMI/SDRAM 核及器件原语保留原文件；项目展示时应说明自编写逻辑与厂商 IP 的边界。不能声称提供厂商加密核心内部源码，也不能仅凭零 setup/hold 端点违例宣称全部板级时序模型或所有工作条件均已签核。
