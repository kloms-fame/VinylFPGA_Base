# 麦克风直插与片内 ADC 混音开发计划

**目标：** 将 AO/G/+/DO 麦克风模块插入交互板 EXT3–EXT6，并与背景音乐同时从 HDMI 输出。以现有已验收项目为基线，优先使用 EG4S20 片内 ADC。

**现状：** 扩展板原理图中 EXT3→J2.37；手册中 J2.37→N12；器件手册 N12→ADC_CH5。实际排母及排线需断电测通。当前 `exp_ext_o[2:5]` 均输出低，必须改造后才能插接。未确认 AO 波形、模块启动/运行电流和 ADC 信号范围。

## 两种供电实现，先完成电气验证

直接 GPIO 供电的设想为 EXT3=AO/ADC_CH5、EXT4=G/输出低、EXT5=+/输出高、EXT6=DO/高阻输入。高低输出是有源器件，非电源轨。EG4S20 数据手册第 5.3 节说明一般 IO 配置前高阻、配置中弱上拉或高阻；实际引脚模式及复位/重新配置需要逐阶段核查。输出强度设置不是供电电流许可。无确切电气限值、麦克风电流及其 3.3 V 启动波形前，不制作或上板此连接方案。

保留同样物理直插外形的更稳妥候选：修改交互扩展板，在将 EXT4、EXT5 原有 GPIO 线路可靠隔离之后，分别连接真实 GND、3V3，EXT3 保留 ADC，EXT6 保留未驱动输入或断开。这是硬件改线/改板方案，需要用户实际硬件、设计和测试，且 EXT4/EXT5 不再是原功能的数字 IO；保留其他输入及 EXT1/2 功能，原 EXT4/5 的空闲输出能力不能宣称保留。不能在没有隔离原 FPGA 驱动的情况下将线路直接短接到电源轨。不要现有固件直接插模块。

官方主板手册与资源包另一版主板原理图对 J2.35/36/38/39/40 映射不一致，J2.37/N12 一致。必须辨识板卡修订并测量 EXT4、EXT5、EXT6 实际网路；禁止假定其 FPGA 管脚或外围负载，尤其是上电配置功能复用。

## 音频架构

AO→ADC_CH5→采样有效判断→去直流/可选低通→定点缩放→与 `audio_source_mux` 输出饱和相加→`hdmi_pcm_source_bridge`。麦克风同时送左右声道，默认关闭；全局静音覆盖音乐和麦克风；音乐暂停时允许麦克风独立运行的行为需明确，HDMI 有持续样本时才可输出。优先移位增益、寄存流水、不用 BRAM；实际资源和时序由构建决定。

片内 ADC `EG_PHY_ADC` 工作时钟 ≤16 MHz，最大 1 MSPS，12 位码宽、有效精度 8 位，输入 0.1–0.9 VREF。官方指南建议 SOC 间隔 <10 µs；候选在同源时钟下按约 144 kS/s 采样并低通、3:1 降采样至 48 kHz；必须验证 ADC 时序、分数节拍及切源相位，滤波器须先定义语音带宽/混叠性能，再决定资源。将转换完成数据作时钟域传输时保证握手及多位一致性。无法预先保证音质。

## 分阶段执行与验收

1. 完成器件、两版板卡原理图、实物连通、GPIO 驱动/绝对最大额定值/上电复位状态核查；独立 3.3 V 测量模块的稳态及启动电流，示波器测 AO 相对于真实地的偏置、语音峰值和 DO。查询 ADC VREF 与噪声；没有测量数据则 GPIO 供电不进入上板阶段。
2. 制作时序参考模型：确定 ADC 频率、SOC/EOC、采样与 48 kHz 相位，制定低通指标与饱和/静音行为。ADC 厂商模型将模拟通道固定，测试必须使用可控行为模型，不能据此声称模拟音质通过。
3. 独立工程或隔离副本做 ADC 采样和可观测 PCM 测试，确认硬核端口/参数、时钟约束及板级噪声。模拟输入做 AC 耦合/偏置或滤波的决定以测量为依据；不得在不符合输入范围时直接接入。
4. 先验证混音模型、饱和/负值、静音、暂停/切换/握手、ADC 断开、复位及原版旁路一致性；再接入原播放器，逐步跑当前仿真回归及 TD 综合布局布线。修改 `src/top_tf_hdmi_audio.v`、`src/io/expansion_integration.v`、`constraints/pin.adc` 和 `prj/VinylFPGA.al` 的具体形式以实现方案和原语结果为准。
5. 复核资源、所有相关约束、setup/hold、报告与警告，进行耳机低音量试听、长时间稳定性和反馈啸叫测试；保留现有已验收镜像，发布新版本并明确差异。

当前阶段：数字实现、仿真与物理实现已完成并通过构建（best_result = seed 14，SWNS +0.122 ns / HWNS +0.031 ns，约束修复见 [microphone_status.md](microphone_status.md)）；硬件电气验证仍处 S0，上电前必须按 [microphone_bringup.md](microphone_bringup.md) 第 0 节确认供电、电流、AO 电平与实物引脚映射。在完成这些验证前，不应声称 GPIO 供电可用，也不要用旧固件接模块。
