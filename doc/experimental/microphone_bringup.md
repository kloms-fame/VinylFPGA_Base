# 片内 ADC 麦克风上板验收教程（分阶段）

固件：`prj/VinylFPGA_Runs/best_result/VinylFPGA.bit`（684,332 字节，SHA-256 `12888BE734514BCE75FBF16651CACA2C2E680833A75909AD35F90CC582C4B2F8`，2026-10-31 在 `main`（基线 fe383ab）上重新综合，seed 15，SWNS +0.060 ns / HWNS +0.021 ns；麦克风增益跟随用户音量（VOL=200 → 5.0×，VOL=100 → 2.5×，VOL=0 → 静音）。工作区根目录留有便于烧录的副本 `稳定固件_麦克风跟随VOL_seed15_12888BE7.bit`）
工程：`prj/VinylFPGA.al`（Seeds 13/14/15，本轮选中 15）
回滚固件（主线版）：`output/VinylFPGA_Contest_Firmware/VinylFPGA.bit`（比赛冻结交付版，seed 10，SWNS +0.105 ns / HWNS +0.024 ns，SHA-256 `97B370265AF7EC7E7B8B4341A88407631722808F434E473D8BA1B4ABF11D3863`，见同目录 `manifest.json`；工作区根目录副本 `稳定固件_主线fe383ab_seed10_97B37026.bit`）

本教程按"母板 → 扩展板 → 麦克风"三段推进，每段都有独立的通过判据。**不要跳段**：先证明新固件没破坏原功能，再引入扩展板，最后接麦克风，任何一段失败都能立刻定位到刚引入的那部分。

## 0. 准备清单

硬件：EG4S20 开发板（HX4S20）、12 V 电源、HDMI 线 + 显示器、3.5 mm 耳机或音箱、含音乐的 SD 卡、JTAG 下载线（OneCable）、J2 交互扩展板、AO/G/+/DO 四线麦克风模块、万用表（**强烈建议**）、杜邦线若干。

软件：TD 6.2.1（Tang Dynasty）、本工作树 `prj/VinylFPGA.al`、可选串口工具（115200 8N1）。

## 0.1 上电前必读（安全）

本固件把 EXT4 驱动为低、EXT5 驱动为高，用 FPGA GPIO 给麦克风供电。GPIO 不是稳压电源，以下三条不满足就不要接麦克风：

1. 模块是 3.3 V 器件（不是 5 V），静态电流远小于单脚 8 mA；
2. AO 输出在 ADC 输入范围（约 0.33–2.97 V，通常需 AC 耦合 + 偏置）；
3. 已用万用表确认 J2 排针 EXT3/EXT4/EXT5 与 FPGA 引脚连通（EXT3=N12、EXT4=P14、EXT5=P12）。

**禁止用主线旧固件接麦克风**：旧固件把 EXT3–EXT6 全部驱动为低，会把模块电源短路到地。

**更安全的替代**：外部 3.3 V 给模块供电，并**先断开 EXT4/EXT5 与模块的连线**，不能一边 FPGA 输出高一边外部供电。

## 0.2 先确认板子里跑的是哪个固件（重要）

J2 的 EXT1–EXT6 在两种固件下电压不同，**用万用表就能判断当前跑的是哪一版**，这是上板第一步。引脚映射已三方核对一致：本工程 `constraints/pin.adc`、扩展板测试工程 `资源/Expansion_Board_Test/README.md`（J2 表 U1.35–U1.40）、开发板原理图（4_GPIO）。

| 引脚 | 网络 | FPGA 引脚 | 主线固件（旧） | 麦克风固件（本工程） | 说明 |
|---|---|---|---|---|---|
| EXT1 | 蜂鸣器镜像 | M12 | ≈3.26 V | ≈3.26 V | 复用 `board_buzzer_n`，空闲为高；**是逻辑信号，不能给麦克风供电** |
| EXT2 | 备用 | M11 | 0 V | 0 V | 未使用 |
| EXT3 | ADC_CH5 | N12 | 0 V | 悬空时读数不定 | 新固件改为 ADC 输入，不再驱动 |
| EXT4 | 麦克风地 | P14 | 0 V | 0 V | 新固件驱动低 |
| EXT5 | 麦克风电源 | P12 | 0 V | **≈3.3 V** | 新固件驱动高，**版本判据** |
| EXT6 | 比较器输入 | R12 | 0 V | 悬空时读数不定 | 新固件为高阻输入，未使用 |

判据：**EXT5 ≈3.3 V = 本工程（麦克风）固件；EXT5 = 0 V = 主线固件**。

典型误判：只测到 EXT1≈3.26 V、EXT2–EXT6 全 0 V，正是主线固件的特征——说明板子里跑的还是主线固件，或 Programmer 里选的是主线工程的 bit。TD 同时打开了主线工程时极易选错，烧录前务必确认配置文件是 `prj/VinylFPGA_Runs/best_result/VinylFPGA.bit`（本工程根目录），并在烧录成功后立刻复测 EXT5。

## 1. 烧录教程

### 1.1 JTAG 下载到 SRAM（本次验收用）

1. 断电，接好 JTAG 下载线（OneCable）到主板 JTAG 口，再上电。
2. 打开 TD，`File → Open Project` 选 `prj/VinylFPGA.al`；或直接打开 Programmer。
3. 进入下载界面（Tools → Programmer / 工具栏下载按钮，不同 TD 版本菜单名略有差异）。
4. 选择配置文件 `prj/VinylFPGA_Runs/best_result/VinylFPGA.bit`。
5. 模式选 **SRAM / JTAG**（不要勾选 SPI Flash 固化），点下载。
6. 等待进度到 100%，提示成功后板子立即运行新固件。断电后 SRAM 内容丢失，重新上电会回到 Flash 里的旧固件。

### 1.2 固化到配置 Flash（全部验收通过后再做）

1. 同一 Programmer 界面，模式改选 **SPI Flash**。
2. 选择 bit 文件（或按主线流程生成 `.bin`），勾选擦除 + 编程 + 校验。
3. 下载完成后断电重上电，确认开机画面出现。
4. 固化后如需回滚，重复 1.2 烧回主线固件。

## 2. 阶段 A：不插扩展板（母板基准）

**目的**：证明新固件的原功能与主线一致，建立"已知良好"基线。

**步骤**：

1. 拔掉扩展板，J2 保持空置；插 SD 卡；接 HDMI 和耳机/音箱。
2. 烧录本固件（1.1），上电。
3. A1 观察开机画面：Logo/动画正常，进入主界面，无花屏、无卡死。
4. A2 母板按键：KEY2 参数复位、KEY3 手动保存、KEY4 静音，逐个按，面板/HUD 有对应反馈。
5. A3 播放音乐：HDMI 出声，音乐流畅，无爆音、无断续。
6. A4 调音量、看灯效/波形/歌词与主线行为一致。
7. A5 暂停、继续、切歌、切下一首。
8. A6 视频/幻灯片（如 SD 卡里有对应素材）能正常切换。
9. A7 连续播放 10 分钟以上，确认无死机、无音画不同步。

**阶段 A 的预期现象（重要）**：

此时 J2 的 EXT3/N12 悬空，ADC 采到的是悬空噪声，会以底噪形式混进音乐，可能听到轻微的"沙沙"声。**这是预期现象，不是故障**，恰好说明麦克风通路在工作。

- 判据：按 KEY4 静音后应**完全无声**（含底噪）；取消静音后音乐正常，可以带一点底噪。
- 想安静测试：断电后用杜邦线把 J2 的 EXT3 短到 GND，AD 读数固定为 0，去直流后输出 0，底噪消失。测完记得拆除。

**通过标准**：上述 A1–A7 全部正常，且"静音后无任何声音"成立。

## 3. 阶段 B：插扩展板，不接麦克风

**目的**：确认扩展板功能正常，并验证本固件对 EXT4/EXT5 的驱动符合设计。

**步骤**：

1. 断电，把扩展板插到 J2（注意 U1 与 J2 对位，不要错位或反插）。
2. 上电。
3. B1 万用表测扩展板 8P 接口（以 GND 为参考），逐项对照 0.2 的表：
   - EXT5：**≈3.3 V**（3.0–3.4 V）；不是 3.3 V 就先停在 B 段，按 0.2 确认固件版本
   - EXT4：≈0 V
   - EXT1：≈3.26 V（蜂鸣器镜像，正常，不是故障）
   - EXT2：0 V
   - EXT3、EXT6：悬空，读数漂移属正常
4. B2 扩展板 LED：DIP3 上拨（LED 使能）后 LED1–LED4 按业务逻辑亮灭。
5. B3 按键 KEY1–KEY12 逐个按，均有对应功能。
6. B4 DIP1–DIP6 逐个拨动，功能切换正常。
7. B5 旋转 EC1/EC2，按压编码器开关，功能正常。
8. B6 红外遥控器按键，功能正常。
9. B7 WS2812 灯珠颜色/顺序正常。
10. B8 再快速回归一遍 A3/A5/A6（音乐、暂停、视频）。

**风险提示**：旧固件 EXT4/EXT5 都是低电平，本固件 EXT5 变成高电平。如果扩展板上 EXT5 网络并非空闲（接了输入、上拉或器件），可能出现异常。**上电后若发现异常发热、功能全乱或 EXT5 电压被拉低，立即断电**，说明该网络不能当电源用，改用外部供电方案。

**通过标准**：B1 电压正确 + B2–B8 扩展板与母板功能全部正常。

## 4. 阶段 C：接麦克风

### C1 只接电源（G、+），暂不接 AO

1. 断电，模块 G → EXT4，+ → EXT5，AO 和 DO 先不接。
2. 上电，万用表测模块 VCC 对 GND：应稳定在 3.2–3.4 V，波动小于 0.2 V。
3. 摸模块是否发热；观察 1 分钟。
4. **失败处理**：电压掉到 2 V 以下、明显发热或复位重启，立即断电。说明 GPIO 带不动，改用外部 3.3 V 供电（并断开 EXT4/EXT5 与模块的连接）。

### C2 再接 AO

1. 断电，AO → EXT3（N12）。DO 不接。
2. 上电，万用表测 AO 对 EXT4（地）：直流偏置应在 0.3–3.0 V 之间。
3. 对着模块说话，用万用表交流电压档观察 AO 有波动（几十 mV 到几百 mV）。
4. **失败处理**：偏置接近 0 V 或 3.3 V 且说话无波动 → 模块没工作或输出饱和，检查模块供电和型号；偏置超出范围不要长时间接 ADC。

### C3 功能验收

| 步骤 | 操作 | 预期 |
|---|---|---|
| C3-1 | 播放音乐 | 音乐正常，底噪应比阶段 A 明显降低 |
| C3-2 | 对着麦克风说话（5–10 cm） | 说话声清晰叠加在音乐上，正常说话即可听清（默认 VOL=200 → 5.0× 增益，约音乐 1/2 音量），约 20 ms 淡入 |
| C3-3 | 停止说话 | 说话声消失，音乐不受影响 |
| C3-4 | 按 KEY4 | 音乐与麦克风同时静音 |
| C3-5 | 暂停音乐后说话 | 能听到说话声 → 麦克风可独立工作；无声 → 属已知限制，不是故障 |
| C3-6 | 拔掉 AO 线 | 约 164 µs 后麦克风通路静音，无爆音、无持续噪声 |
| C3-7 | 连续说话 2–3 分钟 | 无破音、无周期性咔哒声、无画面异常 |
| C3-8 | 进 OSD 音频页把音量 200→100→200 | 麦克风随音乐一起变轻/变响（VOL=100 约 2.5×）；音量调到 0 时麦克风完全无声；调节过程无咔哒声（增益斜坡约 27 ms） |

C3-1 到 C3-7 全部满足即功能验收通过。

## 6. 排障

**测到 EXT2–EXT6 全 0 V（只 EXT1 有 3.26 V）**：这是主线固件的电压特征，说明板子里跑的不是本工程固件。先按 0.2 核对 Programmer 里选的 bit 路径并重新烧录，不要动硬件接线。

**阶段 A 就异常（花屏、无声、死机）**：说明不是麦克风的问题。烧回主线固件确认板子正常，再对比本固件；检查是否烧错文件（核对 SHA-256）。

**阶段 B 异常**：优先怀疑 EXT5 输出高与扩展板网络冲突，断电用万用表测 EXT5 对地电阻；必要时改外部供电方案。

**阶段 C 听不到说话声**：按 C1/C2 的顺序查电压和偏置，再确认烧的是本 bit；最后降低音乐音量排除掩盖。

**音量仍然偏小**：确认烧的确实是 `12888BE7…` 这一版（更早的实验版只有 0.25× 固定增益或 5× 不随音量）。先把音量调到 200（=5.0×）再测；若 5.0× 仍不够，说明瓶颈在模拟前端（47 Ω 压降、麦克风偏置、ADC 输入幅度），此时应测 C1 的直流偏置是否接近 VREF/2、交流幅度是否达到几百 mV，而不是继续加数字增益。

**麦克风音量随音乐变小/调到 0 后完全无声**：这是本轮设计行为——麦克风增益 = round(VOL×4/5)，跟随用户音量，避免音乐小声时麦克风过响；需要更大麦克风音量时把主音量调高（上限仍封顶 5.0×）。

**持续啸叫**：麦克风与扬声器距离太近，降低音量或拉开距离。
