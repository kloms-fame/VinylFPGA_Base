**正式拍摄的初始状态：**

- DIP1 开：扩展板输入可用。
- DIP2 关：避免自动轮播干扰其他镜头。
- DIP3 开：扩展 LED 可见。
- DIP4 关：普通镜头避免自动息屏。
- DIP5 开：允许遥控。
- DIP6 开：允许两路灯带。
- 母板 SW1 开：数码管可见。
- 母板 SW3 关：手动保存镜头不被自动保存提前触发。
- 启动图保持正常启用；蜂鸣器硬件开关接通。
- 先记录原参数，不要每拍一条都执行恢复默认。

**本稿使用的关键操作：**

| 控件             | 实际用途                                                 |
| ---------------- | -------------------------------------------------------- |
| EC1 旋转         | 浏览时选曲；播放时按约 2 秒档位前后定位                  |
| EC1 按下         | 浏览时确认播放；播放时暂停、继续                         |
| 扩展 KEY1 / KEY3 | 上一、下一封面；播放时上一、下一曲                       |
| 扩展 KEY2        | 确认、暂停、继续                                         |
| 扩展 KEY4 / KEY5 | 播放时音量加、减                                         |
| 扩展 KEY6        | 支持该功能且实板核对通过的版本：五行歌词／当前句专注切换 |
| 扩展 KEY7        | 返回选曲                                                 |
| 扩展 KEY8        | 静态封面／MV 切换                                        |
| 扩展 KEY9        | 选择转场模式；选择后还要实际换图                         |
| 扩展 KEY10       | J2 灯带全灭／VU 切换                                     |
| 扩展 KEY11       | 播放背景切换                                             |
| 扩展 KEY12       | 切换曲末处理模式                                         |
| 母板 KEY3        | 保存五项参数                                             |
| 母板 KEY4        | 静音、恢复                                               |
| 母板 KEY2        | 恢复默认参数并安排保存；只在对应镜头使用                 |

EC2 调参统一按这个顺序操作：**按下打开 SELECT → 旋转选择参数 → 按下进入 ADJUST → 旋转改值 → 按下返回 SELECT。** 浮窗隐藏后直接旋转会调音量；继续调其他参数时，先重新打开浮窗。

KEY6 和六帧 MV 缓存属于后续增量版本，只有实际拍摄固件已完成相应实板核对，才加入对应镜头与数据。选择旧冻结版时，KEY6 镜头改拍中文、英文歌词与换句动效。
