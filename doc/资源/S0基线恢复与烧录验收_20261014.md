## 4. 先诊断SD卡

插入测试SD卡与读卡器后，在工程根目录运行：

```powershell
python -B tools/safe_raw_writer.py --list-disks
```

核对目标的number、friendly_name、serial_number、size、bus_type。不要根据过去的E盘或磁盘1猜测当前目标。系统/启动盘及镜像所在物理盘会被拒绝。

只读诊断（N替换成真实SD盘号）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'D:\Data_Backup\VinylFPGA_Workspace_Base\VinylFPGA\doc\资源\sd卡\write_card.ps1' -DiagnoseOnly -DiskNumber N
```

也可以使用Python直达：

```powershell
python -B tools/safe_raw_writer.py --diagnose --image 'doc/资源/sd卡/stage4/card_STAGE4.img' --disk-number N --expected-sha256 e9f24f4c8a901a820fd2a0d6b4fdad572d9d842a6af5390ca3b0fb059b0f94f1
```

以上不含--write，不锁卷或写物理卡。RAW无盘符卡也可在设备身份和容量可查询时诊断。若列表不见SD卡、容量异常或设备离线，先检查插卡、读卡器和USB连接，必要时换健康测试卡。工具不会自动清盘、改只读属性或格式化；锁卷也不能修复介质CRC故障。

## 5. 写入S0镜像

1. 关闭资源管理器里该卡的目录，以及正在访问该卡的其他程序。
2. 右键[write_card.bat](D:/Data_Backup/VinylFPGA_Workspace_Base/VinylFPGA/doc/资源/sd卡/write_card.bat)，选择“以管理员身份运行”。
3. 核对列表中的真实SD盘号，输入number；输入Q可取消。
4. 查看选中设备完整身份和只读预检查。预检查失败时脚本停止，不进入写入。
5. 输入WRITE选择写入，再精确输入脚本给出的`ERASE N SIZE_BYTES`。确认文字绑定真实盘号和物理容量，操作会覆盖这张物理盘的镜像范围。
6. 工具锁定/卸载该设备全部可解释的卷，按4MiB块流式写入，flush后保持卷锁，关闭并重开物理句柄，完整回读并核对SHA。
7. 观察进度中的phase、offset、total、MiB/s，以及最终timings_seconds。进度每约0.8秒更新；若单次I/O阻塞，offset可能暂时不动，这不等于已成功。
8. 最终必须出现`mode=physical-write-verified`、readback_sha256与镜像SHA一致，并显示“S0写入与完整回读成功”。只见写入阶段完成不能作为通过。
9. 日志自动保存在`doc/资源/sd卡/stage4/write_logs/`。失败会返回非零，记录failure_offset和win32_error；整体SHA失配无法定位首个坏字节时明确显示null。
10. 成功后安全弹出，再断电装入板卡。不要把.img复制成SD里的普通文件，也不要通过资源管理器单独替换媒体文件。

镜像文件系统只有128MiB，Windows显示小容量不表示卡的物理容量变小。整个镜像写完后不要再格式化它；主机分区视图必要时通过安全弹出重新插入刷新。物理回读及随后断电/重新装卡验收一起判断实际可靠性。

写卡实测尚未完成，本轮普通文件速度不代表SD速度。新工具提供分别的SHA预检、写入、flush和回读耗时，用于判断真正瓶颈。

建议先用已有JTAG/SRAM方式验收。连接HDMI、音频、下载线和扩展板，使用你现有的TD下载工具配置，选择本轮冻结bit并核对SHA。SRAM固件掉电会丢失；冷启动测试需按原板卡下载/启动方式重新加载。待通过后再决定Flash固化，本阶段不自动烧录Flash。

建议初始扩展拨码：DIP1开启控制、DIP2关闭自动轮播、DIP4关闭60秒屏幕消隐；红外/LED/灯带按原验收配置。

- [ ] 上电/复位后能完成Logo并进入选歌页，四张旧基线封面可正常浏览。
- [ ] EC1旋转/方向键选曲，EC1按下或KEY2确认播放；播放页暂停/继续有效。
- [ ] 音频、进度、左右时长与静态演示歌词恢复原行为。S0四曲共享音频属于已说明的预期。
- [ ] 播放窗口显示完整缩小封面，四角和构图可见，没有只取左上局部或持续横线。
- [ ] 歌曲1的30秒MV可显示；KEY8可在封面/MV之间切换；其他曲目显示封面。片段结束后整机交互仍可操作。
