## 重新生成

Pillow为唯一新增Python依赖。命令在仓库根目录运行，输出目录须选择尚未包含 `card_STAGE3B.img` 的目录，工具拒绝覆盖已有镜像。

```powershell
python tools/pack_backgrounds.py --source "doc/资源/sd卡/card_S6.img" --output-dir "doc/资源/sd卡/stage3b_new"
python tools/vinyl_packer.py verify --image "doc/资源/sd卡/stage3b_new/card_STAGE3B.img"
```
