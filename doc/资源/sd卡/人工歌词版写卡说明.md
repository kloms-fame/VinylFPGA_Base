# 四曲四 MV 人工歌词版写卡说明

## 本次应写入的镜像

运行 `write_card_manual_lyrics.bat`，它固定指向：

`release_20261020_manual_lyrics_4songs_4mvs_fullbleed/VinylFPGA_SD_4SONGS_4MVS_MANUAL_LYRICS_FULLBLEED_20261020.img`

镜像大小 1536 MiB，SHA-256：`3bf36c259d093b9f85fd538892e11c74275b1e68111ed366b8c77e58cd654654`。它包含四份独立音频、四张封面、四支完整 MV 和人工校准歌词。MV 按 S5 的已审核视觉素材规则输出为 320×240 RGB565LE、10fps；第 1、4 首先去除源视频自带黑边，再满幅裁切。不要选择旧的 S4/S5/S6 小镜像作为最终卡。

发布目录中的 `release_manifest.json`、`S1_media_manifest.json`、`S2_mv_manifest.json`、`S3_lyrics_manifest.json`、`visual_assets_manifest.json` 和 `SHA256SUMS.txt` 记录构建与验收数据。当前镜像已通过文件系统、索引、媒体 CRC、连续簇链和全媒体哈希回读；实体卡和开发板尚未验收。

```powershell

python tools\vinyl_packer.py verify --image "doc\资源\sd卡\release_20261020_manual_lyrics_4songs_4mvs_fullbleed\VinylFPGA_SD_4SONGS_4MVS_MANUAL_LYRICS_FULLBLEED_20261020.img" --width 640 --height 480
```

另可用 `Get-FileHash <镜像路径> -Algorithm SHA256` 核对上述镜像哈希。正式写卡脚本还会再次校验镜像哈希、目标磁盘身份与容量，并在写入后完整读回。

## 写卡步骤

1. 插入专用测试卡，关闭 Windows 的格式化提示。卡容量至少 1536 MiB。
2. 右键 `write_card_manual_lyrics.bat`，选择“以管理员身份运行”。
3. 仔细核对磁盘号、型号、序列号和容量；确认所选设备就是测试 SD 卡。
4. 输入 `WRITE`，再原样输入 `ERASE <磁盘号> <字节数>`。任一确认不匹配都会停止。
5. 等待写入和全量回读成功，安全弹出 SD 卡后再装入开发板。

写入会覆盖目标物理磁盘上的全部数据。不要在本教程中选系统盘或其他存储设备。`write_card.bat` 也转到此当前镜像；`write_firmware_card.bat` 不写 SD 卡。

## 配套固件

同一发布目录内的配套固件为 `VinylFPGA_4songs_4mvs_manual_lyrics_fullbleed_20261020.bit`，SHA-256：`26baebd9fcf9a051bd91b204fda325e40bf92f29985a21afce10a454ec3fe82e`。在 Anlogic TD 6.2.168116 中通过 Download/JTAG 选择该 bit 下载到 EG4S20 的 SRAM。SRAM 配置断电会丢失；没有对板上配置 Flash 执行写入。

SD 镜像和 FPGA 固件是两件独立的东西：卡镜像由写卡脚本写入 TF 卡，bit 文件由 TD 下载器通过 JTAG 配置 FPGA。开发板验收步骤见同目录 `测试验收.md`。
