## 验收 ②：选第 N 首封面不错位

**写卡**：菜单选 **1**（card_A.img）→ 看到 `DONE` → 安全弹出 E: → 拔卡插板子。

**板子上操作**：
1. 上电，等 Logo 过完进主界面。
2. 初始屏幕中心应该是 Track 1 的封面（PIC1）。
3. 顺时针拧 EC1（或按右键）→ 中心图切到 Track 2（PIC2）。
4. 继续切 Track 3、Track 4。
5. 逆时针切回 Track 1。

**通过标准**：
- 切歌时**屏幕中心那张图确实是对应序号的封面**，转场动画和 S3 一样。
- 不会出现"我选第 2 首，中心却显示 PIC1/PIC3"这种错位。
- 4 张都能切到，不卡死。
- 切到第 1 首时有声音（AUDIO.PCM），切到 2/3/4 没声音是**正常**（S4 只有单轨音频，多曲播放是 S5）。

- 不挂死、不黑屏、不持续报错。
- 屏幕上**没有**"无可用资源"那种错误——因为卡上 PIC1~4 齐全，旧路径能走通。

## 验收 ⑤：仅索引供图 + 双坏报错

### ⑤a 无 PIC 只有索引

**写卡**：菜单选 **3**（card_SONG.img）→ 安全弹出 → 插板子。

> 这张卡根目录里**没有** PIC1~4.BMP，只有 SONG1~4.BMP + INDEX.BIN。FPGA 扫描器必须靠 INDEX.BIN 才能找到封面。

**板子上操作**：上电。

**通过标准**：
- **4 张封面正常显示、能切**。
- 这就证明封面确实来自索引（不是回退 PIC 路径——因为根本没有 PIC 文件）。

### ⑤b 双坏：无 PIC + 索引也坏

**写卡**：菜单选 **4**（card_B_broken.img）→ 安全弹出 → 插板子。

**板子上操作**：上电。

**通过标准**：
- 屏幕上出现**可见的错误码**（OSD 上的 `bmp_error`/`osd_error_code`，对应 `0x34` CRC 或 `0x35` 簇越界）。
- **不是死循环、不是黑屏、不是一直转圈圈**。
- 系统停在错误状态，等你换卡，不会自己挂掉。

## 故障速查

| 现象                                   | 原因                         | 处理                                  |
| -------------------------------------- | ---------------------------- | ------------------------------------- |
| 写卡脚本报 `LOCK_OK` 后 WriteFile 报错 | E: 被资源管理器/杀毒软件占用 | 关掉所有打开 E: 的窗口，重跑 bat      |
| 写完 E: 还是 31GB                      | FlushFileBuffers 没刷下去    | 安全弹出 E: 再插回，看大小是否变 27MB |
| 板子黑屏/不进主界面                    | 卡没插好 / bit 没烧 S4       | 先确认 bit 是 S4_index_v3；拔插一次卡 |
| 选 ② 时中心封面和切歌序号对不上        | 索引错位                     | 把 INDEX_A.json 发我，我对一下簇号    |
| 选 ④ 时黑屏                            | 坏索引回退路径本身有 bug     | 拍 OSD 错误码照片发我（0x30~0x37）    |
| 选 ⑤b 时一直转圈                       | 错误路径没兜住               | 拍串口输出和屏幕发我，这是 RTL bug    |

跑完哪一步卡住，把屏幕现象（最好拍个照）和 write_card.bat 窗口的输出发我。
