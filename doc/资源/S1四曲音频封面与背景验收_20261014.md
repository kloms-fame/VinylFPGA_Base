## 操作步骤

1. 使用一张健康、容量大于 1536 MiB 的 SD 卡和可靠读卡器。你之前报故障的卡如果无法被系统稳定识别，先换健康测试卡；本工具不会格式化或修复介质。
2. 推荐先用上文 S1 验证固件，核对 SHA 后再烧录。若你在工程内重新生成 bit，只用当前原 `.al`，按 S0 教程检查综合、route setup/hold 与 bitgen 均成功后再烧录；若出现 setup/hold 负裕量或工程报错，先不要用于本阶段验收。
3. 右键 `write_card_s1.bat`，选择“以管理员身份运行”。核对列表里的盘号、型号、序列号和容量确实属于 SD 卡，不能选系统 NVMe。
4. 脚本先对 1536 MiB 镜像预哈希并执行只读设备诊断。输入 `WRITE` 后，再精确输入屏幕显示的 `ERASE <盘号> <物理字节数>`。任何身份或容量不对就输入其他内容退出。
5. 等待物理写入、flush 和完整 SHA 回读全部结束。只有脚本明确显示 S1 写入与完整回读成功且读回 SHA 等于 `f407b008e1b9641950fd123c012aceaabe20cd70ae67dfe6d4422614ca8d96f0` 才安全弹出。日志在 `doc/资源/sd卡/stage4/write_logs/`。
6. 装卡并加载上面配对的 S0 bit。先复位，等待 SD 扫描结束后再操作，避免刚启动时打断首次加载。
