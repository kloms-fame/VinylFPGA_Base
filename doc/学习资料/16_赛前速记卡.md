# 赛前速记卡

## 1. 一句话

VinylFPGA是基于安路EG4S20的唱片主题互动音视频播放器，TF预置媒体、HDMI音视频、歌词/MV/幅度显示，以及旋钮、遥控和唱针实体交互整合在同一系统。

## 2. 三条技术主线

1. **连续服务：** SD不稳定，SDRAM预取+PCM FIFO吸收有限波动；音频低储备限制低优先级服务。
2. **一致位置：** 实际消费样本计时，歌词、进度、MV围绕它；显示状态帧边界提交。
3. **一致参数：** 50MHz唯一CSR，多入口只发修改意图；快照跨域，双槽Flash保存。

## 3. 必记数字

| 项目 | 数字 |
|---|---|
| PCM | 48kHz、16-bit、有符号小端、单声道 |
| 音频速率 | 96000B/s |
| 一个扇区 | 512B=256样本≈5.333ms |
| 每毫秒 | 48个消费样本 |
| 960扇区储备 | 5.12秒内容，不是等待5.12秒 |
| PCM FIFO | 名义4096样本≈85.33ms |
| MV | 320×240、RGB565LE、10fps |
| MV一帧 | 153600B=300扇区 |

| 封面 | 640×480、24-bit BMP、当前像素偏移54 |
| 扫描 | 25MHz、800×525、约59.52Hz |
| SDRAM | 2M×32bit=8MiB，word地址不是byte地址 |
| 时钟 | UI50、SD控制100、内存125、像素25、HDMI相关125MHz |
| 曲目 | 当前最多4首，歌词ROM共283行 |
| 参数 | VOL/BRI/CON/ROT/WSL，默认200/3/2/2/4 |

资源、WNS与bit哈希不要背成跨版本常量。上场前从14的实际比赛版本表核对。旧字库候选的+0.148/+0.030ns不代表所有新修改版通过。

## 4. 赛题对应

基础：TF/BMP→SDRAM→HDMI；手动/自动轮播；音频；固化与稳定完整系统。

重点扩展：图层歌词、转场、参数OSD、PCM幅度可视化。固定2:1缩小是局部缩放能力，不能说任意尺寸自适应已完成。

## 5. 五句话不要说错

- 唱针控制转盘与唱片灯效，声音来自TF数字媒体。
- 幅度柱不是FFT频谱。
- 裸PCM不是任意WAV/MP3解码，预制MV帧不是MP4/H.264解码。
- 歌词/标题/字体为预置ROM，背景模糊是离线资产。
- 统一媒体时间不等于端到端纳秒同步，有限缓存不等于任意慢卡零卡顿。

## 6. 回答顺序

先结论，再机制，再证据，最后范围。评委只问一个点时，先用20秒答清；追问后再展开代码。

示例：“以实际消费样本统一时间；每48样本1ms；顶层接wav_sample_consumed；没有把它扩写为屏幕和扬声器零误差。”

## 7. 最短演示

选曲→播放→暂停/恢复→一次Seek→调参OSD→说明保存恢复→唱针控制转盘灯效。自动轮播、不同转场、背景、结束策略按现场时长与实际版本增加。

主板与扩展板同名KEY要说清。EC1选曲/Seek，EC2调参；KEY6单行/五行；KEY7返回；KEY8封面/MV；KEY9转场；KEY11背景；KEY12播完策略。

## 8. 被追问不会时
