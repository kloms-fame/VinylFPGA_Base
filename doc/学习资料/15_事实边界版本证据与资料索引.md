## 5. 高风险表述纠错表

| 避免使用 | 当前可用的准确表述 | 理由 |
|---|---|---|
| 真黑胶拾音/唱针启动音乐 | TF数字媒体，唱针门控转盘与唱片灯效 | 实际无音沟拾音链路 |
| 任意WAV/MP3直接播放 | 48kHz、16-bit、单声道裸PCM | 模块不解析通用WAV头/压缩音频 |
| FPGA实时解码MP4 | 预制RGB565帧读取与调度 | 无通用压缩视频解码 |
| FFT/32段对数频谱 | PCM幅度抽取、32组显示历史与峰值 | 没有频域变换 |
| 任意尺寸双线性自适应 | 固定尺寸封面、2:1缩小 | bilinear参考未接主链路 |
| 逐字卡拉OK | 逐句定位、高亮、上滚，单句/五行 | 非逐字染色 |
| 实时高斯模糊背景 | 离线预制模糊图，运行时读取缓存 | 算法发生位置不同 |
| Cover Flow/Mode7/2.5D | 当前实际封面浏览和播放窗口 | 未见这些算法主链路依据 |
| 百叶窗/完整双帧交叉混合 | 直切、方向擦入、经黑场淡出淡入 | 当前单路图像转场 |
| 所有OSD半透明淡出 | 参数菜单按实际面板与隐藏策略显示 | 旧稿描述不能替代代码 |
| 纳秒级强同步 | 以实际消费样本建立统一媒体位置 | 无端到端误差测量 |
| 完全零卡顿/任意慢卡无影响 | 有限缓存、优先级、欠载与错误处理 | 有限容量不能抵消持续不足 |
| 上电0.5秒/瞬时启动 | 启动时长需绑定实际测量 | BOOT参数不是完整启动实测 |
| 息屏大幅低功耗 | 像素消隐、音频继续 | 无整机功耗对照 |
| 全部底层IP从零手写 | 明确厂家IP与自编业务集成范围 | 贡献归属必须准确 |
| UART实时打印所有事件 | 当前生产uart_tx置高、静默 | 顶层端口注释过时 |
| 当前六帧MV缓存 | 当前可见主链路三bank | 历史候选不能套用 |
| 本次已完成所有硬件验证 | 本次完成资料和源码分析及文档核验 | 未执行板测或新构建 |

## 6. 文档冲突如何裁决

### 赛题PDF与PPT

保留正式指南“可选扩展”和PPT“至少一项”的差异。当前准备重点是稳定展示已完成的扩展；现场以赛事当前正式解释为准，不自行宣布某资料无效。

### 教程与当前实现

教程中的三PLL、首簇目录遍历、独立音频时钟、某套rtl目录、未实现对比度等，属于其例程或时间点。当前源码与工程连接决定本项目事实，08已逐讲说明。

### 参数表、控件表与代码

旧产品交互中的KEY6逐字、KEY9百叶窗、播放方向键快进/歌词翻页、红外音量方向与预留保存键等存在历史不一致。以当前`ui_event_bridge/ui_command_router/play_ctrl`和实板核对为准，不修改旧文件来掩盖演变。

### 歌词行数

当前多曲ROM为128/72/22/61，共283行；`lrc_geom.vh`中9行属于另一历史资产路径，不能据此说当前只有9行。每曲行数、每行16字形与18-bit毫秒字段等限制要看实际消费模块。

### 手册中的Flash单位

W25Q64为64Mbit/8MiB，具体配置Flash容量描述在资料中存在矛盾。引用功能与器件料号，实际容量以芯片和数据手册核对。不要把MB与Mbit差8倍的数字直接搬上答辩页。
