# 阶段一：播放页 UI 优化人工验收

## 本阶段改动

- 进度条覆盖封面/MV 的 320px 宽度，坐标 X=16..335、Y=314..317；已播放段为 `#D4AF37`，未播放段只在 Y=315 绘制 `#282830` 细线。
- `progress_fill` 扩展到 9 位，按 `elapsed / total` 计算 0..320；使用 41 位分子和逐位除法，在像素扫描路径之外更新。
- 移除播放页两块面板和边框。歌词按字形像素色键叠加，活动行金色 `#FFD700`，其余行暗灰 `#606068`。
- 歌名与时间并排在 Y=324..339；歌名 X=16..223，时间 X=232..335。歌手在 Y=344..359。时间沿用现有字库做半宽采样，没有增加字体 ROM。
- DE 消隐期间 RGB 输出黑色。RGB、DE、VS、X 沿用单拍对齐。

## 烧录前检查

SynthPilot 综合快照为 `prj/resource_opt_verified_20261005/stage1_ui_clean_r2`；原生布局布线与 bit 生成快照为 `prj/resource_opt_verified_20261005/stage1_ui_clean_release`。**任务未显示完成前不要烧录**。

1. 查看 `release_driver.log`，确认末尾出现 `BITGEN_COMPLETE`。
2. 确认在 `stage1_ui_clean_release` 同目录存在 `VinylFPGA_optimized.bit` 和 `bitstream.sha256`。
3. 确认 `native_build.log` 含 `VERIFIED_ROUND_COMPLETE`，并且 `final.qor` 的 Setup/Hold WNS、TNS 均通过；`final.constraints` 的 no-clock、invalid-constraint、combinational-loop 计数为 0。
4. 若日志出现 `BUILD_FAILED`、`BITGEN_FAILED`、`ERROR` 或 `FATAL`，先停止，不要使用旧 bit 代替本轮固件。

## 准备开发板和 SD 卡

1. 用 `doc/资源/sd卡/write_card.bat` 写入 `card_S6.img`：在菜单选择 **6**。写卡工具会清空目标卡；先确认它要写入的确实是开发板 TF 卡（脚本当前使用 E:），完成后安全弹出。
2. 该镜像的 Track 1 同时有 PCM 和 30 秒 MV；Track 2–4 共用 `AUDIO.PCM`，不带 MV。它适合检查 MV/封面区与播放页布局，但不代表四首独立音频素材。
3. 连接开发板电源、HDMI、J2 扩展板和 TF 卡。按板卡当前稳定基线使用的拨码设置启动。
4. 在 Tang Dynasty 下载工具选择 EG4S20BG256，加载上面确认过的 `VinylFPGA_optimized.bit`，先做 JTAG/SRAM 下载。不要在本阶段自动写 Flash。

## 人工验收步骤

| 项目 | 操作 | 通过标准 |
|---|---|---|
| 冷启动 | SRAM 下载后复位/重新上电，等待启动 Logo | HDMI 正常锁定，Logo 后进入浏览页，无黑屏或明显花屏 |
| 浏览与进入播放 | 用 EC1 旋转浏览封面，按 EC1 确认进入播放页 | 四张封面仍可浏览；Track 1 能进入播放页 |
| 面板移除 | 观察播放页歌词区域和曲目信息区域 | 没有矩形歌词卡片/外框；字形外的像素保持页面原有暗色背景 |
| 歌词颜色 | 播放 Track 1，观察五行歌词滚动和当前行 | 当前行金色，其他行暗灰；字形清楚，无背景矩形、乱码或行间撕裂 |
| 进度条起点 | 刚开始播放时观察进度条左端 | 左端从 X=16 开始，已播放段接近 0；未播放轨道只有中间一条暗灰细线 |
| 进度条中点 | 播放至约一半，或使用播放中 EC1 Seek 接近一半 | 金色段约到 X=175；轨道总长 320px，与 MV/封面左右边缘对齐 |
| 进度条终点 | 播放到 PCM 结束；必要时用 Seek 到末尾 | 金色段到 X=335，不能在 255px 回绕或留下尾端空白 |
| 时间与信息 | 观察歌名、歌手和时间行 | 歌名在左、`MM:SS / MM:SS` 在右且不重叠；时间不超过 X=335；歌手在下一行；时间字符可辨认 |
| 暂停/恢复 | 播放中按 EC1 暂停，再按一次恢复 | 暂停期间声音、进度和时间停止；恢复后继续推进，无位置跳变 |
| Seek | 播放中顺/逆时针转 EC1，再短按暂停/恢复 | 音频位置、进度、时间与现有歌词/MV Seek 行为保持同步 |
| MV/封面切换 | Track 1 播放超过 30 秒；再返回浏览并播放 Track 2 | Track 1 MV 结束后 PCM 可继续；Track 2 无 MV 时仍正常显示封面/播放页 |
| 返回浏览 | 按 KEY7 或 KEY11 | 返回中央封面浏览，系统不挂死，能再次进入播放 |
