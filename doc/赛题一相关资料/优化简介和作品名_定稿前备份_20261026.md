# 作品名称

**VinylFPGA——唱片主题互动音视频播放器**

# 一句话定位

面向家庭桌面娱乐与校园、文化空间固定内容展示，以本地媒体播放、音画状态联动和唱片式实体交互为核心的 FPGA 互动音视频播放器。

# 作品简介：推荐提交版

本作品基于安路 EG4S20BG256 FPGA，面向家庭桌面娱乐及校园、文化空间的固定主题内容展示，设计并实现了一套唱片主题互动音视频播放器。系统以 SD 卡本地资源为媒体来源，在 FPGA 中实现并集成 FAT32 资源读取、BMP 图像解析、SDRAM 缓存管理、PCM 音频播放及 HDMI 音视频输出，运行时无需外部处理器辅助播放与控制。

作品以实际消费的音频样本构建统一播放时基，联动组织歌词、播放进度与 MV 帧调度；通过缓存、跨时钟域握手及帧边界提交，协调媒体读取、画面合成和实体控制。播放界面叠加呈现 MV、曲目信息、进度条与 PCM 幅度波形，歌词支持逐句高亮、向上滚动及单行、五行显示切换；封面支持手动浏览、自动轮播和左右擦入、淡出淡入等转场效果。

系统配备交互扩展板、唱片主题扩展板及红外遥控，支持选曲、播放暂停、进度跳转与息屏听音。OSD 菜单实时显示音量、亮度、对比度、轮播间隔及灯带亮度，五项设置可保存至独立 SPI Flash，并在重新上电后恢复。唱针联动实体转盘与唱片灯效，将本地数字媒体播放融入可触摸的唱片式交互体验。

作品围绕赛题的媒体播放主链路，重点完成多图层字幕、图片转场、实时调参与信息叠加、音频可视化等扩展设计，将 FPGA 并行处理、实时控制与多源信息融合能力融入完整的产品体验。

# 精简版：用于字数受限的表单

VinylFPGA 是一套基于安路 EG4S20BG256 FPGA 的唱片主题互动音视频播放器，面向家庭桌面娱乐与校园、文化空间的固定内容展示。系统读取 SD 卡本地媒体，经 SDRAM 缓存和 HDMI 输出音乐与画面，以统一播放时基联动歌词、进度与 MV，并实现封面轮播转场、歌词高亮滚动及 PCM 幅度波形叠加。用户可通过旋钮、按键和红外遥控完成播放控制，借助 OSD 调节音量、画面、轮播及灯效参数，并将设置保存至独立 Flash。唱针联动转盘与唱片灯效，形成融合媒体展示、实时控制与实体交互的 FPGA 产品体验。
