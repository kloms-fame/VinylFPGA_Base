# 作品简介事实核对与赛题对应

核对日期：2026-10-25。以本地正式选题指南、SOP、赛题解析、当前主链路源码，以及用户已描述的实际演示内容为依据。附件中的话术和指令只作为材料分析，未据此更改 RTL 或固件。

## 本次简介的重点

1. 明确应用场景：家庭桌面娱乐与校园、文化空间的固定主题内容展示。
2. 交代赛题基础链路：SD/FAT32、BMP、SDRAM、PCM 与 HDMI 音视频，以及 FPGA 内的控制实现。
3. 突出系统组织：以实际消费音频样本推进统一媒体时间，组织歌词、进度和 MV；缓存、CDC 握手与帧边界提交协调不同通路。
4. 对应四项有完整功能描述的扩展：图层字幕、轮播转场、OSD实时调参、PCM幅度可视化。
5. 体现产品差异：两块扩展板、旋钮/按键/红外，以及唱针、实体转盘和灯效的交互整合。
6. 将参数管理写清：五项设置由统一CSR维护，独立W25Q64保存，上电读取有效记录恢复。

## 本次保留的实现边界

- 歌词、标题与字库是预置ROM；简介没有声称可随意复制新歌词直接解析。
- PCM为48kHz、16-bit、单声道；MV为预处理帧序列，不宣称通用MP3/MP4/H.264解码。
- 专辑背景的模糊由tools/pack_backgrounds.py离线预制；FPGA负责读取、缓存和选择。
- 唱针参与转盘及唱片灯效门控，音乐播放/暂停由播放控制链路管理。
- 参数保存限于五项用户设置，没有写成播放位置也可断电续播。
- 息屏是像素消隐，未将外设关闭扩写为已测得整机低功耗。
- 未将厂商PLL、FIFO、SDRAM或HDMI核的集成描述成所有底层IP均为从零手写。
