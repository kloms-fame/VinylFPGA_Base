# 作品名称

**VinylFPGA——唱片主题互动音视频播放器**

# 一句话定位

面向家庭桌面娱乐与校园、文化空间固定主题展示，将离线媒体播放、音画联动和唱片式实体交互融为一体的 FPGA 互动音视频播放器。

# 作品简介｜最终提交版

VinylFPGA 是一套基于安路 EG4S20 FPGA 的唱片主题互动音视频播放器，面向家庭桌面娱乐与校园、文化空间的固定主题内容展示。作品以离线播放预置媒体为基础，将音乐、歌词、MV、音频波形与实体唱片交互融为一体，让本地数字媒体兼具视听展示与动手操作的体验。

系统在 FPGA 中实现并集成本地资源读取、BMP 图像解析、SDRAM 缓存管理、PCM 音频播放及 HDMI 音视频输出，播放与控制无需额外处理器参与。以实际消费的音频样本计数建立统一播放时基，协调歌词推进、进度显示与 MV 帧调度；通过模块化设计、缓存管理、跨时钟域握手及帧边界更新，组织媒体读取、画面合成与交互控制的并行协作。

围绕赛题的多媒体扩展要求，播放界面叠加呈现 MV、曲目信息、播放进度与 PCM 幅度波形；歌词支持逐句高亮、向上滚动及单行、五行显示切换。封面支持手动浏览、自动轮播、左右方向切换与淡出淡入转场，并可按固定比例缩小至播放窗口，实现图片、文字与动态内容的组合展示。

实时调参与 OSD 信息叠加是作品的重点设计。用户通过旋转编码器调整音量、亮度、对比度、轮播间隔和灯带亮度，屏幕同步显示参数名称与当前数值。五项设置可保存至独立 SPI Flash，并在重新上电后恢复；存储采用双记录交替写入、CRC 校验与回读确认，为参数保存提供完整性检查。

作品配备交互扩展板、唱片主题扩展板及红外遥控，支持选曲、播放暂停、进度跳转、息屏听音，以及播完暂停、单曲循环和自动下一首三种策略。播放过程中，唱针可控制实体转盘与唱片灯效，形成具有辨识度的操作反馈。作品将 FPGA 音视频处理、实时参数控制与唱片式实体体验整合于同一系统，体现赛题所强调的并行处理、音画联动与多源信息融合。
