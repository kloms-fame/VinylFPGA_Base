## 1. 教程内容与本工程差异

第十五讲《缩略图交互选择》是练习课。教程明确说明完赛工程没有
`thumbnail_controller.v`，练习答案负责管理：

- `view_mode`：0 = 全屏，1 = 缩略图；
- `focus_index`：2x2 缩略图焦点 0~3；
- `active_index`：确认选中的图片索引；
- `transition_req`：在帧边界产生一次转场请求；
- `image_complete[focus_index]`：未加载完成的图片不能确认。

教程假设完赛工程存在 `media_policy.v` 和
`media_player_control.v`。当前 VinylFPGA 工程没有这两个文件，也没有
`pending_index` 快速提交接口。因此本工程没有为了“形式一致”再造一套
播放器框架，而是：

1. 按教程参考答案新增 `thumbnail_controller`；
2. 复用第十三讲已有的 `thumbnail_layout` 和缩略图取像链路；
3. 在 `sd_card_bmp` 上增加一个默认无效的快速选图端口；
4. 复用已有 `video_fade_transition`，仍在淡出完成的黑场边界切 bank；
5. 不修改 SD/FAT32 扫描、SDRAM、HDMI、PLL、FIFO 和视频时序。

## 2. 两键映射

本工程物理上只有 KEY1、KEY2。第十四讲的组合键参数菜单仍然位于按键链最前级，
第十五讲只在菜单控制器输出之后接管缩略图相关短/长按。

| 当前模式 | 按键 | 行为 |
|---|---|---|
| 全屏 | KEY1 短按 | 下一张，保留原转场 |
| 全屏 | KEY1 长按 1s | 进入缩略图 |
| 全屏 | KEY2 短按 | 自动轮播开关，保留原行为 |
| 全屏 | KEY2 长按 1s | 上一张，保留原行为 |
| 缩略图 | KEY1 短按 | 焦点右移，3 后回绕到 0 |
| 缩略图 | KEY1 长按 1s | 退出缩略图，不切图 |
| 缩略图 | KEY2 短按 | 焦点左移，0 后回绕到 3 |
| 缩略图 | KEY2 长按 1s | 确认当前焦点并返回全屏 |
| 任意 | KEY1 + KEY2 同时长按 | 进入/退出第十四讲参数菜单 |

缩略图模式下，KEY2 会在整个按压期间锁定并屏蔽 `sd_card_bmp` 的原 KEY2
路径，直到确认键真正松开，避免确认后又被解释成“上一张”。

## 3. 关键代码

### 3.1 `src/io/thumbnail_controller.v`

按教程 3.2.2 参考答案逐条实现：

```verilog
if (key_mode) begin
    view_mode <= ~view_mode;
    trans_pend <= 1'b1;
end

if (view_mode && key_right)
    focus_index <= (focus_index == 2'd3) ? 2'd0 : focus_index + 1'b1;

if (view_mode && key_left)
    focus_index <= (focus_index == 2'd0) ? 2'd3 : focus_index - 1'b1;

if (key_confirm && image_complete[focus_index]) begin
    active_index <= focus_index;
    view_mode    <= 1'b0;
    trans_pend   <= 1'b1;
end

if (frame_start && trans_pend) begin
    transition_req <= 1'b1;
    trans_pend     <= 1'b0;
end
```

### 3.2 `src/SD/sd_card_bmp.v`

新增端口：

```verilog
input       select_req,
input [1:0] select_index,
output reg  select_ack
```

快速选择只在 `select_req=1` 时进入最高优先级仲裁。旧功能下该端口恒为 0，
因此下一张、上一张、自动轮播和预加载路径保持原优先级与行为。

`select_index` 指向的 bank 已经由 `image_complete` 保证加载完成时，直接更新
`img_idx/disp_buf_idx`，不重新读 TF 卡。若所选 bank 恰好就是当前 bank，
`state_code` 不会变化，此时复用已有 `switch_abort_toggle` 释放转场状态机，
避免画面一直停在黑场。

### 3.3 `src/top_tf_hdmi_audio.v`

顶层完成以下连接：

- `thumbnail_controller.focus_index -> thumbnail_view_reader.focus_index`；
- `thumbnail_controller.view_mode -> video 域 frame_start 整帧提交`；
- KEY1 短按在全屏走下一张，在缩略图走焦点右移；
- KEY2 短按在缩略图走焦点左移；
- KEY2 长按在缩略图走确认；
- 确认后的 `transition_req` 在帧边界触发一次 `video_fade_transition`；
- 淡出完成时用 `select_req/select_index` 切到目标 bank；
- 切 bank 完成后复用原有 `index_commit` 淡入。

新增选图请求使用“保持请求直到 `select_ack`”的握手。若后台预加载暂时占用
加载器，请求不会因为丢失一个单拍脉冲而失效。

1. 全屏长按 KEY1，确认切到 2x2 缩略图且焦点框在图片 1；
2. 缩略图短按 KEY1，确认焦点右移并循环；
3. 缩略图短按 KEY2，确认焦点左移并循环；
4. 焦移到已加载图片后长按 KEY2，确认真接全屏显示目标图片；
5. 对未加载图片按确认，确认画面无响应；
6. 再检查全屏 KEY1 下一张、KEY2 短按自动轮播、KEY2 长按上一张和
   KEY1+KEY2 参数菜单未受影响。
