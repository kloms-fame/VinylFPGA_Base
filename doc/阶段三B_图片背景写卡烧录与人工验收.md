## 4. 烧录与初次观察

1. 开发板断电插入新卡，连接HDMI、音频及下载线。
2. 等本轮出现 `BITGEN_COMPLETE`，TD中确认目标EG4S20BG256，按此前方式JTAG/SRAM下载本轮bit；先不写配置Flash。
3. 启动仍经过原封面预加载、开机页及选歌页。背景在封面预加载结束后低优先级加载，不阻止音频开始。
4. 选歌进入播放。默认仍是柔和灰，不需要等待图片加载。
5. KEY11按下沿每次推进一次；四种模式如下。

| 模式 | 效果与未就绪行为 |
|---:|---|
| 0 | 中等灰、轻微渐变 |
| 1 | 当前歌曲封面模糊图；未准备好先灰底，完成后下一帧显示 |
| 2 | 通用低饱和蓝紫光晕；首次加载未就绪先灰底 |
| 3 | 近黑 |

第四次KEY11回到模式0。切歌、KEY7返回再进入均记忆所选模式；视频复位回灰。KEY11在浏览页不推进模式。

### A. 四种效果与显示边界

- [ ] KEY11四模式完整循环，模式1/2确实显示图片而非一直灰底；先等首次加载完成再判断。
- [ ] 模式1在四首歌之间呈现不同封面衍生色彩，模式2始终为同一张蓝紫图。
- [ ] 封面/MV窗口仍清晰；检查x=16/335、y=48/287周边无错位、彩点或宽条带。
- [ ] 标题、歌手无重复尾字，时长数字正常，已播放白色/未播放浅灰；歌词当前行金色、波形正常。

### B. 切歌、在途加载和记忆

- [ ] 模式1切到新歌时立即开始原音频，先灰底；背景完成后整帧恢复模式1，过程中不显示另一首歌的图。

- [ ] 模式1加载期间按KEY11切模式0/2/3，再切回1，均能正常显示或灰底等待。
- [ ] 模式2跨歌不重新变化；模式3跨歌/暂停/重播/返回重进仍近黑。
- [ ] KEY7能停止并返回选歌，选歌页仍显示原中央大图；刚返回的首帧也没有背景覆盖选歌封面。
