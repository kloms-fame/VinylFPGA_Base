
## 1 项目定位与差异化亮点

### 1.1 项目定位

实现一台**纯硬件 HDMI 多媒体播放器**，开机显示封面墙；支持编码器 / 按键 / 红外遥控操作；支持切歌、转场特效；播放时可输出 MV 视频或者黑胶旋转动画；配套硬件逐字变色卡拉 OK 歌词、音频频谱可视化；完整参数 OSD 调节；全部音画同步由硬件 48kHz 采样计数器统一驱动，从根源避免音画漂移。


### 1.2 核心差异化创新点

1. **黑胶旋转渲染**：MV模式播放视频，黑胶模式贴一张黑胶唱片图片旋转
2. **实时歌词**：显示当前播放歌词，三行歌词显示
3. **MV 流式播放**：采用 RGB565 BMP 帧序列方案，三帧环形缓冲掩盖 SD 读取抖动。
4. **统一 48kHz 全局时基**：MV 换帧、歌词比对、频谱刷新、播放进度全部挂载同一采样计数器，硬件原生音画同步。
5. **专用 J2 人机交互扩展板**：双 EC11 编码器 + 12 按键 + 红外 + 拨码全局使能开关；**设计上不再做拔掉扩展板后的播放器业务交互兜底逻辑**，母板外设仅用于系统状态监控与系统级控制；拔掉扩展板系统不崩溃，仅播放器业务交互不可用。

> 职责划分：**J2 扩展板承担全部用户人机交互输入与交互反馈输出；HX4S20 母板外设仅负责系统状态显示、系统级控制、告警与提示音效，不承担播放器业务交互，无兜底冗余逻辑。拔掉J2扩展板系统不会崩溃，播放器业务交互不可用，保留母板系统控制。**

### 3.3 链路说明

1. **显示输出**：HDMI‑B 输出 640×480@60Hz 视频（或者更高）；使用便携显示器，规避部分高清显示器不支持低分辨率。
2. **音频输出**：HDMI 同缆输出 48kHz 音频，搭配 HDMI 音频提取器输出给音箱；预留 I2S DAC 小板作为故障兜底方案。
3. **供电**：整机 Type‑C 5V≥2A 电源，满足 WS2812 峰值电流需求。

# 3.4 按键 & 编码器业务映射完整梳理

> 整体原则：
> 
> 1. **J2‑HMI 扩展板：承担播放器全部业务人机交互（播放、切歌、OSD 菜单、特效切换、灯效、歌词模式、红外遥控）**；
> 2. **HX4S20 母板（FPGA 开发板）：仅做系统级控制、调试、演示模式，不介入正常播放业务逻辑**；
> 3. 顶层状态分为：`BOOT开机态` / `BROWSE浏览选歌态` / `PLAY播放态`；
> 4. OSD 菜单属于界面叠加浮层，不属于顶层状态；蜂鸣器、LED、数码管作为反馈输出。

> 全自动演示模式 (SW4 拨上)：系统自动完成：开机动画→循环切歌、转场、播放、暂停、切换 MV / 黑胶、切换歌词效果，无人干预，适合答辩现场自动演示。

## 3.4.3 反馈外设行为映射（J2扩展板 + HX4S20 母板）

|反馈器件|归属硬件|行为逻辑|
|---|---|---|
|扩展板 LED1‑LED4|J2扩展板|LED1：红外接收指示；LED2：按键 / 编码器操作瞬时反馈；LED3：系统心跳；LED4：播放 / 文件告警；受 DIP4 拨码硬件使能控制|
|WS2812 ×8 彩灯|J2 扩展板|音频律动 / 播放进度条；受 DIP1 拨码硬件使能；RTL 限制最大亮度 30%|
|8 位共阳数码管|HX4S20 母板|动态扫描；显示优先级：错误码 Err‑xx > 参数临时值 > 播放时长 > 歌曲序号；受 SW1 拨码控制开关|
|板载独立 LED1‑4|HX4S20 母板|LED1：500ms 系统心跳翻转；LED2：TF‑SD 读写闪烁；LED3：播放常亮 / 暂停慢闪烁；LED4：TF 异常告警常亮；受 SW2 拨码控制开关|
|蜂鸣器|HX4S20 母板|开机音效；按键 / 编码器 / 红外确认短促音；参数越界告警音；音量跟随主音量；受硬件 SW5 物理开关控制|

## 3.4.4 关键设计约束总结

1. **业务隔离原则**：播放器所有正常使用的业务交互（切歌、播放暂停、OSD 菜单、特效切换、灯效歌词）全部来自**J2 扩展板输入**；母板按键拨码只用于**系统维护、调试、全自动演示**，不作为正常播放器操作入口。
2. J2 扩展板 DIP1‑DIP4：**硬件模块使能开关，只读，只关闭外设硬件，不会改变软件业务模式**。
3. 母板 SW5、SW6 属于纯硬件通路开关，**不接入 FPGA 逻辑，必须人工拨到对应档位**：SW5 拨下蜂鸣器才能发声；SW6 固定拨数码管档位，本项目不使用双色 LED。
4. 母板 SW4 全自动演示模式：答辩现场使用；正常使用状态下 SW4 拨下，关闭自动演示。
5. KEY5 长按判定：必须≥1.2s 才触发返回浏览态；短按执行播放 / 暂停；时间阈值采用 RTL `parameter`参数，便于仿真调试修改。
6. EC11 编码器：使用**格雷码状态机跳转正交解码**，**禁止简单 2ms 稳定消抖，防止高速旋转丢步**。
7. 全部按键输入模块使用`parameter`定义消抖时间，禁止写死硬编码常数。
8. 所有来自J2扩展板的FPGA输入引脚内部开启弱上拉；扩展板拔掉时输入稳定高电平，杜绝浮空X态传播，防止状态机死机。

### 3.5 容错边界行为（评测考察点）

|故障场景|系统行为|
|---|---|
|TF 卡未插入 / 挂载失败|浏览态 UI 提示 TF 异常；数码管输出 Err‑01；每 30s 自动重试挂载；开机 Logo 依旧正常显示（来自 QSPI）|
|曲库为空|UI 提示曲库为空，不崩溃，等待更换 TF 卡重试|
|索引指向的媒体文件缺失|该曲目封面置灰；确认按键无效，Toast 提示文件缺失；不会进入播放状态|
|SD 读取超时|重试最多 3 次；失败自动跳下一首；连续多首失败触发 TF 异常逻辑|
|播放时拔掉 TF 卡|音频平滑淡出静音，界面不崩溃；插回后自动尝试重新挂载|
|MV 帧缓冲欠载|冻结当前画面等待数据，不黑屏撕裂；数据恢复继续播放|
|模块局部故障|**降级运行，关闭对应图层，整机不崩溃**|
|参数调节到达边界|蜂鸣器告警音，参数钳位，不越界|
|J2扩展板拔掉/IO浮空|J2全部输入无效，播放器交互功能不可用；系统不崩溃，母板系统级控制功能正常|
|QSPI读取开机Logo失败|跳过Logo画面，直接进入Splash开机动画，不阻塞系统启动流程|

## 4 产品功能规格与业务交互逻辑

### 4.1 顶层三态有限状态机（冻结）

```
上电 → STATE_BOOT（开机启动态） → STATE_BROWSE（选歌浏览态） ◄──┐
                                          │确认键                │
                                          └───▶ STATE_PLAY（播放态）┘
```

> OSD 菜单不属于顶层状态机，只在当前状态画面上叠加半透明浮层，避免状态机爆炸。

1. **STATE_BOOT 开机态**
    - ① QSPI 读取 Logo 帧，上电 0.5s 内输出全屏 Logo 画面；并行执行 PLL、SDRAM 初始化。QSPI Logo读取失败直接跳过Logo，进入Splash，不阻塞启动。
    - ② Splash 开机动画，读取 TF 卡`/boot`目录帧序列循环播放；**任意按键、编码器、红外可以立刻跳过动画**；TF不存在/boot目录则直接关闭Splash，跳转浏览态。
    - 后台并行任务：FAT32 挂载、歌曲索引`song_index_db`解析、字模预热。
    - 挂载失败依旧跳转浏览态，显示错误提示，不会死等。
2. **STATE_BROWSE 浏览选歌态（主门面界面，640×480）**
    - UI 布局：顶部信息栏；左右降灰缩略图；居中 240×240 全彩大封面；曲名歌手序号文字；底部特效指示条。
    - 核心逻辑：**封面预取机制**，后台异步预取当前索引 ±1 封面存入 SDRAM 双缓冲，实现切歌 0 延迟；30s 无操作自动轮播；快速连按直接中断正在播放的转场特效。
3. **STATE_PLAY 播放态**
    - UI 布局：顶部曲目与时长；左侧 320×240 播放窗口（MV 或者黑胶旋转）；右侧 FFT 频谱、三行歌词；底部播放进度条。
    - 业务逻辑：
        - 读取索引`has_mv`标志位，有 MV 播放帧序列；无 MV 渲染黑胶旋转画面；KEY9 可以强制手动切换两种模式。
        - 播放暂停：MV 冻结画面；黑胶停止旋转，唱针抬起摆动动画。恢复播放从断点继续。
        - 歌曲播放结束，行为由 KEY7 配置：自动下一首 / 返回浏览界面。

### 4.2 图层合成顺序（五层，冻结，L0 底层→L4 顶层）

`L0背景层 → L1转场特效层 → L2歌词层 → L3频谱可视化层 → L4 OSD菜单/UI浮层`

> mixer_osd 模块完成五层 Alpha 混合输出最终像素流给 HDMI 发送模块。

### 4.3 OSD 菜单系统规格

- 两级菜单，纯 FSM 实现，**无软核**；只叠加在当前画面之上，不切换画面。
- 一级调音台菜单：音量、亮度、对比度、人声消除、转场风格。
- 二级设置菜单：自动轮播开关、歌曲结束行为、数码管显示项、恢复默认、版本信息。
- 交互：EC2 唤醒菜单；3s 无操作，0.5s 线性 Alpha 淡出；参数修改实时写入`param_csr`寄存器堆，数码管同步显示参数；本版本**不做参数掉电保存，上电读取J2扩展板DIP拨码 + 母板SW1‑SW4系统拨码 + 默认参数**。

### 4.4 反馈外设规格（数码管、LED、蜂鸣器、WS2812）

> 反馈外设完整行为映射详见 **3.4.3反馈外设行为映射（J2扩展板 + HX4S20母板）**。 关键约束：
> 
> 1. 8位数码管（母板）：动态扫描；显示优先级：错误码 Err‑xx > 参数临时值 > 播放时长 > 歌曲序号。
> 2. J2扩展板LED、WS2812受DIP硬件全局使能开关控制。
> 3. 母板蜂鸣器受硬件SW5物理开关控制。
