## 0. 结论摘要

S7-01 以「不破坏现有主链路功能与综合通过率」为前提完成：

1. **S7-01A 边界审计**：新增遥测未新增任何 IO、任何时钟、任何约束；全部走已有 `uart_tx`（D12）与已约束的 50 MHz `clk` 域。
2. **S7-01B 被动遥测**：新增 `health_monitor`（clk 域）汇聚四路饱和计数、sticky 最近错误码、周期 `STAT` 快照与错误变化 `ERR` 上报，经 `exp_echo_reporter` 在既有串口上扩展输出。
3. **资源与时序**：LUT 15102→15500（+398，77.05%→79.08%），REG 9691→9905（+214），BRAM 46 不变、DSP 16 不变；Setup WNS +110 ps、Hold WNS +3 ps，Setup/Hold TNS 均为 0，Slow/Fast 两角均通过。
4. **验证**：新增 3 个定向仿真台全部通过；S6 全量回归（含 WAV 基线逐拍等价对比）全部通过；原生 TD 全流程综合通过。

SD「超时/重试」与「最大等待」两项因当前 SD 层无显式超时/重试寄存器，本阶段不伪造计数，明确列入 S7-02 待补项（见第 9 节）。

## 1. 目标与约束

本阶段目标（与 S7 规划 S7-01 一致）：让后续每次迭代能够解释「哪里错、何时错、是否影响音频」。具体分解为：

- S7-01A：对现有构建做零行为变化审计，复核 CDC、宽泛时序例外与外部 IO 时序适用性。
- S7-01B：增加饱和计数与 sticky 状态：音频 underrun、视频失败、事件溢出、最近错误、缓冲低水位、运行版本。

实施约束：

- 不破坏现有主链路功能与综合通过率；
- 遵循已有命名、时钟域（clk=50 MHz / sd_card_clk=100 MHz / ext_mem_clk=125 MHz / video_clk=25 MHz / hdmi_5x_clk=125 MHz）与复位约定；
- 改动范围最小化，遥测为**被动旁路**，不反压、不阻塞音视频主链路，不改任何既有状态机；
- 单一 UART 拥有者：扩展 `exp_echo_reporter`，不做第二个 UART。

### 2.2 关键差异说明

**`health_monitor.v`（新增，clk 域）**

- 输入均为顶层已同步到 clk 域的信号，模块内不再二次跨域。
- 四路 16 位饱和计数（到达 `16'hFFFF` 后停住，不归零）：
  - `cnt_underrun`：音频欠载单拍脉冲累加；
  - `cnt_buffer_low`：仅「流式播放中」且低水位电平出现上升沿时累加，避免上电空缓冲与播放结束排空被误判；
  - `cnt_video_fail`：MV 失败电平上升沿累加；
  - `cnt_ev_overflow`：事件队列溢出脉冲累加。
- sticky `err_code`：仅在出现新的非零错误码时锁存并请求上报（相同码不重复、零码不覆盖）。
- 周期 `stat_req` 脉冲（默认 2000 ms）与 `err_req` 脉冲，交给 reporter 拼装。
- `fw_version` 参数透出（默认 `32'h0701_0001`，大版本/子阶段/构建号），单一事实来源。

**`wav_stream_player.v`（修改）**

- 新增 `output reg underrun_pulse`（video_clk 域）。
- 欠载判定条件：`sample_tick && sample_ready && !buffer_available && stream_active_rd && (wstate_sync2 != WS_END)`。
- 门控 `sample_counter != 0`：播放起始阶段缓冲尚未充满不计为欠载，避免每次起播误报一次。
- 该新增输出不影响既有 `sample_out/sample_valid/sample_counter/stream_active/stream_end/buffer_low` 的任何行为；WAV 基线逐拍等价回归已证实输出逐拍一致。

**`exp_echo_reporter.v`（修改）**

- 新增 7 路遥测输入（`stat_req/err_req/err_code/stat_underrun/stat_buffer_low/stat_video_fail/stat_ev_overflow/fw_version`）。
- 新增 `ST_STAT`/`ST_ERR` 两态与 `fmt_stat`/`fmt_err` 拼装 task；`stat_pending`/`err_pending` 锁存单拍请求。
- 优先级：错误 `ERR` 高于普通事件，周期 `STAT` 仅填充空闲，不抢占更高优先级。
- 原 S1/S2 事件行、BOOT/INFO/VERIFY 逻辑不变。

**`expansion_integration.v`（修改）**

- 新增 6 路遥测输入端口；例化 `health_monitor`；把其 `stat_req/err_req/err_code/cnt_*` 接到 reporter，`ev_overflow` 接 reporter 的 `ovf_pulse`。

**`top_tf_hdmi_audio.v`（修改）**

- `include "io/health_monitor.v"`。
- 新增 `wav_underrun_pulse` wire，接 `u_wav_stream_player.underrun_pulse`。
- 新增跨域同步（详见第 6 节 CDC 审计表）：
  - `underrun_pulse`（video_clk）→ toggle 翻转 → 2FF → 边沿还原为 `underrun_pulse_clk`；
  - `wav_buffer_low`/`wav_stream_active`（video_clk）/`mv_failed`（sd_card_clk）→ 2FF 电平同步；
  - `osd_error_code`（8 bit）+ `osd_error_toggle`（sd_card_clk）→ 数据 2FF + toggle 边沿还原为 `osd_err_valid_clk/osd_err_code_clk`。
- 更新 `wav_stream_player` 与 `expansion_integration` 实例端口。

## 3. 事件编码格式

统一 UI 事件编码保持 S1 既有定义（`src/include/exp_event_defs.vh`，module 作用域 localparam，**不加 include 保护**，每模块各自包含一次）：

| `ev_code` | 名称 | `ev_arg[15:0]` | `ev_aux[15:0]` |
|---|---|---|---|
| `4'd0` | `EV_NONE` | — | — |
| `4'd1` | `EV_KEY_DOWN` | key_index (0..11) | 0 |
| `4'd2` | `EV_KEY_UP` | key_index (0..11) | 0 |
| `4'd3` | `EV_DIP_CHANGE` | `{12'b0, dip_level, dip_index[2:0]}` | 0 |
| `4'd4` | `EV_ENC_STEP` | enc_count | `{14'b0, enc_id, direction}` |
| `4'd5` | `EV_ENC_SW` | `{15'b0, pressed}` | `{15'b0, enc_id}` |
| `4'd6` | `EV_IR_FRAME` | ir_code[15:0] | ir_code[31:16] |
| `4'd7` | `EV_IR_REPEAT` | ir_code[15:0] | ir_code[31:16] |

约定：`enc_id` 0=EC1、1=EC2；`direction` 0=递增(+)、1=递减(-)；`pressed` 1=按下。NEC 帧布局 `{Addr[31:24], ~Addr[23:16], Cmd[15:8], ~Cmd[7:0]}`，命令字节取 `code[15:8]`，遥控按键区分用高 8 位地址 `code[31:24]`。

## 4. 串口输出格式（STAT / ERR）

沿用 J2 标定工程 115200 8N1（板载 USB 转 UART，TX=D12）。遥测只发 TX，继续兼容既有事件行，均为 ASCII + CRLF。

**周期遥测快照（默认每 2 秒一次，仅空闲填充）：**

```text
STAT UR=hhhh BL=hhhh VF=hhhh OV=hhhh ERR=hh VER=hhhhhhhh
```

字段（均为大写十六进制，无 `0x` 前缀）：

| 字段 | 含义 | 来源 |
|---|---|---|
| `UR=hhhh` | 音频欠载饱和计数 | `cnt_underrun` |
| `BL=hhhh` | 播放中缓冲低水位饱和计数 | `cnt_buffer_low` |
| `VF=hhhh` | MV 取帧失败饱和计数 | `cnt_video_fail` |
| `OV=hhhh` | 事件队列溢出饱和计数 | `cnt_ev_overflow` |
| `ERR=hh` | sticky 最近错误码 | `err_code` |
| `VER=hhhhhhhh` | 运行版本 | `fw_version`（默认 `07010001`） |

**错误变化上报（新非零错误码出现时）：**

```text
ERR hh
```

示例（`err_code=0x0A`、`fw_version=0x07010001`）：

```text
ERR 0A
STAT UR=0001 BL=0002 VF=0003 OV=0004 ERR=0A VER=07010001
```

## 5. J2 约束片段

S7-01 **未新增、未修改任何 IO 与约束**，遥测复用既有 `uart_tx`（D12），全部沿用 `constraints/pin.adc`。以下为 J2 相关既有约束片段（仅列出与本阶段遥测/诊断强相关部分，非改动）：

```text
set_pin_assignment { uart_tx }        { LOCATION = D12; IOSTANDARD = LVCMOS33; DRIVESTRENGTH = 8; PULLTYPE = NONE; }
set_pin_assignment { board_buzzer_n } { LOCATION = H11; IOSTANDARD = LVCMOS33; DRIVESTRENGTH = 8; PULLTYPE = NONE; }
```

J2 输入/输出完整引脚归属（`constraints/pin.adc`，均 LVCMOS33，本阶段未改动）：

- 编码器：`exp_enc1_a/b/sw_n = P4/N4/N3`，`exp_enc2_a/b/sw_n = M5/M3/M4`（PULLUP）。
- 按键 `exp_key_n[0..11] = N1,M2,M1,L1,H2,H1,G1,G3,L4,L5,J12,K11`（PULLUP）。
- 拨码 `exp_dip_n[0..5] = L3,J3,J4,H4,K14,L12`；其中 `exp_dip_n[0]`（DIP1，在场声明）为 **PULLDOWN**，其余 PULLUP。

## 6. CDC 与时序审计

### 6.1 本阶段新增 CDC

| 信号 | 源时钟域 | 目的时钟域 | 同步方式 |
|---|---|---|---|
| `wav_underrun_pulse`（单拍） | video_clk | clk | 脉冲→电平 toggle 翻转 → 2FF → 边沿还原 |
| `wav_buffer_low`（电平） | video_clk | clk | 2FF 同步 |
| `wav_stream_active`（电平） | video_clk | clk | 2FF 同步 |
| `mv_failed`（sticky 电平） | sd_card_clk | clk | 2FF 同步 |
| `osd_error_code`（8 bit 低频数据）+ `osd_error_toggle` | sd_card_clk | clk | 数据 2FF + toggle 边沿还原（数据稳定后按 toggle 采样） |

说明：

- 单拍脉冲用「电平翻转 + 边沿还原」避免直接 2FF 采样丢脉冲；
- 多 bit 低频数据用「数据 2FF + 握手 toggle」保证数据在采样时稳定；
- 电平类慢变状态直接 2FF，`health_monitor` 内部再做上升沿检测计数。

## 9. S7-02 待补项

以下为 S7-01B 规划中因当前 SD 层无显式寄存器而**未伪造**、明确后置到 S7-02 的遥测：

- **SD 超时/重试**：当前 `fat32_media_loader`/`mv_stream_player` 无显式超时与重试计数寄存器，需由 S7-02 `media_supervisor` 引入参数化期限与重试上限后，再挂接计数。
- **最大等待**：依赖上述超时语义，无独立信号可观测，随 S7-02 一并落地。

错误码表（Err-01 挂载失败 / 02 空库 / 03 索引/版本/CRC / 04 关键文件缺失 / 05 读超时 / 06 MV 描述/数据错误 / 07 歌词错误 / 08 配置 Flash 错误 / 09 输入队列溢出）由 S7-02 集中管理，本阶段的 `ERR hh` 仅透传 OSD 侧既有 `osd_error_code`，未重新定义错误码域。

## 10. 回退与兼容

新增遥测为纯增量旁路：将 `ECHO_ENABLE` 关为 0 或移除 `health_monitor` 接线即可回到 S7-00/S6 行为，主链路数据路径（音频/视频/存储/显示）逐拍不受影响。串口新增 `STAT`/`ERR` 行只发 TX，不影响既有 KEY/DIP/ENC/IR/BOOT/INFO/VERIFY 事件行的发送顺序与内容。
