## 0. 一张图看懂命名的 6 层对应关系

```
物理丝印功能      软件事件/编号      顶层端口(Verilog)      FPGA 引脚   开发板网络     J2 脚位
  (扩展板)   →   (串口打印)    →        (top.adc)       →  (EG4S20) →  (GPIOB_x)  →  (IDC40)

  例：上按键  →  KEY 04 DOWN  →  exp_key_n[3]      →     L1      →  GPIOB_13  →   J2.16
  例：左播控按 →  ENC1 SW DOWN →  exp_enc1_sw_n     →     N3      →  GPIOB_2   →   J2.3
  例：WS总控  →  DIP 6 1      →  exp_dip_n[5]      →     L12     →  GPIOB_29  →   J2.34
  例：遥控上一首→ IR BA45FF00  →  exp_ir_rx         →     K6      →  GPIOB_20  →   J2.23
```

**关键认知（两个层次，不要混淆）**

- **测试固件只认"编号"**：它不知道"歌词动效/切歌模式"这些名字，只上报 `KEY n`、`DIP n`、`ENC1/2`、`IR`。
- **"功能名"来自扩展板丝印 / 整机播放器定义**：本次靠你实机按一遍，把物理功能名和固件编号绑死，见第 3–6 节。
- 输入信号 `*_n` 均为**低有效**（板内上拉，动作时接地）；输出均为 3.3 V LVCMOS。

## 3. 旋转编码器（左/右播控）

每只旋转编码器占 **A、B 两相 + 一路按压 SW**，共 3 个 FPGA 引脚。固件对 A/B 做同步 + 1 ms 稳定采样 + 四相位判步（`quadrature_decoder.v`），带机械消抖。

| 编码器 | 物理位置 | A 相 | B 相 | 按压 SW |
|:---|:---|:---:|:---:|:---:|
| **ENC1** | **左播控旋转编码器** | J2.1 / P4 | J2.2 / N4 | J2.3 / N3（`*_sw_n` 低有效） |
| **ENC2** | **右播控旋转编码器** | J2.4 / M5 | J2.5 / M3 | J2.6 / M4（`*_sw_n` 低有效） |

**实测方向 / 动作 → 串口事件**

| 你的动作 | 串口打印 | 计数变化 |
|:---|:---|:---|
| 旋钮**左转（逆时针）** | `ENCx - <CNT>` | 16 位计数 **递减** |
| 旋钮**右转（顺时针）** | `ENCx + <CNT>` | 16 位计数 **递增** |
| **按下**旋钮 | `ENCx SW DOWN` | — |
| **松开**旋钮 | `ENCx SW UP` | — |

- `<CNT>` 为 **4 位十六进制、16 位有符号回绕**：`0000` 再减 1 变 `FFFF`（即 ‑1）。
- 查询命令 `ENC?` 回两行，例如 `ENC1 CNT FFFC A 1 B 1 SW 1`：`CNT` 当前计数、`A/B` 当前相电平、`SW` 按压状态（`1`=未按，`0`=按下）。
- 标定时 ENC1 上电初值为 `FFFC`（‑4，上电前旋钮被转过），ENC2 为 `0000`；初值不影响方向结论，整机用时可在初始化时清零。
- 实采证据（节选）：左播控左转 `ENC1 - FFFF/FFFE/…`、右转 `ENC1 + …/0000/0001…`、按压 `ENC1 SW DOWN/UP`；右播控 EC2 同构。

## 4. 12 个独立按键 KEY（方向键 5 + 功能键 7）

全部低有效（按下接地，板内上拉），经 8 ms（400_000 个 50 MHz 时钟）消抖后上报。串口编号 `KEY n`（`n` = Verilog 数组位 `exp_key_n[k]` 的 `k+1`，两位数显示）。

### 4.1 方向 / 确认键（5 个）

| 物理按键 | 串口编号 | 顶层端口 | FPGA 引脚 | J2 脚 |
|:---|:---:|:---|:---:|:---:|
| **上** | KEY 04 | `exp_key_n[3]` | L1 | 16 |
| **下** | KEY 05 | `exp_key_n[4]` | H2 | 17 |
| **左** | KEY 01 | `exp_key_n[0]` | N1 | 13 |
| **右** | KEY 03 | `exp_key_n[2]` | M1 | 15 |
| **中间确定** | KEY 02 | `exp_key_n[1]` | M2 | 14 |

> 注意：方向键的**物理布局（上/下/左/右/中）与编号 01–05 并不按位置顺序排列**，软件里请直接按端口/编号映射，不要想当然用编号推位置。

### 4.2 功能键（7 个）

| 物理按键（丝印功能） | 串口编号 | 顶层端口 | FPGA 引脚 | J2 脚 |
|:---|:---:|:---|:---:|:---:|
| **歌词动效** | KEY 06 | `exp_key_n[5]` | H1 | 18 |
| **切歌模式** | KEY 07 | `exp_key_n[6]` | G1 | 19 |
| **播控方式** | KEY 08 | `exp_key_n[7]` | G3 | 20 |
| **切歌动效** | KEY 09 | `exp_key_n[8]` | L4 | 21 |
| **WS 灯效**（原记录"WS等效"） | KEY 10 | `exp_key_n[9]` | L5 | 22 |
| **拓展1** | KEY 11 | `exp_key_n[10]` | J12 | 31 |
| **拓展2** | KEY 12 | `exp_key_n[11]` | K11 | 32 |

**事件格式**：按下 `KEY nn DOWN`、松开 `KEY nn UP`；主动查询 `KEY?` 回 `KEY 000000000000`，**12 位从左到右依次是 KEY12…KEY1，1=当前按住**（固件 `event_reporter.v` 按位 11→0、低有效取反打印）。

**实测按键顺序（与串口一一对应，已核对无误）**：
`04上 → 05下 → 01左 → 03右 → 02中 → 06歌词动效 → 07切歌模式 → 08播控方式 → 09切歌动效 → 10 WS灯效 → 11拓展1 → 12拓展2`。

## 5. 6 个拨码开关 DIP

| 拨码 | 丝印功能（整机功能位） | 顶层端口 | FPGA 引脚 | J2 脚 |
|:---:|:---|:---|:---:|:---:|
| **DIP1** | **拓展2** | `exp_dip_n[0]` | L3 | 7 |
| **DIP2** | **拓展1** | `exp_dip_n[1]` | J3 | 8 |
| **DIP3** | **指示灯** | `exp_dip_n[2]` | J4 | 9 |
| **DIP4** | **屏幕消隐** | `exp_dip_n[3]` | H4 | 10 |
| **DIP5** | **红外接收**（功能使能） | `exp_dip_n[4]` | K14 | 33 |
| **DIP6** | **WS 总控**（功能使能） | `exp_dip_n[5]` | L12 | 34 |

**实测电平语义（以串口为准）**

| 你的操作 | 串口打印 |
|:---|:---|
| 拨码**向上 = 打开/ON** | `DIP n 1` |
| 拨码**向下 = 关闭/OFF** | `DIP n 0` |

- 主动查询 `DIP?` 回 `DIP 111111`，**6 位从左到右依次是 DIP6…DIP1，1=上拨/打开**（本次空闲态 6 路全为 `1`）。
- 端口虽命名 `*_n` 且约束为上拉，但本板实测：**上拨读到高电平 1、下拨接地读到 0**，即"上拨位置不接地（释放上拉/接高）"。写软件时直接按"`DIP n 1` = 该功能打开"使用即可，无需再取反。
- DIP5「红外接收」、DIP6「WS 总控」是**整机应用层的功能使能开关**；它们本身是普通 FPGA 输入，与 J2.23 的红外接收头数据线、J2.28 的 WS2812 数据线不是同一条线。当前测试固件只上报 6 路原始电平，不执行使能逻辑。
- 实测拨码顺序：`DIP6 WS总控 → DIP5 红外接收 → DIP4 屏幕消隐 → DIP3 指示灯 → DIP2 拓展1 → DIP1 拓展2`，每路均先 `1` 后 `0`。

## 6. NEC 红外遥控

- **接收脚**：J2.23 / GPIOB_20 / **K6** / `exp_ir_rx`（`ir_nec_decoder.v`，50 MHz 解码 NEC 引导码 + 32 位数据 + 重复帧）。
- **事件格式**：收到新帧 `IR <32位HEX> CMD <命令字节>`；按住连发时后续只打印 `IR REPEAT`；查询 `IR?` 回最近一帧，无则 `IR NONE`。
- **帧结构（已对全部 15 键逐位校验，地址/命令反码全部合法）**：

```
| Addr(8) | ~Addr(8) | Cmd(8) | ~Cmd(8) |
   按键区分靠这一字节        本遥控恒为 FF 00
```

  本遥控器 **命令字节恒为 `FF`（`~Cmd=00`），靠"地址字节 Addr"区分按键**。整机解码应判 **高 8 位地址**，不要判 `CMD`。

### 6.1 遥控器 15 键码值表（实测）

| 遥控器按键 | 32 位完整帧 | 地址 Addr（用这个判键） | Cmd |
|:---|:---:|:---:|:---:|
| **上一首** | `BA45FF00` | `BA` | FF |
| **下一首** | `B946FF00` | `B9` | FF |
| **播放 / 暂停** | `B847FF00` | `B8` | FF |
| **音量＋** | `BB44FF00` | `BB` | FF |
| **音量－** | `BF40FF00` | `BF` | FF |
| **息屏** | `BC43FF00` | `BC` | FF |
| **进度＋** | `F807FF00` | `F8` | FF |
| **进度－** | `EA15FF00` | `EA` | FF |
| **重播** | `F609FF00` | `F6` | FF |
| **重启** | `E916FF00` | `E9` | FF |
| **上（方向）** | `E718FF00` | `E7` | FF |
| **下（方向）** | `AD52FF00` | `AD` | FF |
| **左（方向）** | `F708FF00` | `F7` | FF |
| **右（方向）** | `A55AFF00` | `A5` | FF |
| **中间确认（OK）** | `E31CFF00` | `E3` | FF |

> 长按任意键，首帧后每约 110 ms 出一帧 `IR REPEAT`，可用于"连续调音量/进度"。

## 8. 串口协议速查（115200 8N1，CRLF）

| 命令 | 作用 | 回复示例 |
|:---|:---|:---|
| `PING` | 链路测试 | `PONG` |
| `STATUS?` | 一次读全部状态 | `LED…/KEY…/DIP…/ENC1…/ENC2…/IR…` 多行 |
| `KEY?` | 读 12 键实时电平 | `KEY 000000000000`（左→右 = KEY12→KEY1，1=按住） |
| `DIP?` | 读 6 拨码 | `DIP 111111`（左→右 = DIP6→DIP1，1=上拨） |
| `ENC?` | 读两编码器 | `ENC1 CNT FFFC A 1 B 1 SW 1` 等两行 |
| `IR?` | 读最近红外帧 | `IR BA45FF00 CMD FF` 或 `IR NONE` |
| `EVENTS ON/OFF` | 开关异步事件（**上电默认 ON**） | `OK` |
| `EVENTS?` | 查事件开关 | `EVENTS ON` |
| `LED n ON/OFF`、`LED ALL …` | 控 LED1–4 | `OK` |
| `WS n RRGGBB` / `WS ALL RRGGBB` / `WS TEST` / `WS OFF` | 控 8 颗 WS2812 | `OK` |

**异步事件（默认开启，动作即主动推送）**

```
KEY nn DOWN / KEY nn UP            按键
DIP n 1 / DIP n 0                  拨码（1=上拨）
ENC1 | ENC2  + | -  <CNT>          旋钮右(加)/左(减)
ENC1 | ENC2  SW DOWN | SW UP       旋钮按下/松开
IR <32位HEX> CMD <xx>              红外新帧
IR REPEAT                          红外长按重复帧
```

## 9. 结论与使用建议

1. **引脚链路三方零差异**：`top.adc`、开发板原理图 J2、手册第 7–8 页引脚表逐脚一致，可直接作为整机集成的硬件契约，无需再猜脚。
2. **判键用端口/编号，判红外用地址字节**：12 个按键里 5 个方向键的物理位置与编号 01–05 不对应；遥控 `CMD` 恒为 `FF`，务必判高 8 位地址。
3. **DIP 电平不要二次取反**：本板实测上拨即 `1`，直接当"功能使能"用。
4. **EXT1–6 尚是裸输出**：当前固件恒为 0，"拓展"功能的 DIP 使能 + KEY 触发 + EXT 输出联动要在整机固件中自行实现。
5. **标定时的已知初态**：ENC1 上电计数为 ‑4（`FFFC`），整机初始化建议清零编码器计数。
