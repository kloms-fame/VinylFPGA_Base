## **项目基础信息**

- 项目名称：VinylFPGA 全硬件MV音乐播放器
- 主控芯片：安路EG4S20BG256(HX4S20C开发板)
- 实现方式：纯硬件RTL、无CPU/无软核/无操作系统
- 竞赛定位：全国大学生嵌入式芯片与系统设计竞赛‑FPGA赛道
- 硬件组成：HX4S20C母板 + J2‑HMI‑Expansion RevB交互扩展板

## **硬件组成**

- HX4S20C母板
    - 显示：HDMI‑A/HDMI‑B/VGA；8位共阳数码管；4颗板载LED
    - 输入：4独立按键；6路乒乓拨码开关
    - 音频：板载蜂鸣器(SW5硬件切断)
    - 存储：W25Q16(配置Flash)；W25Q64；TF‑SD卡槽
    - 接口：USB‑JTAG；CH340串口；J2/J2 40Pin GPIO扩展口
    - 时钟：50MHz有源晶振
- J2‑HMI‑Expansion RevB扩展板（对接J2）
    - 输入：2个EC11旋转编码器；12路轻触按键；6路拨码DIP1‑DIP6；38K红外接收头
    - 输出：4颗状态LED；8颗级联WS2812彩灯
    - 连接器：40Pin主排座；8P预留拓展排母
    - 备注：播放器全部业务交互在此板；拔掉扩展板系统不崩溃，但播放器交互不可用，仅保留母板系统控制

## **顶层业务状态**

- STATE_BOOT 开机态
    - QSPI读取Logo画面，上电≤0.5s输出画面
    - Splash开机动画，按键/编码器/红外可跳过
    - 后台：SDRAM初始化、FAT32挂载、歌曲索引解析
- STATE_BROWSE 浏览选歌态
    - 封面展示、歌曲列表、封面预取，切歌无延迟
    - 30s无人操作自动封面轮播
    - 支持转场特效切换
- STATE_PLAY 播放态
    - 两种播放画面：MV视频 / 黑胶旋转动画
    - 播放、暂停、切歌、播放进度管理
    - 歌词、音频频谱可视化
- OSD菜单（悬浮浮层，不改变顶层状态）
    - 一级菜单：音量、亮度、对比度、人声消除、转场风格
    - 二级菜单：自动轮播、曲终行为、数码管设置、恢复出厂、版本信息

## **核心产品功能**

- 🎵音频功能
    - TF卡读取48kHz WAV音频播放，HDMI输出音频
    - 立体声人声消除功能
    - 软件音量调节；蜂鸣器告警提示
- 🖼画面与特效
    - HDMI输出640×480@60Hz视频
    - MV播放：RGB565 BMP帧序列，三帧环形缓冲
    - 黑胶渲染：Mode7逆向映射旋转、唱针抬起动画
    - 图像转场：淡入淡出 / 百叶窗 / 推幕
    - 五层图层混合：背景‑转场‑歌词‑频谱‑OSD
- 📝歌词功能
    - 硬件解析二进制LRC歌词
    - 模式：逐字动态变色 / 弹出淡入 / 静态高亮
- 📊音频可视化
    - 256点FFT音频频谱柱状图，快升慢降+峰值保持
- 🎛人机交互
    - 2路EC11编码器：播控编码器 + OSD调参编码器
    - 12按键：音量、切歌、歌词、特效、灯效等
    - NEC红外遥控，支持数字键跳转歌曲
    - DIP拨码：硬件全局开关(WS2812、红外、指示灯)
- 💡反馈外设
    - WS2812：音频律动 / 播放进度条灯效
    - 扩展板LED：红外、按键操作、心跳、告警指示
    - 母板数码管：歌曲序号、播放时长、错误码
    - 母板LED：系统心跳、SD读写、播放状态、错误告警

## **容错与降级能力**

- TF卡拔出/挂载失败：UI报错，数码管输出错误码，系统不死机
- 媒体文件缺失：曲目置灰，禁止进入播放
- MV帧读取欠载：冻结当前画面，不黑屏撕裂
- 模块故障：关闭对应图层，整机继续运行
- 资源紧张可裁剪：WS2812 → 红外 → FFT降点数 → 仅保留淡入淡出转场

## **最终成品效果**

1. 上电0.5s输出Logo画面，可播放Splash开机动画；任意输入可跳过动画进入浏览界面
2. 浏览界面：歌曲封面展示，编码器/按键切歌，支持多种转场特效，自动轮播
3. 播放模式A‑MV模式：播放MV视频 + 卡拉OK逐字变色歌词 + 音频频谱，音画硬件同步，漂移≤100ms
4. 播放模式B‑黑胶模式：无MV时渲染旋转黑胶动画，暂停唱针抬起摆动动画，搭配歌词与频谱
5. 可呼出OSD菜单，完成音量、画面参数、播放行为配置，3s无操作菜单自动淡出
6. 支持红外遥控器完整控制整机；WS2812彩灯跟随音乐或者播放进度展示
7. 系统异常有数码管、LED、蜂鸣器提示；24h长时间稳定运行，无花屏爆音死机
8. QSPI Flash固化程序，拔掉TF卡依然输出开机Logo，上电自启动
