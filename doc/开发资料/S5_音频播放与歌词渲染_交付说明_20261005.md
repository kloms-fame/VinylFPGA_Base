## 1. S5 做了什么（一句话）

把"扫描完就自动播 AUDIO.PCM"升级为**按索引选曲播放**：缩略图里选定第 N 首 →
进入播放态，播放该曲目自己的裸 PCM；建立**全工程唯一的 48 kHz 毫秒时基**，
音频与歌词同源；EC1 按压暂停/恢复（位置与时基同时冻结）、EC1 旋转切曲、
KEY04/KEY05 调音量；歌词按 `cur_time_ms` 显示单行。

## 3. 交互与状态约定（S5 冻结）

| 状态 | 操作 | 行为 |
|---|---|---|
| 浏览（全屏） | EC1 旋转 | 换封面（S3 行为） |
| 浏览（全屏） | EC1 按压 | 进 2×2 缩略图 |
| 缩略图 | EC1 旋转 | 移动焦点 |
| 缩略图 | EC1 按压 | **选定该曲目并进入播放态**，同时按 S3 的选图路径换封面 |
| 播放 | EC1 旋转 | 上一首 / 下一首（在可用曲目内回绕），封面同步切换（转场淡入淡出） |
| 播放 | EC1 按压 | 暂停 / 恢复 |
| 播放 | KEY04（上） | 音量 +16 |
| 播放 | KEY05（下） | 音量 −16 |
| 播放 | KEY07 | 退出播放态回浏览 |

音量在 `[32, 255]` 之间**饱和钳位**（不会溢出回绕成静音或爆音）。
母板 KEY1/KEY2 兜底仍作用于浏览态；播放态控制走 J2 事件（本阶段边界）。

## 4. 统一 48 kHz 时基（S5 的关键约束）

```text
video_clk(25 MHz) ──分数累加器──► wav_sample_tick(48 kHz，既有唯一源)
                                     │
           ┌─────────────────────────┴──────────────────────────┐
           ▼                                                    ▼
  wav_stream_player(sample_tick)                     timebase_48k(sample_tick)
  （播放位置；暂停时被门控冻结）                       └─► cur_time_ms ─► lrc_osd
```

- 歌词**只认** `timebase_48k.cur_time_ms`，自己不做任何时间计数 → 结构与音频同源，不会各自漂移。
- 暂停时：`wav_sample_tick_eff` 被门控 → 播放器位置**冻结**；同时音量压 0 且
  `force_arpeggio=1`，让 48 kHz 流继续（静音）以免 HDMI 音频饿死；恢复后从当前点续播。
- 切曲时：`play_track_step` 把 `play_enable` 松开 12 拍，让播放器回到 IDLE 并按新的
  `start_lba` 重播；同一事件在 video 域复位时基。

## 5. 歌词资源格式与字库预算

`.lrc`（`[mm:ss.xx]文本`，最多 15 行、每行 ≤16 字）→ `tools/gen_lrc_assets.py` →

- `lrc_font_rom.v`：16×16 点阵，`addr = 字形号*16 + 行`，每行 16bit；**只收录该歌词文件
  真正用到的字符**（本演示 60 字形 = 1920 字节）。
- `lrc_lines_rom.v`：每行 `{起始毫秒, 16 个字形号}`，按 16:1 选择。
- `lrc_geom.vh`：行数/每行字数/字号/位置/颜色/地址宽度。

字形渲染按**包围盒自适应缩放并居中**（不能直接在 (0,0) 画：中文字号 16 的包围盒常略大于
16×16，会裁掉笔画）。实测综合后 BRAM 仍为 `46/64`（未占用额外 BRAM，字库落在 LUT 逻辑里），
所以"S5 先做小字表、BRAM 留给后续 MV"的预算没有被动用。

歌词位置 `(96, 340)`，落在底部波形条（Y 376..471）之上，不与波形/状态 OSD 重叠。

## 7. 上板人工验收清单（待确认）

1. 上电：Logo → 首图（S2/S3 行为不变），浏览/切封面正常。
2. 进 2×2 缩略图，移到第 N 格按 EC1：应**进入播放态并从第 N 首开始出声**，无爆音；
   封面同步切到第 N 首。
3. 按 EC1 暂停：声音停、屏幕歌词**定格**；再按恢复：从**刚才的位置**继续（不是从头）。
4. 播放中旋转 EC1：切上一首/下一首，封面与音频同步切换，转场淡入淡出，无 SD 噪声。
5. KEY04/KEY05 调音量：能听出增减，最大最小不会失真/静音（钳位）。
6. 歌词：单行中文歌词随播放推进按时间切换，抽测与音频的偏差目标 ≤100 ms。
7. KEY07 退出播放态回浏览；再进缩略图选另一首仍正常。
