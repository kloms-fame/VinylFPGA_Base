## 9. 人工验收教程

### 9.1 写入验收卡

1. 插入专用测试卡，管理员 PowerShell 运行 `doc/资源/sd卡/write_card.ps1`。
2. 选择 `7 = card_UIRES.img`，再次核对目标盘符，避免覆盖系统盘。
3. 写完后重新插卡；必要时在 PC 侧再次运行：

```powershell
python tools/vinyl_packer.py verify --image "doc/资源/sd卡/card_UIRES.img" --width 640 --height 480
```

### 9.2 当前固件重新签核

```powershell
python tools/verify_core_acceptance.py --out sim/core_acceptance_20261008
& tools/c3_gate_export.ps1 -OutDir prj/closeout/gate -SynMode area_prior
& tools/c3_build_full.ps1 -GateDb prj/closeout/gate/VinylFPGA_gate_latest.db -Seed 5 -OutDir prj/closeout/full
```

只有日志出现 `C3_BUILD_PASS` 且 `final.qor` 的 Setup/Hold WNS 均非负，才可继续 bit 下载。不要直接使用本轮未签核的历史 bit。

### 9.3 JTAG SRAM 下载

在生成签核 bit 后，复制现有下载 Tcl 的设备核对模式：连接 Allink，确认目标字符串包含 `EG4S20BG256`，再执行 `download -mode jtag -bit <签核bit>`。下载后再次读取器件型号；这里只下载易失 SRAM，不改 W25Q16 上电镜像。

### 9.4 OmniProbe 串口

1. 在 EK-OmniProbe 选择 `COM8`、115200、8N1，连接并开始接收。
2. 打开 AI 本机桥，端口 8765。
3. 先做只读快照：

```powershell
python "C:/Users/Renni/.codex/skills/ek-omniprobe-ai/scripts/client.py" snapshot --port 8765 --seconds 5
```

4. 再做 10 秒监听：

```powershell
python "C:/Users/Renni/.codex/skills/ek-omniprobe-ai/scripts/client.py" watch --port 8765 --seconds 10
```

5. 预期至少看到启动、媒体扫描、INDEX/UIRES 成功和 `ERR=00`；没有行时先排查串口工作台是否已经“开始接收”，不能先判断 FPGA 正常。

### 9.5 板上最小冒烟

1. 冷启动：Logo、HDMI 锁定、进入浏览态，无异常错误码。
2. 选择 1~4 曲：标题、歌手和歌词随曲变化，不残留上一曲。
3. 播放：左侧元数据、进度条、底部波形与右侧五行歌词同时可见。
4. KEY06：L0 关闭 -> L1 静态五行 -> L2 滚动五行，循环正确。
5. 暂停：进度和歌词动画冻结；恢复后继续，不跳错行。
6. Seek/重播：歌词直接定位，不逐条补动画；进度条跳到对应位置。
7. DIP2 与 ROT：非 MV 播放下按设定周期在 4 张背景间切换，切换发生在整帧边界，无撕裂；暂停/MV/切曲门控符合方案。
8. 浏览/缩略图：原 4 封面保持正常，不被播放背景区污染。
9. MV 注意：当前 C4 未接入，MV 时窗口外保留播放背景这一最终目标尚不能验收；看到整帧路径择一属于当前已知阶段边界。
10. 连续播放至少 15 分钟，观察音频爆音、歌词串曲、背景写坏、错误码和串口溢出计数。

## 10. 遗留问题与下一阶段

1. P0：先把 route 后 slices 从 97.55% 降到建议不高于约 88%~90%，并消除 setup/hold 违例；优先共享/重构 SD 域 CRC 与资产解析、降低高扇出和跨区长连线，不再做只减 FF 不减等价 LUT 的优化。
2. P0：重新生成当前工作树的面积优先 gate DB，做少量有依据的 seed/布局策略比较；每轮必须保持输入哈希一致。
3. P1：时序通过后再接 C4，先完成“新 reader 只读整背景”，再做 MV 三段行组合；每个增量都测 owner 交接和音频不受影响。
4. P1：C4 完成后修 U4，使底图、媒体窗、元数据、进度、歌词作为同一页面参与转场。
5. P2：最后实现 U3 浮窗；当前器件资源紧张时，应优先考虑更大器件或减少非核心常驻诊断/显示逻辑，不能牺牲既有已验收音视频链路。
