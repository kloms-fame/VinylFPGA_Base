## 2. 保留的修改

### 像素流水与控制对齐

`brightness_contrast_adjust` 增加默认关闭的 INPUT_PIPELINE 参数，保留独立模块原一拍行为。顶层启用后，RGB、DE、brightness、contrast 同拍寄存，总输出延迟为两拍。原有有符号乘法、算术右移、截断和饱和表达式保持一致。

亮度寄存器初始化及复位为 255，对比度为 128；既符合默认画质，也让顶层固定满亮度输入可被常量折叠。RGB/DE 初始化及复位为 0。显示层 VS 延迟两拍，波形、启动层、歌词和 AXIS 使用对齐后的 VS；行内 X 按输出 DE 重建，首像素为 0、末像素为 639。读调度、帧参数提交继续使用原始帧事件，诊断图案继续使用原始像素节拍。下游没有使用需要额外延迟的原始 HS。

### UIRES 元数据流水

扫描完成后第一拍捕获 cluster−2、data_start 和簇大小移位值，第二拍计算并发布首扇区 LBA 与 valid。scan_start 撤销旧 valid/LBA，pending 结果可被重扫或复位取消。支持当前 done 单拍，同时防止保持电平的 done 被重复采样。

独立审查发现：扫描器提前报错时可能保留上一次合法 UIRES 目录信息。增加 `scanner_error == 0` 条件；真实扫描器注入坏引导签名时，旧 valid=1/LBA=44 不再重新发布，输出变为 0/0。

### 构建与回归基础

- `td_optimization_round.py` 管理独立输入和报告归档，拒绝变动的输入、过期日志、空报告集合及重复归档。允许 TD 保存工程时的等价路径、实体和编译序号规范化；拒绝映射策略变化、相对编译顺序变化或被篡改的原始工程。
- `build_verified_round.py` 对 Tcl 阶段错误执行 catch 并退出，避免 TD 返回交互提示符后一直等待；复用 gate.db 前核对源码与约束一致性。
- `verify_s7_acceptance.py` 增加独立输出目录、新用例和中文日志解码，静态资源仿真台按其语法使用 SystemVerilog 编译。
- 修复四缓冲测试替身缺失的 UIRES 端口；更新灯效测试为此前 C2.11 的量化 VU、静态进度和末端色契约。保留全部 192 位解码、脉宽、亮度上限、静音、关闭补黑及帧中复位检查。没有修改灯效生产 RTL。

没有修改 SDC/ADC、增加 false path、新建时钟、改变 CDC 或修改第三方 HDMI IP。

## 6. 签核状态与后续顺序

最终 seed 7 的数值 setup/hold 已通过，但尚不具备生成 bit 的完整签核条件：

1. 两个 PLL 仍有 USR-6135 反馈使用局部网络告警；PHY-5079 标记 1 个时钟网络使用局部布线资源。需按器件、实际反馈连接与报告核查，不能仅凭正 WNS 忽略。
2. fix_hold 的 ECO 中出现 PHY-7002（U3/sdram 初始位置不合法并移动）告警，需核对 ADC 与最终物理对象。没有直接改管脚或按日志坐标添加约束。
3. check_timing 报告没有非法约束、组合环路或 PLL 频率不匹配，但有 33 个输入和 38 个输出缺少 delay，并有 dummy 节点。应区分异步人机输入与 SD/SDRAM/HDMI 等同步接口，再按真实板级参数补齐；不能批量捏造 I/O delay。
4. setup +0.081、hold +0.024 ns 低于建议 +0.2/+0.05 ns，seed 5 失败及 seed 6 setup 违例说明实现仍对布局敏感。

后续先审计时钟与接口约束，再优先处理最终 seed 7 的 UIRES desc_static_bytes_r_reg[3]→state_reg[3] 路径（slack +0.081 ns），评估描述符校验预计算及控制扇出。seed 6 的 SD/BMP file_len→bmp_error 负路径作为跨 seed 鲁棒性目标，考虑预计算或拆分合法状态拍；同时观察 SD 初始化使能。每次只改一个结构点并重跑对应仿真、综合、物理实现。BRAM 合并必须证明生命周期可复用，本轮没有为少量 LUT 盲目增加 RAM。

本轮没有执行 bitgen、烧录、串口设备操作或远端 Git 推送。后续新增功能应以这份可信输入和报告为基线，解决以上问题后再进行 bit 与硬件验收。
