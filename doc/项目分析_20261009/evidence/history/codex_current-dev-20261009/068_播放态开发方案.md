### 一、 视觉视区与流水线合成架构

#### 1. 640×480 物理视区与绝对几何坐标划分

```
     0                    264         320        344                       640 (X)
  0  ┌─────────────────────┬───────────┬──────────┬─────────────────────────┐
     │ [烘焙底图] 640×480 (SDRAM Ping-Pong 读出，左上角已贴合 240×240 封面)     │
     │ ┌─────────────────┐ │           │          │ Line -2 (Y:44~59, 暗灰) │
 28  │ │ 封面/黑胶 240×240│ │           │          │                         │
     │ │ (X: 24 ~ 263)   │ │           │          │ Line -1 (Y:104~119,浅灰)│
     │ │ ─────────────── │ │           │          ├─────────────────────────┤
     │ │ [MV 展宽视窗]   │ │           │          │★Line  0 (Y:164~195,纯白)│
     │ │ (X: 24 ~ 343)   │ │           │          │ 32px (2x 硬件降采样放大)│
267  │ └─────────────────┘ │           │          ├─────────────────────────┤
276  │ 歌名 (16px, Y:276~291)          │          │ Line +1 (Y:240~255,浅灰)│
298  │ 歌手 (16px, Y:298~313)          │          │                         │
326  │ 极简白色进度条 (高3px, X:24~263)│          │ Line +2 (Y:300~315,暗灰)│
328  │ ─────────────────   │           │          │                         │
     └─────────────────────┴───────────┴──────────┴─────────────────────────┘
376  ┌──────────────────────────────────────────────────────────────────────┐
     │ [全屏底部音谱区] promax_audio_waveform                               │
     │ X: 64 ~ 576, Y: 376 ~ 471 (维持原有 96px 高度与坐标不变)              │
472  └──────────────────────────────────────────────────────────────────────┘
480 (Y)
```

- **左侧视区（播控与视听焦点）**：
  - **视窗区域（$Y \in [28, 267]$，高度 240px）**：
    - *封面模式*：$X \in [24, 263]$。由于采用 PC 烘焙方案，底图该区域已预先合成当前歌曲封面，底层像素直通。   
    - *黑胶模式*：$X \in [24, 263]$。`vinyl_renderer` 在该区域覆盖输出旋转黑胶动画。   
    - *MV 模式*：$X \in [24, 343]$。视窗横向展宽至 320px，覆盖该区域输出动态视频流。   
  - **元数据文本区**：
    - *歌曲名*：$X \in [24, 263], Y \in [276, 291]$（高 16px），16×16 点阵，高亮纯白 `24'hFFFFFF`，最大 15 个汉字（超长硬件硬截断）。   
    - *歌手名*：$X \in [24, 263], Y \in [298, 313]$（高 16px），复用 16×16 点阵，次级浅灰 `24'h808090`。   
  - **极简白色进度条**：
    - $X \in [24, 263], Y \in [326, 328]$（高 3px，宽 240px）。
    - 填充部分为纯白 `24'hFFFFFF`，未播部分为深灰底槽 `24'h303038`。取消时间文字，纯视觉呈现。   
- **右侧视区（沉浸式五行歌词）**：
  - 横向范围：封面/黑胶模式下 $X \in [280, 620]$（视宽 340px，最多容纳 10 个 32px 大字）；MV 展宽时自动向右避让至 $X \in [356, 620]$。   
  - 纵向五行：Line -2 ($Y: 44 \sim 59$, 暗灰 `24'h404048`)、Line -1 ($Y: 104 \sim 119$, 浅灰 `24'h808090`)、Line 0 ($Y: 164 \sim 195$, 纯白 2x 放大 `24'hFFFFFF`)、Line +1 ($Y: 240 \sim 255$, 浅灰 `24'h808090`)、Line +2 ($Y: 300 \sim 315$, 暗灰 `24'h404048`)。   
- **底部音谱区**：
  - 维持现有 `promax_audio_waveform` 物理参数完全不动：$X \in [64, 576], Y \in [376, 471]$。   

#### 2. 25 MHz 像素时钟单向无延迟级联流水线


### 二、 显存分配与无缝切图控制流

#### 1. 片内 SDRAM（8 MiB / 2M×32-bit）空间划分表

利用烘焙套图方案，显存无需存储额外的全屏大图，两块 640×480 帧缓存构成交替平滑切换通道：   

| **显存分区名称**         | **物理基地址 (32-bit 字)**  | **大小 (字 / 字节)**      | **用途说明**                          |
| ------------------------ | --------------------------- | ------------------------- | ------------------------------------- |
| **Bank 0 (显示乒乓 A)**  | `21'd0`                     | 307,200 字 (1.17 MiB)     | 当前显示的 640×480 烘焙底图（含封面） |
| **Bank 1 (显示乒乓 B)**  | `21'd307200`                | 307,200 字 (1.17 MiB)     | 后台加载的目标 640×480 烘焙底图       |
| **Bank 2 (MV 环形帧 0)** | `21'd1228800`               | 76,800 字 (0.29 MiB)      | 320×240 RGB565 MV 视频帧 0            |
| **Bank 3 (MV 环形帧 1)** | `21'd1305600`               | 76,800 字 (0.29 MiB)      | 320×240 RGB565 MV 视频帧 1            |
| **Bank 4 (MV 环形帧 2)** | `21'd1382400`               | 76,800 字 (0.29 MiB)      | 320×240 RGB565 MV 视频帧 2            |
| **黑胶 16 帧贴图区**     | `21'd1459200`               | 153,600 字 (0.58 MiB)     | 16 帧 160×160 唱片微缩贴图序列        |
| **动态安全保留区**       | `21'd1612800 ~ 21'd2097151` | **484,352 字 (1.85 MiB)** | 保持空余，防突发读写越界溢出          |

#### 2. 无缝平滑切图状态机（`wallpaper_ctrl.v`）

实现“后台预写空闲 Bank $\to$ 写入完成 $\to$ 垂直消隐边界翻转显示指针”，达成零黑屏瞬时切换：   

程式碼片段

```
stateDiagram-v2
    [*] --> ST_IDLE
    
    ST_IDLE --> ST_PREPARE: 触发切图事件 (30s 定时溢出 OR KEY06 按下)<br/>[前提: allow_switch=1]
    
    ST_PREPARE --> ST_LOADING: 计算目标扇区与空闲 Bank (write_bank = ~disp_bank)<br/>发起 SD 读图请求
    
    ST_LOADING --> ST_WAIT_VBLANK: SD 扇区读入完成，SDRAM 写入完成标记置位
    
    ST_WAIT_VBLANK --> ST_IDLE: 捕获 frame_start (垂直消隐边界)<br/>原子更新 disp_bank <= write_bank<br/>重置 30s 自动定时器
```

- **硬件信号约束绑定**：
  - **自动轮播使能**：`GPIOB_28`（`K14`，`exp_dip_n[4]`，即 DIP5），拨上输出高电平 `1` 使能。   
  - **屏幕消隐控制**：`GPIOB_9`（`H4`，`exp_dip_n[3]`，即 DIP4），继续保持原 60s/遥控息屏功能。   
  - **手动切换按键**：`GPIOB_15`（`H1`，`exp_key_n[5]`，即 KEY06）按下触发单拍脉冲。   
  - **MV 互斥闭锁**：当 `mv_stream_active == 1`（MV 正在播放）时，硬件强制挂起自动轮播与 KEY06，SD 带宽 100% 保障音频与视频，避免爆音。

#### 1. 极简白色细线进度条模块（`src/display/progress_bar_osd.v`）

Verilog

```
`timescale 1ns / 1ps

module progress_bar_osd (
    input  wire        clk,             // 25MHz video_clk
    input  wire        rst_n,
    input  wire        frame_start,     // 场消隐单脉冲 (VS 下降沿)
    input  wire [31:0] cur_time_ms,     // 当前播放时间 (ms)
    input  wire [31:0] total_time_ms,   // 歌曲总时间 (ms)
    input  wire [9:0]  pixel_x,
    input  wire [9:0]  pixel_y,
    input  wire [23:0] rgb_in,
    output wire [23:0] rgb_out
);

    localparam [9:0] BAR_X = 10'd24;
    localparam [9:0] BAR_W = 10'd240;
    localparam [9:0] BAR_Y = 10'd326;
    localparam [9:0] BAR_H = 10'd3;

    reg [7:0] fill_len_q;

    // 场消隐期完成除法计算，像素扫描期无宽位运算延迟
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            fill_len_q <= 8'd0;
        end else if (frame_start) begin
            if (total_time_ms == 32'd0 || cur_time_ms >= total_time_ms)
                fill_len_q <= BAR_W[7:0];
            else
                fill_len_q <= (cur_time_ms * BAR_W) / total_time_ms;
        end
    end

    wire in_bar_y = (pixel_y >= BAR_Y) && (pixel_y < BAR_Y + BAR_H);
    wire in_bar_x = (pixel_x >= BAR_X) && (pixel_x < BAR_X + BAR_W);
    wire in_fill  = (pixel_x <  BAR_X + fill_len_q);

    assign rgb_out = (in_bar_y && in_bar_x) ? 
                     (in_fill ? 24'hFFFFFF : 24'h303038) : rgb_in;

endmodule
```

```
`timescale 1ns / 1ps

module song_meta_osd (
    input  wire        clk,             // 25MHz video_clk
    input  wire        rst_n,
    input  wire [9:0]  pixel_x,
    input  wire [9:0]  pixel_y,
    input  wire [23:0] rgb_in,
    output wire [23:0] rgb_out,

    // 当前曲目元数据 (来自 song_index_db 锁存)
    input  wire [255:0] title_gbk,      // 32 字节 (最多 16 汉字)
    input  wire [127:0] artist_gbk,     // 16 字节 (最多 8 汉字)

    // 字库只读接口 (复用 16x16 lrc_font_rom)
    output wire [10:0] font_addr,
    input  wire [15:0] font_data
);

    localparam [9:0] META_X_START = 10'd24;
    localparam [9:0] TITLE_Y      = 10'd276;
    localparam [9:0] ARTIST_Y     = 10'd298;

    wire hit_title_box  = (pixel_y >= TITLE_Y)  && (pixel_y < TITLE_Y + 10'd16) &&
                          (pixel_x >= META_X_START) && (pixel_x < META_X_START + 10'd240);

    wire hit_artist_box = (pixel_y >= ARTIST_Y) && (pixel_y < ARTIST_Y + 10'd16) &&
                          (pixel_x >= META_X_START) && (pixel_x < META_X_START + 10'd240);

    wire [3:0] dy_title  = pixel_y[3:0] - TITLE_Y[3:0];
    wire [3:0] dy_artist = pixel_y[3:0] - ARTIST_Y[3:0];
    wire [7:0] dx        = pixel_x - META_X_START;

    wire [3:0] char_idx  = dx[7:4]; // 字符序号 (0 ~ 14)
    wire [3:0] dot_col   = dx[3:0]; // 字模内列坐标 (0 ~ 15)

    // 提取当前列对应的 GBK 内部索引 (由工具建立 6-bit 紧凑索引)
    wire [6:0] cur_glyph_id = hit_title_box ? title_gbk[char_idx*8 +: 7] :
                              hit_artist_box ? artist_gbk[char_idx*8 +: 7] : 7'd0;

    wire [3:0] cur_row = hit_title_box ? dy_title : dy_artist;

    assign font_addr = {cur_glyph_id, cur_row};
    wire dot_active  = font_data[15 - dot_col];

    assign rgb_out = (hit_title_box  && dot_active) ? 24'hFFFFFF :
                     (hit_artist_box && dot_active) ? 24'h808090 : rgb_in;

endmodule
```

#### 3. 五行动态歌词平滑位移模块（`src/display/lrc_five_line_osd.v`）

Verilog

```
`timescale 1ns / 1ps

module lrc_five_line_osd (
    input  wire        clk,             // 25MHz video_clk
    input  wire        rst_n,
    input  wire        frame_start,     // 场消隐触发信号
    input  wire        mv_active,       // MV 模式状态 (用于动态避让)
    input  wire [31:0] cur_time_ms,     // 物理时基
    input  wire [9:0]  pixel_x,
    input  wire [9:0]  pixel_y,
    input  wire [23:0] rgb_in,
    output wire [23:0] rgb_out,

    // 歌词装载流 (来自 lyric_loader)
    input  wire        lyric_valid,
    input  wire [31:0] line_time_ms,
    input  wire [127:0] line_text_indices, // 当前行 16 个字符字模索引

    // 共享 16x16 字库接口
    output wire [10:0] font_addr,
    input  wire [15:0] font_data
);

    // 动态左右开窗边界 (MV 展宽避让)
    wire [9:0] LRC_X_START = mv_active ? 10'd356 : 10'd280;
    localparam [9:0] LRC_X_END   = 10'd620;

    // 行基准 Y 坐标
    localparam [9:0] Y_LINE_M2 = 10'd44;
    localparam [9:0] Y_LINE_M1 = 10'd104;
    localparam [9:0] Y_LINE_0  = 10'd164; // Line 0 基准起始 (高度 32px)
    localparam [9:0] Y_LINE_P1 = 10'd240;
    localparam [9:0] Y_LINE_P2 = 10'd300;

    // 16 帧平滑位移动态状态机
    reg [3:0]  scroll_cnt;
    reg        scrolling;
    reg [4:0]  y_offset; // 每帧上移 3 像素 (0 ~ 45)

    wire next_line_trigger = (cur_time_ms >= line_time_ms) && lyric_valid;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            scroll_cnt <= 4'd0;
            scrolling  <= 1'b0;
            y_offset   <= 5'd0;
        end else if (frame_start) begin
            if (next_line_trigger && !scrolling) begin
                scrolling  <= 1'b1;
                scroll_cnt <= 4'd0;
                y_offset   <= 5'd0;
            end else if (scrolling) begin
                if (scroll_cnt == 4'd15) begin
                    scrolling  <= 1'b0;
                    scroll_cnt <= 4'd0;
                    y_offset   <= 5'd0;
                end else begin
                    scroll_cnt <= scroll_cnt + 4'd1;
                    y_offset   <= y_offset + 5'd3;
                end
            end
        end
    end

    // 垂直视窗检测 (叠加平移量 y_offset)
    wire in_x_range = (pixel_x >= LRC_X_START) && (pixel_x < LRC_X_END);

    wire hit_m2 = in_x_range && (pixel_y >= Y_LINE_M2 - y_offset) && (pixel_y < Y_LINE_M2 + 16 - y_offset);
    wire hit_m1 = in_x_range && (pixel_y >= Y_LINE_M1 - y_offset) && (pixel_y < Y_LINE_M1 + 16 - y_offset);
    wire hit_0  = in_x_range && (pixel_y >= Y_LINE_0  - y_offset) && (pixel_y < Y_LINE_0  + 32 - y_offset); // 32px
    wire hit_p1 = in_x_range && (pixel_y >= Y_LINE_P1 - y_offset) && (pixel_y < Y_LINE_P1 + 16 - y_offset);
    wire hit_p2 = in_x_range && (pixel_y >= Y_LINE_P2 - y_offset) && (pixel_y < Y_LINE_P2 + 16 - y_offset);

    // 核心算法：Line 0 硬件 2x 降采样坐标映射
    wire [9:0] dy_raw = pixel_y - (Y_LINE_0 - y_offset);
    wire [9:0] dx_raw = pixel_x - LRC_X_START;

    wire [3:0] line0_row = dy_raw[4:1]; // >> 1 实现纵向每点重复 2 行
    wire [3:0] line0_col = dx_raw[4:1]; // >> 1 实现横向每点重复 2 列
    wire [3:0] line0_char_idx = dx_raw[8:5]; // 每个字占 32 像素宽

    // 其他行正常 1x 采样
    wire [3:0] norm_row = pixel_y[3:0];
    wire [3:0] norm_col = dx_raw[3:0];
    wire [3:0] norm_char_idx = dx_raw[7:4]; // 每个字占 16 像素宽

    // 字模寻址与读取
    wire [6:0] glyph_id = hit_0 ? line_text_indices[line0_char_idx*8 +: 7] :
                                  line_text_indices[norm_char_idx*8 +: 7];

    assign font_addr = {glyph_id, (hit_0 ? line0_row : norm_row)};
    wire pixel_active = font_data[15 - (hit_0 ? line0_col : norm_col)];

    // 到位瞬间色彩判定
    assign rgb_out = (!pixel_active) ? rgb_in :
                     hit_0  ? 24'hFFFFFF : // 纯白高亮
                     (hit_m1 || hit_p1) ? 24'h808090 : // 浅灰
                     (hit_m2 || hit_p2) ? 24'h404048 : rgb_in; // 暗灰

endmodule
```

#### 4. 全局壁纸轮播控制器（`src/display/wallpaper_ctrl.v`）

Verilog

```
`timescale 1ns / 1ps

module wallpaper_ctrl #(
    parameter integer CLK_FREQ_HZ = 100_000_000,
    parameter integer ROTATE_SEC  = 30
)(
    input  wire        clk,             // 100MHz sd_card_clk
    input  wire        rst_n,
    input  wire        dip_auto_en,     // DIP5 (K14, exp_dip_n[4]): 自动轮播使能
    input  wire        key_manual_next, // KEY06 (H1, exp_key_n[5]): 手动切图脉冲
    input  wire        mv_active,       // MV 播放中互斥标志 (锁定禁止切图)
    input  wire        frame_start,     // 场消隐原子切换
    input  wire        load_done,       // SD 卡一张图写入 SDRAM 完成

    output reg         load_req,        // 启动后台加载请求
    output reg  [2:0]  bg_index,        // 当前壁纸序号 (0~7)
    output reg         active_bank      // 当前显示 Bank (0 或 1，无缝翻转)
);

    localparam [31:0] TIME_LIMIT = CLK_FREQ_HZ * ROTATE_SEC;

    reg [31:0] sec_cnt;
    reg        pending_bank;
    reg        load_busy;

    wire trigger_next = (key_manual_next || (dip_auto_en && (sec_cnt >= TIME_LIMIT))) && !mv_active;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            sec_cnt      <= 32'd0;
            bg_index     <= 3'd0;
            active_bank  <= 1'b0;
            pending_bank <= 1'b0;
            load_req     <= 1'b0;
            load_busy    <= 1'b0;
        end else begin
            load_req <= 1'b0;

            // 1. 定时器驱动 (手动按键或 MV 激活时强制清零复位)
            if (key_manual_next || mv_active || !dip_auto_en) begin
                sec_cnt <= 32'd0;
            end else if (sec_cnt < TIME_LIMIT) begin
                sec_cnt <= sec_cnt + 32'd1;
            end

            // 2. 切图请求触发 (写入后台非显示 Bank)
            if (trigger_next && !load_busy) begin
                sec_cnt      <= 32'd0;
                bg_index     <= bg_index + 3'd1;
                pending_bank <= ~active_bank; // 写入空闲缓冲
                load_req     <= 1'b1;
                load_busy    <= 1'b1;
            end

            // 3. 后台加载完成，场消隐边界原子更新显示指针
            if (load_busy && load_done) begin
                load_busy <= 1'b0;
            end

            if (frame_start && !load_busy && (active_bank != pending_bank)) begin
                active_bank <= pending_bank; // 瞬间原子切换，绝不黑屏
            end
        end
    end

endmodule
```

### 四、 PC 离线预处理工具链升级（`tools/vinyl_packer.py`）

```
import os
import struct
from PIL import Image, ImageEnhance

# -----------------------------------------------------------------------------
# 1. 专属壁纸套图烘焙逻辑 (暗化 50% + 左上角贴合 240x240 专辑封面)
# -----------------------------------------------------------------------------
def bake_song_wallpapers(wallpaper_paths, cover_path, output_dir, song_id):
    """
    为指定歌曲生成一组专属烘焙底图 BG0_songX.BIN ~ BG3_songX.BIN
    """
    cover_img = Image.open(cover_path).convert("RGB").resize((240, 240), Image.Resampling.LANCZOS)
    
    for idx, wp_path in enumerate(wallpaper_paths):
        wp = Image.open(wp_path).convert("RGB").resize((640, 480), Image.Resampling.LANCZOS)
        
        # 整体画面压暗 50%
        enhancer = ImageEnhance.Brightness(wp)
        dark_wp = enhancer.enhance(0.50)
        
        # 左上角 (X:24, Y:28) 贴入 240x240 封面
        dark_wp.paste(cover_img, (24, 28))
        
        # 导出为标准 640x480 RGB565 裸流
        out_bin = os.path.join(output_dir, f"BG{idx}_S{song_id}.BIN")
        with open(out_bin, "wb") as f:
            for y in range(480):
                for x in range(640):
                    r, g, b = dark_wp.getpixel((x, y))
                    rgb565 = ((r >> 3) << 11) | ((g >> 2) << 5) | (b >> 3)
                    f.write(struct.pack("<H", rgb565))

# -----------------------------------------------------------------------------
# 2. INDEX.BIN 扩展格式定义 (每曲分配定长 128 字节)
# -----------------------------------------------------------------------------
"""
[0x00 ~ 0x03] : flags (bit0:cover, bit1:audio, bit2:lrc, bit3:mv)
[0x04 ~ 0x07] : cover_first_cluster
[0x08 ~ 0x0B] : cover_bytes
[0x10 ~ 0x13] : audio_first_cluster
[0x14 ~ 0x17] : audio_bytes (裸 PCM 字节数)
[0x18 ~ 0x1F] : MV 描述符 (LBA, 帧数, fps, 编码)
[0x20 ~ 0x3F] : 歌曲名称 (32 字节 GBK 编码，最多 16 汉字，不足补 0x00)
[0x40 ~ 0x4F] : 歌手名称 (16 字节 GBK 编码，最多 8 汉字，不足补 0x00)
[0x50 ~ 0x7F] : 保留对齐 (48 字节)
"""
def pack_index_entry(song_meta):
    entry = bytearray(128)
    # ... 填充前序簇与长度信息 ...
    title_gbk = song_meta['title'].encode('gbk')[:32]
    artist_gbk = song_meta['artist'].encode('gbk')[:16]
    entry[0x20:0x20+len(title_gbk)] = title_gbk
    entry[0x40:0x40+len(artist_gbk)] = artist_gbk
    return entry
```

#### 2. 编译门禁与资源防爆确认清单

在安路 TD 工具中执行综合与布局布线时，严格核对以下指标：

1. **Slices 预算防线**：全套新增逻辑总计增加约 260 个 Slices，结合 X0R 阶段的局部精简，最终 Slices 占用率稳定收敛在 **84.5% ~ 85.5%**，严守不超过 88% 的安全上限。   
2. **BRAM 增量防线**：
   - Line 0 大字放大采用 `>> 1` 降采样插值算法，增加 **0 块 BRAM**。   
   - 歌名与歌手复用现有 16×16 点阵字模，增加 **0 块 BRAM**。   
   - 全局仅由 `lyric_loader` 消耗 **2 块 BRAM9K** 存放当前曲目五行缓存，片内 64 块 BRAM 剩余仍有 22 块以上，余量充足。   
3. **时序收敛防线**：
   - 除法计算全部剥离至场消隐期（`frame_start`）单周期完成，25 MHz 视频流水线全链条为纯组合比对与位移，无多周期大位宽路径，确保全局 Hold WNS 维持在正值。   
   - 全流程构建参数强制绑定 `--map-mode area_prior`，种子扫描锁定 Seed 7 与 Seed 5。
