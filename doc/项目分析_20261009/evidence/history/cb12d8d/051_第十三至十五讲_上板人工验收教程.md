
## 2. 第十三讲：缩略图显示与彩点回归

### 2.1 进入缩略图

操作：

```text
全屏状态下，按住 KEY1 约 1.2 秒，然后松开。
```

期望现象：

```text
1. 画面整帧切换到 2x2 缩略图，不出现半帧撕裂；
2. 四个缩略图分别位于左上、右上、左下、右下；
3. 左上=PIC1，右上=PIC2，左下=PIC3，右下=PIC4；
4. 四格内部必须是缩小后的真实图片内容，不能是纯白；
5. 当前焦点格最外圈有 2 像素黄色边框；
6. 右半屏和下半屏应为黑色，不应出现花屏或噪点。
```

本项是本次修复的核心。只要仍有任一格为纯白，就记录具体是哪一格、黄框是否正常、四格是否全白。

### 2.2 退出缩略图

操作：

```text
再次按住 KEY1 约 1.2 秒，然后松开。
```

期望现象：

```text
1. 返回全屏模式；
2. 返回的图片内容与进入缩略图前一致；
3. 全屏图片没有白屏、闪屏、错位或新增彩点；
4. 原有 OSD、转场和自动轮播继续正常。
```

### 2.3 长时间彩点回归

操作：

```text
1. 先在全屏静止观察 2 分钟，记录原有彩点基线；
2. 进入缩略图停留 1 分钟；
3. 返回全屏静止观察 10~15 分钟；
4. 重复“全屏->缩略图->全屏”至少 10 次；
5. 再让全屏和缩略图各停留 5 分钟，检查是否新增彩点。
```

通过标准：

```text
退出缩略图后不新增彩点，彩点数量不随时间增加。
```

失败时记录：

```text
1. 是进入缩略图后立即出现，还是返回全屏一段时间后出现；
2. 彩点固定不动还是持续变化；
3. 切换四张图片后是否增多；
4. 只要切换一次缩略图就出现，还是多次切换后才出现。
```

## 3. 第十四讲：参数菜单与亮度/对比度

### 3.1 进入菜单

操作：

```text
同时按住 KEY1 和 KEY2 约 1.2 秒，然后同时松开。
```

期望现象：

```text
1. 菜单成功进入，不会触发下一张、上一张或自动轮播；
2. OSD 第二行出现 BFFC80；
3. BFF 表示亮度默认 255，C80 表示对比度默认 128；
4. 菜单文字不能被亮度/对比度再次调暗或调亮。
```

### 3.2 菜单内 KEY1：亮度

短按操作：

```text
按一下 KEY1，约 0.2~0.5 秒内松开。
```

期望现象：

```text
brightness: FF -> 00，OSD 变为 B00C80；
画面明显变暗，亮度 00 时应接近全黑。
```

长按操作：

```text
按住 KEY1 约 1.2 秒后松开。
```

期望现象：

```text
brightness: 00 -> FF，OSD 恢复 BFFC80；
画面恢复正常亮度。
```

连续短按 KEY1 的亮度序列：

```text
FF -> 00 -> 40 -> 80 -> C0 -> FF
```

### 3.3 菜单内 KEY2：对比度

短按操作：

```text
按一下 KEY2，约 0.2~0.5 秒内松开。
```

期望现象：

```text
contrast: 80 -> C0，OSD 变为 BFFCC0；
画面层次增强，亮部更亮、暗部更暗。
```

长按操作：

```text
按住 KEY2 约 1.2 秒后松开。
```

期望现象：

```text
contrast: C0 -> 80，OSD 恢复 BFFC80；
画面恢复正常对比度。
```

连续短按 KEY2 的对比度序列：

```text
80 -> C0 -> FF -> 00 -> 40 -> 80
```

### 3.4 按键隔离与超时

在菜单内依次确认：

```text
1. 短按 KEY1 只调亮度，不切换下一张；
2. 长按 KEY1 只反向调亮度，不进入缩略图；
3. 短按 KEY2 只调对比度，不切换自动轮播；
4. 长按 KEY2 只反向调对比度，不切换上一张；
5. 调整过程中原图片内容保持不变，不出现整帧跳图。
```

停止操作，等待 10 秒：

```text
菜单应自动退出，OSD 第二行 BxxCyy 消失；
退出后 KEY1/KEY2 恢复原有全屏功能。
```

再次用双键长按进入菜单，再用双键长按退出，确认退出后按键不会一直失效。

## 4. 第十五讲：缩略图交互选择

### 4.1 焦点移动

在缩略图模式下：

```text
KEY1 短按：焦点右移，3 后回到 0；
KEY2 短按：焦点左移，0 后回到 3。
```

期望现象：

```text
1. 黄色边框跟随焦点移动；
2. 焦点循环顺序正确；
3. 焦点移动不改变缩略图内容和全屏图片。
```

### 4.2 快速选图

操作：

```text
1. 用短按把焦点移到 PIC2；
2. 按住 KEY2 约 1.2 秒后松开。
```

期望现象：

```text
1. 在淡出完成的黑场边界切到 PIC2；
2. 返回全屏后显示 PIC2，不串图；
3. 松开 KEY2 不会额外触发“上一张”；
4. 转场、OSD 和音频正常。
```

再分别选择 PIC3、PIC4 和当前图片 PIC1，确认都能返回正确全屏。

### 4.3 KEY1 长按返回

操作：

```text
在缩略图模式下，按住 KEY1 约 1.2 秒后松开。
```

期望现象：

```text
1. 退出缩略图并返回全屏；
2. 如果之前没有确认其他图片，返回图片保持原位置不变；
3. 不产生额外下一张或错误转场。
```

### 4.4 未加载图片门控

上电后尽快进入缩略图，在四张图还未全部加载完成时，把焦点移到仍为黑色或未完成的格子，长按 KEY2：

```text
1. 未加载完成的格不能确认；
2. 已加载完成的格应能正常确认；
3. 等待加载完成后再次确认，按键应恢复正常。
```

该步骤可选；若不方便抓住加载窗口，以已加载四图的交互测试为主。

## 5. 交叉回归

三轮验收后还要确认既有功能没有被破坏：

```text
1. 全屏 KEY1 短按：下一张；
2. 全屏 KEY2 短按：自动轮播开关；
3. 全屏 KEY2 长按：上一张；
4. WAV 播放和音频波形继续正常；
5. 转场、状态 OSD、错误码显示继续正常；
6. HDMI 无闪烁、无半屏撕裂、无黑边变化；
7. 复位后重新加载 SD 卡并回到正常显示；
8. 观察期间 FPGA 不应异常复位或卡死。
```

## 7. 常见异常与判断方向

```text
13-A 四格仍全白，但黄框正常：
     说明布局和焦点已工作，优先查缩略图逐像素取像仲裁/地址流。

13-B 某几格白，某几格正常：
     优先查对应 bank 的基址、image_complete 状态和该 bank 读数据。

13-C 缩略图正常，但退出后出现新彩点：
     优先查 SDRAM 读口在途数据归属和刷新避让是否仍有跨模式串扰。

14-A 菜单能进入但 KEY1/KEY2 完全无反应：
     优先确认烧入的位流确实包含新修复，并检查 100 MHz 域按键消抖。

14-B OSD 数值变化但画面不变化：
     优先查 frame_start 参数锁存和像素处理链。

14-C KEY1 短按变成下一张、KEY2 短按变成轮播：
     说明菜单按键隔离失效，优先检查 param_menu_controller 输出门控。

15-A 确认后显示错误图片：
     优先查 select_index、active_index 和 bank 选择。

15-B 确认后一直黑屏：
     优先查同 bank 确认时的 switch_abort_toggle 和转场释放。

15-C KEY1 长按退出后图片位置改变：
     优先查 view_mode 切换是否误触发下一张。
```

## 8. 验收完成后的处理

若十三、十四、十五讲全部通过：

```text
1. 记录新位流 SHA256 和实际现象；
2. 将对勾后的结果表反馈给 Codex；
3. 再决定是否把本轮未提交修复提交到 Git；
4. Flash 固化属于后续单独步骤，必须确认新位流稳定后再执行。
```

若仍有失败：

```text
1. 保留当前 bit 和 SD 卡，不要重新格式化；
2. 记录失败条目、操作时长、OSD 数值、图片编号和彩点位置；
3. 尽量用照片或短视频记录 HDMI 画面；
4. 把记录表发回 Codex，再决定是否接 ILA 观察缩略图读口。
```
