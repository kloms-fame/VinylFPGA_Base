# VinylFPGA 逐功能人工验收清单

日期：2026-10-09。配套[主报告](项目现状_赛题对照_资源优化与分阶段开发方案.md)。**本文件是后续验收模板；所有新增阶段当前均为未执行，不代表已经上板通过。**

## 1. 每轮必须填写的记录

| 字段 | 填写内容 |
|---|---|
| 阶段/本次唯一功能 | 例如 B1：EC2 音量，暂不包含浮窗和亮度 |
| 上一人工通过版本 | commit / bit路径 / bit SHA-256 / 卡镜像 SHA-256 |
| 当前候选 | commit，是否dirty，输入manifest，bit SHA-256 |
| 构建条件 | TD版本、器件、top、map_mode、seed、SDC/ADC哈希 |
| 自动测试 | 实际默认集合数量、结果文件、定向测试、失败说明 |
| final物理报告 | LUT / Slice / PLB / BRAM / DSP，setup / hold，TNS / endpoints，overflow |
| 开放告警 | PLL反馈、CDC、I/O约束，已解释或待处理 |
| 素材 | 镜像、INDEX、歌词/字库、真实曲目/分辨率 |
| 实板环境 | 板卡、电源、显示器/音箱、HDMI线、DIP初始状态 |
| 人工结果 | 通过 / 失败 / 待补证据；日期；具体观察 |
| 证据与遗留项 | 短视频/照片/记录路径；已知限制；是否允许进入下一阶段 |

未填人工结果，不能更新accepted标记。录屏可以辅助，至少应直接观察板上画面与声音，不能只看事件仿真或串口输出。当前生产UART静默，旧手册的UART报文不是这一版本的验收依据。

## 2. 每轮共同的短回归

每轮新功能先跑自动门禁，再用SRAM候选验收；保留上一验收固件可恢复。以下测试不要求每次都重跑全部长稳，但每次至少确认受影响链路和这些关键行为：

- [ ] 复位/启动Logo后进入正确界面，不花屏，不停在黑屏。
- [ ] EC1/KEY01/03浏览与选曲保持；KEY02/EC1按压播放/暂停正常。
- [ ] 有真实PCM声音，暂停静音，恢复无明显爆音。
- [ ] 播放当前时间随实际位置变化；暂停保持；Seek/重播同步。
- [ ] MV/黑胶切换和无MV曲目的回退符合规格。
- [ ] Home/停止后能再次播放，无旧会话数据串入。
- [ ] DIP1在场、DIP5红外开关、DIP6灯带开关不被新功能改写。
- [ ] 媒体拔出时进入安全静音/画面；插回可按已有恢复规则重新操作。
- [ ] 新功能的按键不误触发另一项业务。

## 3. A0：冻结稳定起点

- [ ] 记录当前板上bit，确认是否与 `afd8bfb/cb12d8d` 对应；无法绑定时明确标为未知，不套用本轮资源数。
- [ ] 记录当前TF镜像；明确S4、S5、S6镜像的不同内容。
- [ ] 完成共同短回归，拍摄当前基准画面。
- [ ] 记录自动轮播目前是否可在这个固件中触发；当前源码未接定时轮播。
- [ ] 确认用于比赛演示的48k测试音方式，不只确认“播放某首歌有声”。
- [ ] 将本轮area_prior报告作为分析基线，记录PLL/约束开放项。

## 4. A1：定时图片自动轮播

- [ ] 关闭轮播时长时间停留当前图片，不受后台计时误切换。
- [ ] 开启后按规定周期切换；1张、2张、4张图片均有明确行为。
- [ ] 自动轮播至少100次，画面无上旧下新、空白首行、瞬间错Bank。
- [ ] 轮播忙期间快速手动切换，结果符合“手动优先/重置计时”等冻结规则。
- [ ] 进入播放/浮窗/缩略图时是否暂停轮播，符合事先写好的策略。
- [ ] 图片加载失败或媒体拔出时计时不会反复请求、卡死。
- [ ] 调ROT后计时端点和最短/最长周期正确，不出现32bit周期溢出。

## 5. A2：48 kHz测试音入口

- [ ] 单一最终固件中可清晰进入/退出测试音，方法写在演示说明。
- [ ] 音调连续，音量0静音，最大档不明显削波；样本仍按48kHz供给。
- [ ] 测试音切到PCM/暂停静音不破坏HDMI连接，不残留旧音符。
- [ ] 采样节拍/ACR值有自动或观测证据；“听到音调”不能证明精确采样率。

## 6. O1：单项功能精简

一次只精简一个对象，避免把“删灯效+删黑胶+删缩略图”合成一轮。

- [ ] 精简前后采用同输入/策略的独立构建，记录真实资源差值。
- [ ] 若删WS充能，off/VU仍正确；DIP6关闭补发黑帧，重新开启没有旧残留。
- [ ] 若简化蜂鸣，确认/边界/唤醒反馈有确定语义，不连续长鸣。
- [ ] 若简化黑胶，封面/MV、暂停、Seek、读口交接均正确。
- [ ] 若计划删缩略图，先提供经过验收的FPGA缩放替代能力与选图入口。
- [ ] 若资源下降但时序失败，标记失败，恢复上一accepted。

## 7. B1：EC2音量与唯一CSR

- [ ] CW增、CCW减，实际方向与文字/数值一致。
- [ ] 单步、连续快转、反向、整数计数回绕没有漏累计/反跳。
- [ ] VOL最小/最大端点、静音与默认值一致；边界持续转不会溢出。
- [ ] EC2、KEY04/05、IR音量同时操作，显示与实际声音一致。
- [ ] 音量0继续播放位置推进；暂停时位置不推进；两者区别明确。
- [ ] 调音量不触发EC1 Seek、换曲、确认或Home。
- [ ] 切曲和暂停恢复后音量是否保持，符合规格。

## 8. B2/B3：亮度和对比度分别验收

使用同一张灰阶/彩条/高低亮度照片，避免凭一张随机封面判断。

- [ ] BRI各档可辨，最大档/默认档符合公式；零/低档不产生随机亮点。
- [ ] CON中性档输出恒等，低/高档暗部和亮部有正确变化。
- [ ] RGB=0/127/128/255、负中间结果与饱和端点在自动验证中正确。
- [ ] 连续调节时每帧整屏一致，不产生参数只作用半帧的横线。
- [ ] MV、封面、转场下效果都生效，OSD文字仍可读。
- [ ] 音频不受调节阻塞；追加乘法/查表后完整route仍通过。

## 9. B4/B5：EC2浮窗、ROT与WSL

- [ ] 第一次旋转/外部音量事件即可出现浮窗，不等第二次操作。
- [ ] SELECT/ADJUST视觉清晰，按压动作不误执行播放/暂停。
- [ ] 边界旋转也续时；活动与超时同拍时操作优先级符合规则。
- [ ] 连续快转不冻结页面，切曲/媒体恢复可正常处理。
- [ ] 文字起点非8px对齐时无切列错位；数值/条形最大端点完整。
- [ ] 自动隐藏后底图、歌词、波形恢复，无旧框残影。
- [ ] 0/最大/无变化值、同时KEY/IR操作均一致。
- [ ] ROT确实改变图片轮播周期，不误改EOF下一曲。
- [ ] WSL确实改变灯带亮度，不改变颜色通道顺序/串行时序，DIP6有效。

## 10. C1/C2：文字数据与播放页

- [ ] 至少两首可辨别曲目；每曲名字、歌手、歌词、音频对应。
- [ ] 旧卡/文字侧车缺失/坏CRC/越界时可播放，文字安全回退。
- [ ] 快速切曲时不会出现新封面配旧歌名/旧歌词；迟到资源不覆盖新曲。
- [ ] 暂停、Seek、重播与时间/进度一致；未知时长条不错误显示全满。
- [ ] 进度0和100%准确，接近EOF不越界；不因计算阻塞像素链。
- [ ] 封面/黑胶/MV三个场景的布局、占位、字体边界可读。
- [ ] 没有浮窗时所有文字完整；出现浮窗时遮挡规则明确。
- [ ] 波形保留，随真实PCM/音量变化，暂停/静音有确定表现。
- [ ] 数据侧车只增加文字逻辑，不顺带加入未验收的后台背景系统。

## 11. D1/D2/D3：五行歌词

- [ ] 用五条明显不同的文本证明五行独立，不是同一行重复五次。
- [ ] 首行前两槽、末行后两槽为空，空歌词/超长句有定义。
- [ ] 中央行时间定位正确，同时间戳策略明确；Seek向前/向后皆正确。
- [ ] 正常跨行只动画一次，完成后不立即重复滚动。
- [ ] 16帧位移单调，不在第11帧附近回绕；终点衔接无明显跳回。
- [ ] 暂停、重播、切曲中止/恢复动画与冻结规则一致。
- [ ] 进入MV布局不截中央大字；必要时离线分行而不是静默截四字。
- [ ] 32px中央字只用共享字库，首列/末列/行边界无错字或上一行残留。
- [ ] KEY06切换五行/单行/隐藏（若设计这些模式）不影响播放和其他键。
- [ ] 完整歌曲至少运行一次，歌词更新无累积音画漂移。

## 12. E1：不同分辨率BMP读图与缩放

- [ ] 卡中同时放真实320×240和640×480的24bit BMP；不是PC统一缩好的同尺寸图。
- [ ] FPGA根据BMP头读取真实尺寸并执行缩放；规则写清楚。
- [ ] 四角标记、格线、非对称图案不镜像/错行，颜色通道正确。
- [ ] 支持集合中的padding/方向处理正确；集合之外明确拒绝并安全回退。
- [ ] 手动与自动切图、转场、缩略图/全屏交接均无撕裂。
- [ ] 装载期缩放不导致音频下溢或SD事务无法完成。

## 13. F1：最终整机与比赛证据

下面次数/时长是本项目建议目标，不是官方逐项固定次数。

- [ ] 每项基础和五项扩展都有实际演示入口、源码定位与短证据视频。
- [ ] 同一个最终固件完整跑一遍，不能拿几个互斥bit拼成“全部实现”。
- [ ] 正常卡完整播放/轮播60分钟无明显花屏、卡死、音频下溢。
- [ ] 快速混合操作：切曲、Seek、EC2、浮窗、模式切换，至少100轮。
- [ ] 好卡/坏INDEX/缺文字/坏BMP/拔插恢复均按规格。
- [ ] Flash固化后完全断电冷启动至少30次，初始化/Logo/媒体进入可靠。
- [ ] 条件允许时至少两种HDMI sink测试画面与声音，不假设一台显示器兼容即普遍兼容。
- [ ] 最终commit/源/约束/资产/bit哈希完整绑定，开放告警如实登记。
- [ ] 演示说明准确写原始PCM/MV，不宣传MP4解码或FFT频谱等未实现能力。

只有F1完整通过，才可以把“用户目标：四项基础与全部五项扩展”标记为最终完成。
