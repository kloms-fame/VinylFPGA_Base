## 2. N2 改动与功能保留

唯一候选产品文件为 `src/SD/song_index_db.v`。其他产品源码不变，N1 目录名改动未叠加。

原 16 位 `hdr_version` 改为低字节 v1/v2 两个匹配标志和一个高字节匹配标志。offset 8 更新低字节分类，offset 9 更新高字节分类；只有高字节为零且低字节分别为 1/2 时才识别合法版本。四个 MV 输出、一处版本错误判断、四个发布 flags 共九处消费者使用分类结果。

保留模块接口、参数、FSM、CRC、错误优先级、P_FIN 发布节拍、busy 时 start 门控、in_valid/in_done 同拍行为、byte_idx 回卷、部分头部保持和全部 MV/音频/封面输出。v1、v2、非法 16 位版本处理及无/坏 INDEX 的上层回退均未删除。

首版高字节存储 `hi_zero`，复位为 1。检查真实 MCP 网表后，最后只试一次等价极性变体：存储 `hi_nonzero`，复位和接受 start 均为 0；offset 9 使用逻辑 `in_byte != 8'd0`，`hi_zero = !hi_nonzero`。这是三 FF 同零复位的表示变化，四态语义保留，未使用 case inequality。反向替换极性变化后与首版逐字节一致。

## 3. 仿真与独立复核

冻结参考模块 `song_index_db_reference.v` 与 E before 仅模块名及 include guard 改名；原始行为没有按新实现重写。新 TB 在 NBA 后比较全部 18 个公共输出，并核对 DUT 实际版本分类线与独立 16 位原始版本模型。

- before 使用 baseline 宏：PASS；两版候选默认编译均不启用该宏，实际候选分支 PASS。
- 所有 65,536 个二值版本通过实际 offset 0–9 字节流输入 DUT；另含 16 个 X/Z 用例，覆盖完整/截断头部、已知失配压过未知值。
- 最终 TB 每版 942825 拍、1885650 次实际分类检查；补充分类模型 458752 次检查单独统计，不混充实际版本穷举。
- 有效 v1/v2 与 MV 正向检查、CRC/错误优先级、流错误、复位、忙中 start、同时 valid/done、回卷与部分更新均覆盖。
- 临时低两位匹配负例在 0x0101 版本触发公开 valid 差分失败；负例已撤销，证据保留。
- 七项规定定向测试全部 PASS；另加 N1 目录接口差分与 `tb_mv_index`，合计九项定向 PASS。
- baseline、N1、N2 首版、最后变体完整默认 runner 均为 **53 项、40 PASS / 13 FAIL**，失败集合完全一致；runner exit=1。新等价 TB 另行执行，未暗中改变默认 53 项口径。
- N2 首版及极性变体分别通过独立规格和质量复核；最后变体无 blocker，四态覆盖建议已落实。
