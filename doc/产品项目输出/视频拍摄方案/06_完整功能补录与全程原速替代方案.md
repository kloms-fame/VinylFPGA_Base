# 完整功能补录与全程原速替代方案

> 主方案覆盖正常用户功能类别，补录用于保留更细分的真实行为证据。本文是计划，不是新增测试记录。

主片默认软重启，断电恢复可换入同一时间槽；两种路线的T分别实测。断电版须事先确认配置Flash可自启和完整失电，不由软复位代替。

## 1. 为什么不能用一个图标证明所有行为

KEY12可以在三种曲终策略间选择，但图标变化只能证明选择接口。实际曲终暂停、单曲回到开头、列表切到下一曲，是三个独立状态转移，需要分别在真实EOF观察。

同样，保存指示不证明所有参数组合的掉电原子性；一段60秒播放不证明长期无欠载；手机录到音乐不测得48kHz精度。内部实现可以简要讲解，实测主张需要对应记录。

| 补录编号 | 拍摄内容 | 准备与动作 | 判定画面 |
|---|---|---|---|
| E01 | 曲终暂停 | 用真实Seek接近曲尾，选择暂停策略；录像开始后自然播完最后若干秒 | 时间停止/暂停状态，不自动换曲 |

| E04 | 所有背景 | 等背景资源实际加载，再分别停留灰底/虚化/艺术图 | 每个独立画面均可识别，不用灰底回退冒充 |
| E05 | 自动保存专门证据 | 开SW3；在默认/恢复事务均结束后改一项非默认值；不再改参等满5秒 | 忙指示及已保存；然后再复位/复电核对 |
| E06 | 真实断电自启及五参数恢复 | 所有值改为已记录的非默认设置、保存并等忙灭、真实断电复电，SELECT逐项查看 | 五个实际值逐项一致 |

每条可另存一段原速、完整因果过程的短视频。短片没有放进去的项，在提交说明里列清楚，不用片尾长列表假装已逐一展示。

## 3. 主片的功能层级

- 主片应直接看到：手动/自动封面、转场、音乐、歌词/进度/波形、MV/背景、播放/暂停/Seek/切曲/重播、两类消隐、参数调节、默认恢复、保存与软重启恢复（可选真实断电）、转盘和灯效。
- 可代表性展示：多个等价物理键/红外码、所有亮度档位、所有DIP组合。入口对应见05，不能每个都占主片一段。
- 需补录独立分支：三个EOF结果、完整五参逐项长核对、极值/错误处理、长期运行。
- 以源码/报告说明：FIFO/CDC、CRC、SDRAM字节通道、三缓冲、采样时基、时序/资源。
- 不列入当前功能：FFT、通用音视频解码、未接入缩放、2×2缩略图、动态任意LRC导入、播放位置续播、退役UART。

## 4. 严格全程1×的三分钟方案

若成片也要求全程实时，推荐删掉主片的完整60秒自动消隐等待，保留手动消隐/首键唤醒，自动消隐移到E类补充原片。这样能把关键操作拍得更清楚：

| 原速时间 | 内容 |
|---|---|
| 0–6 | 定位与整机 |
| 6–27 | 手动/自动封面及两种转场 |
| 27–48 | 播放原声、唱针、暂停恢复 |
| 48–68 | Seek、切曲、重播 |
| 68–90 | MV、背景、波形、静音、手动消隐 |
| 90–122 | 五参数与默认恢复、模式/灯效 |
| 122–130 | 保存并观察完成 |
| 130–132 | 默认准备E9，在132秒触发；可选断电并在132秒复电 |
| 132–132+T | 对应模式原速启动至浏览可用 |
| 132+T–144+T | 参数核对与重新播放 |
| 144+T–152+T | 收尾 |

该原速版本总长152+T，T≤26秒时不超过178秒。若T=20秒，则为172秒。它没有完整证明自动消隐60秒定时，字幕应据实标记，不能借用手动息屏代替。

## 5. 若必须原速保留自动消隐

让L表示最后一次有效输入发生的原片秒数，随后留60秒等待、2秒消隐听音、4秒唤醒、2秒重启准备、T秒启动、12秒核对、8秒收尾：

~~~text
总时长 = L + 88 + T
要在178秒内：L ≤ 90 − T
T=20秒：最后一次有效输入需在70秒前完成
~~~

70秒不足以从容把主方案112秒内的所有动作和细节都拍清楚。必须删减重复控制、全部背景轮换或部分维护流程，保留最有说服力的功能族；不能承诺同样覆盖且仍原速≤3分钟。

这条公式与主方案的4×预算不是同一个版本。不要拿某版本的片头和另一个版本的结尾直接拼时间表。

## 6. 超时、失败和资源未就绪

1. 如果只是旁白太长，先删形容词和重复讲解，不加快实际操作来挤时间。
2. 若SD/背景/Seek反应比预算慢，重新测关键动作；让画面稳定后再操作。
3. 若自动消隐未触发，检查最后有效输入、DIP4、红外干扰和真实计时；不能后期做纯黑画面补结果。
4. 若保存或恢复不一致，当前素材不能作为成功证据。先确认固件、实际值和保存状态，再决定重新排练。
5. 若掉电后不能自启，不能靠电脑重新下载后接回镜头；改拍真实软复位并改名，或在自启配置完成后重新录。
6. 若全片某一步失败，保留原片用于定位，最终成功主片重新完整拍摄；不删除失败中间部分又称全程实时。

如果赛事最终提交规则不允许任何变速，直接采用第4节原速主片，并把自动消隐完整过程作为补充；SOP是拍摄建议，具体提交格式和限制仍以用户拿到的赛方要求为准。
