# 软重启与断电自启：双版本拍摄卡

> 已纳入用户最新要求：手机固定机位、一人操作；可以展示软重启，也可以展示真实断电自启或断电恢复。以下是拍摄计划，不是已完成的板上验证。

## 1. 怎么选主片版本

| 路线 | 适合情况 | 镜头能直接证明什么 | 准确字幕 |
|---|---|---|---|
| A：默认软重启 | 希望操作简洁，先按已确认方案排练 | 本次复位启动后，五项用户参数从保存记录恢复 | 保存设置 → 软重启 → 参数恢复 |
| B：真实断电复电 | 实物已能脱离下载器上电运行，断电与启动时间符合预算 | 本次真实失电后能够自启；重开参数面板，保存值仍一致 | 真实断电 → 上电自启 → 参数恢复 |

若B路线实际可用且时长合适，建议正式成片选B：同一段同时呈现独立启动能力与用户习惯记忆。A保留为更容易执行的替代版。无需在三分钟内把两种重启都重复拍一遍。

“断电自启”与“参数恢复”是两个结果：自动进入浏览页证明本次自启；五项非默认值与保存前一致才证明本次参数恢复。出现Logo不能单独证明后者。两条路线均不称播放位置续播。

## 2. 统一的准备动作

按主脚本，最终拟保存值为 VOL168、BRI2、CON3、ROT1、WSL2。拍摄参数面板和手动保存，等母板LED3忙结束、LED2已保存亮；发生故障时不继续宣称保存成功。

前面展示恢复默认后，还要按脚本重新修改这五项。不要保存前全是默认值，恢复后也全是默认值，却把没有前后差异的画面当作记忆证据。

112秒最后一次E6是空闲计时锚点。随后不操作满60秒，拍自然消隐、原声和唤醒，再进入下面的替换段。无人操作中仅前58秒4×，最后2秒与消隐边沿原速。

## 3. A路线：软重启拍法

| 原片时间 | 单人操作 | 后期说明 |
|---|---|---|
| 178–180秒 | 手持遥控器进入画面，对准接收器；在180秒锚点发送E916FF00 | 红外E9：软重启；无二次确认 |
| 180–180+T | 不再按键，原速保留实际重启到浏览页可用 | 实际启动过程，原速 |
| 后续12秒 | 按EC2进入SELECT，旋转逐项查看保存值；然后重新选曲播放 | 五项设置与保存前一致 |
| 最后8秒 | 手离开，整机继续运行 | 本地媒体 / 音画联动 / 实体交互 |

旁白：“现在软重启，核对保存的设置。”启动等待较长时，可补一句：“整个启动过程保留原速。”

源码依据：`src/io/ui_command_router.v`把E9映射到重启请求，且`restart_confirm_active`固定为0；`src/top_tf_hdmi_audio.v`用`restart_req`触发`soft_rst_n`，经`ext_rst_n`向各域复位；参数CSR与持久化模块连接`exp_rst_n`。这解释复位路径，不代表本轮已经上板测过。

## 4. B路线：真实断电自启/恢复拍法

先在实际装置上确认配置Flash可自启。检查USB下载器及其他可能反供路径，设备失电动作与板卡、屏幕反馈在同一画面内。显示器可独立供电；不要只关显示器或拔HDMI。

| 原片时间 | 单人操作 | 后期说明 |
|---|---|---|
| 178–180秒 | 使用现有设备供电开关切断板卡供电，拍到实际失电；180秒重新供电 | 真实断电 / 重新上电 |
| 180–180+T | 不按复位、不重新下载固件，原速拍完实际上电启动 | 上电自启，启动等待原速 |
| 后续12秒 | 浏览可用后进入EC2 SELECT逐项核对，再重新播放 | 五项用户参数断电恢复 |
| 最后8秒 | 整机正常工作 | 体验闭环完成 |

旁白：“接着真实断电、重新上电，核对保存的设置。”不要添加设备不存在的自动恢复播放位置解说。

2秒只是供电操作的拍摄预算，不是保证任何电路都能充分放电的规范。若实物指示灯未灭或需要更长时间，延长此段为P秒，并重新计算成片为 **154.5+P+T** 秒；启动、核对与结尾的时间轴均相应后移，现有生成器的固定2秒模板也需人工校准。不能为硬凑2秒而假称已经断电。

## 5. T分别怎么测、时长怎么算

- 软重启T：E9事件被接受，到浏览页稳定且可接受操作。
- 断电T：实际重新接通供电，到同一浏览可用终点。
- T不含后续12秒核对。两种路线不能共用一次测量值。
- 默认供电/触发准备2秒时：原片200+T，成片156.5+T。
- T=20仅为示例：原片3分40秒，成片2分56.5秒；T≤21.5可留至少2秒余量。
- 如果T更长，优先减少前段等价操作、减少背景遍历，或按06选择原速替代方案；不加速关键启动过程。

恢复核对时，EC2保持SELECT，只旋转选参数，不进入ADJUST。每项停约0.8–1秒，下次动作应在1.8秒隐藏超时前完成；如果已经隐藏，先按压重新进入SELECT，不能直接旋转，因为隐藏态旋转会改音量。若12秒读不清，就延长并回收其他段预算。

## 6. 对应字幕一键生成

在本目录运行；示例T必须替换为各自实测值：

~~~powershell
# A：默认软重启
python ./字幕生成器.py --startup-seconds 18.5 --restart-mode soft
# B：真实断电复电
python ./字幕生成器.py --startup-seconds 20 --restart-mode power
~~~

默认写入不同子目录：字幕输出_soft_T18.5秒、字幕输出_power_T20秒。每个目录含旁白SRT、功能标签SRT、配音TXT与原片/成片分镜CSV。根目录附带的T20排练素材属于默认软重启版。

生成器只调整T及重启路线；若最后输入时刻、供电动作P、参数核对时长或前段动作发生变化，仍需对照真实视频手动重排。文件生成成功不代表设备功能已经拍摄或验证成功。
