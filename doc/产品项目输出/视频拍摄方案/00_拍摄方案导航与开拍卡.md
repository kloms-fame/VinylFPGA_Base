## 推荐采用的方案

**连续拍一条原片，关键操作全程原速，真实60秒无人操作中，仅前58秒标注4倍速，最后2秒与消隐触发恢复原速。** 所有基础/扩展/体验功能顺着一次听歌流程出现，参数保存、重启与恢复保留原速；断电分支以实际可自启为前提。

定义T：默认从红外E9软重启被接受，到浏览页稳定可操作；断电分支从真实重新供电起计，到同一终点。

~~~text
原片时长：200 + T
成片时长：156.5 + T
T=20秒：原片3:40，成片2:56.5
T≤21.5秒：成片≤2:58
~~~

拍摄过程一镜到底，成片包含公开标注的变速。它不称为全程实时录像。若你的“一镜到底”要求成片也必须每秒对应现场一秒，采用06的原速方案并接受其功能取舍。

SOP中的3:15和备注4–5分钟不作为本片预算；成片连同片头片尾严格小于180秒。本文没有承诺未经排练的“完美一次成功”。

## 一张操作口令卡

| 原片时间 | 操作者口令 |
|---|---|
| 0–6 | 整机亮相，手离开 |
| 6–12 | EC1正反选封面 |
| 12–18 | DIP2自动轮播一次，再关 |
| 18–26 | KEY9擦入+换图；KEY9淡变+换图 |
| 26–32 | 按EC1播放，留原声 |
| 32–44 | 放针、暂停/恢复、抬针/落针 |
| 44–59 | EC1正反Seek；KEY3/1切曲；IR B9重播 |
| 59–75 | MV/封面、背景；IR F6息屏/首键唤醒；F3静音恢复 |
| 75–102 | 默认恢复；EC2依次改VOL/BRI/CON/ROT/WSL |
| 102–107 | 曲终模式/VU；拍到真实自动保存才保留该标签 |
| 107–112 | F8减音量到168；E6保存并等成功；112最后E6 |
| 112–172 | 完全不操作，真实等60秒 |
| 172–178 | 原速黑屏听音，再首键唤醒 |
| 178–180 | 默认对准遥控，在180秒锚点发E9；断电版改为断电灯灭、180秒复电 |
| 180–180+T | 原速拍完真实启动 |
| 180+T–192+T | 只在SELECT查看五参数，再重新播放 |
| 最后8秒 | 整机持续工作，收尾 |

“全部功能”按05逐项标识：主片直接演示、等价入口、补录分支、内部设计说明。三种曲终结果、所有故障/输入组合和长时间稳定性不能由一次短片证明。

## 开拍前的四个判断

- 最终使用的固件和TF/ROM素材配套，所有目标画面能出现，记录实际bit哈希。
- 镜头能同时解释“谁操作、哪里变化”，屏幕不反光，画质调节时相机曝光不跟随补偿。
- 不以按键次数作为覆盖标准；以关键因果动作、参数面板和真实反馈为主，不在现场临时调试。
- 拍前完整排练，确认112秒操作预算、60秒自动消隐、T与12秒恢复核对均可完成；不能完成就按06重新分配。

本执行包含8份Markdown、软重启与断电版T20排练素材。已核对文档本地链接，以及两种重启路线共22组T取值下的字幕先后顺序、分镜连续性和变速时长计算，未发现格式/时间轴问题。以上属于文本素材检查，不代表实物排练通过。

本执行包仅读取SOP、当前RTL与已有报告，并进行字幕/文件格式检查；未操作硬件、未重跑工程构建。原有27份项目分析文档保持原样。
