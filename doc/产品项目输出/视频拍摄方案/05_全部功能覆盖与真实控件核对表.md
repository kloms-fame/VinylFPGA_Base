# 05｜全部功能覆盖与真实控件核对表

> 用途：拍摄前逐项核对当前 RTL 的功能与操作，防止沿用旧键位说明；与主片脚本配合使用。本文来自当前代码、顶层接线和约束的只读分析，没有操作硬件、重跑测试或确认任何遥控器实体标签。它是功能覆盖计划，不是“全部功能已测试通过”的验收报告。
>
> 用户已确认项目开发完成并已完赛。本文将完赛事实与本轮拍摄能留下的证据分别说明。源文件中的历史注释、旧产品手册和遥控器名称冲突时，以当前解码表达式、实际连线及实物排练结果为准。

## 1. 拍摄前先统一编号和状态

“扩展 KEY1～KEY12”指 `exp_key_n[0]～[11]`，事件索引为编号减一；“母板 KEY1～KEY4”是另一组控件。拍摄时说“母板保存键”或“扩展板确认键”，避免两个 KEY3 混淆。现有文档还使用 SW3、SW4 等扩展板丝印称谓；本文以 RTL 逻辑名和 ADC 引脚定位，未额外用原理图/实物照片确认所有面板丝印。

本片连续拍摄约200+T秒。真实60秒无人操作中，仅前58秒4×，触发前2秒及后续全部1×；成片156.5+T秒。T=20仅为示例，成片176.5秒；T≤21.5可控制在178秒以内。T默认从E9软重启被接受到浏览可用，断电版改为实际复电起计，两者分别实测。

主片默认“保存后软重启恢复参数”，红外E916FF00立即生效、没有二次确认。可在同一位置改拍真实断电复电；只有该分支证明实际掉电后自启及参数恢复。下文所有冷启动/反供检查按断电分支执行。

关键时间口径如下：

| 源素材时间 | 计划内容 | 本表关心的证据 |
|---|---|---|
| 0～26秒 | 浏览、转场、自动轮播 | 手动换封面、真实轮播完成、不同转场 |
| 26～59秒 | 播放、暂停、唱针、Seek、切歌、重播 | 声音/画面/时间及机械反馈相互印证 |
| 59～75秒 | MV/封面、背景、手动息屏和静音 | 区分模式选择和实际结束行为 |
| 75～102秒 | EC2五参数及恢复默认 | 每项参数有非默认值；恢复默认前后可对比 |
| 102～107秒 | 不再改参，演示KEY12策略/KEY10 VU，条件性观察自动保存 | 保存计时不被参数更新重置，忙/已保存灯可见 |
| 108秒 | 红外音量减 | 让当前参数确实变脏，母板已保存灯灭 |
| 109秒 | 红外E6手动保存 | 五参数快照写入，等待忙灭、已保存亮 |
| 112秒 | 最后一次红外E6作为明确空闲锚点；MV状态提前确认 | 有效IR帧重置空闲计时；参数未变不代表又写了一笔Flash |
| 112～172秒 | 真实60秒不碰控件 | 连续画面、声音和时间推进；之后自动纯黑 |
| 172秒以后 | 唤醒、软重启（或真实断电）、恢复核对 | 首键只唤醒；Flash参数恢复，结尾完整播放 |

**112秒最后动作与60秒计时要以原片实际动作时间校正。** 消抖、红外事件和帧边界会带来小量延迟，自动黑屏应自然发生，不能在预定秒数手动代替。拨码、旋钮、遥控或人为触碰都不安排在该等待段；保留原始连续素材供核对。主片无需塞入全部等价按键、红外码和拨码组合；下文标明需要补录的分支。

## 2. 四种覆盖状态

| 状态 | 含义 | 视频中允许的说法 |
|---|---|---|
| 主片可见 | 主脚本安排了动作及可见/可听结果 | “本次画面展示了……”；按实际素材确认 |
| 等价或需补录 | 代码存在，但主片只拍了等价入口，或未覆盖该分支 | “支持……”可由代码说明；不能说本片逐项验收 |
| 内部设计字幕 | 位于数据通路/控制通路，短片只能给设计说明 | “采用……设计”；不能由画面推出全部边界已证明 |
| 未集成/未证实 | 当前没有业务连线，或缺实物证据 | 不列为当前已演示功能；可列后续方向 |

同一功能族可以同时有主片可见部分和需补录分支。例如主片展示EOF策略图标，实际“播放到末尾暂停/重播/下一首”仍需分别补录。

## 3. 扩展板KEY1～KEY12逐项核对

依据：[事件桥](../../../src/io/ui_event_bridge.v)、[浏览状态适配](../../../src/io/browse_fsm.v)、[播放控制](../../../src/audio/play_ctrl.v)、[引脚ADC](../../../constraints/pin.adc)。事件桥约第75～100、146～152行是当前解码依据。

| 扩展键/端口/引脚 | 浏览状态 | 播放状态 | 可拍证据与限制 |
|---|---|---|---|
| KEY1，`exp_key_n[0]`，N1 | 上一封面 | 上一曲，按曲目数回绕 | 标题、曲号、封面变化；不是快退 |
| KEY2，`[1]`，M2 | 确认当前封面播放 | 暂停/恢复；EOF暂停结束后确认可重启 | 声音和进度停/走；与EC1按压等价 |
| KEY3，`[2]`，M1 | 下一封面 | 下一曲，按曲目数回绕 | 标题、曲号和音频变化；不是快进 |
| KEY4，`[3]`，L1 | 上一封面 | 音量加16，最大255 | OSD音量和声音；不是歌词上翻行 |
| KEY5，`[4]`，H2 | 下一封面 | 音量减16，最小0 | OSD音量和声音；不是歌词下翻行 |
| KEY6，`[5]`，H1 | 未发现当前业务动作 | 未发现歌词动效动作 | 可有输入反馈音/动作灯，但这不能证明歌词功能 |
| KEY7，`[6]`，G1 | 不启动播放 | 退出播放，回中央封面浏览 | 歌词播放页回浏览页、电机停止 |
| KEY8，`[7]`，G3 | 无有效播放视窗切换 | MV/静态封面显示选择 | 等MV显示有效后切换；没有旋转几何绘制承诺 |
| KEY9，`[8]`，L4 | 循环选择封面转场 | 可改变模式，但播放页对浏览转场做保护 | 先按键再在浏览页换封面，才展示实际转场 |
| KEY10，`[9]`，L5 | J2灯带全灭/VU切换 | 同左 | 只影响J2 VU灯带，不影响唱片灯带或电机 |
| KEY11，`[10]`，J12 | 当前不累积背景切换 | 灰→歌曲虚化图→艺术图1→艺术图2 | 每次等资源就绪；灰底回退不算已展示对应图 |
| KEY12，`[11]`，K11 | 可改变策略状态，浏览页不显示策略图标 | 循环播完暂停/单曲循环/列表下一首 | 图标在帧边界更新；三种实际EOF行为需补录 |

KEY1/3切曲后会清除暂停并请求会话重启，从新曲起点开始。默认EOF策略为列表下一首（内部值2）；因此复位后第一次KEY12切到播完暂停（0），第二次到单曲循环（1），第三次回列表下一首（2）。见 `play_ctrl.v` 的复位 `end_mode<=2` 和 `mode_event` 分支。

转场初始为0直切，KEY9依次切为1水平擦入、2淡出/淡入、0直切。来源为顶层 `effect_mode` 的0/1/2循环及 [video_fade_transition](../../../src/display/video_fade_transition.v)。当前擦入按16帧推进，约0.27秒量级；淡出/淡入分阶段推进，还包含bank切换等待，不能承诺所有卡型固定响应时长。播放页使用 `preserve_media` 保护，拍摄转场应回到浏览页操作。

## 4. EC1与EC2的真实状态机

### 4.1 EC1：选曲、暂停和Seek

| 动作 | 浏览 | 播放 | 证据 |
|---|---|---|---|
| 顺时针一步 | 下一封面 | 向曲尾Seek 2秒 | 曲目或时间跳变 |
| 逆时针一步 | 上一封面 | 向曲首Seek 2秒 | 曲目或时间跳变 |
| 按压 | 确认当前封面播放 | 暂停/恢复 | 音频、时间、唱片机械反馈 |

事件桥依编码器累计计数还原步数，见 `ui_event_bridge.v` 的 `enc_target/enc_delivered`；Seek依据 [seek_controller](../../../src/audio/seek_controller.v) 的 `STEP_ENC=96000`，即48kHz下2秒。接受条件为 `play_active && total_samples!=0`，目标钳位到合法样本范围。Seek后的排空、重新取数和起播时间依硬件/介质状态决定；给镜头留出稳定时间后再进行下一动作。

### 4.2 EC2：选择与调节要分开

依据：[ec2_param_controller](../../../src/io/ec2_param_controller.v)、[EC2事件重放](../../../src/io/ec2_event_replay.v)、[参数CSR](../../../src/io/ui_param_csr.v)。顶层以 `PARAM_COUNT(5)` 实例化控制器。

~~~text
隐藏态按压 → SELECT选择态
SELECT旋转 → 选择 VOL / BRI / CON / ROT / WSL
SELECT按压 → ADJUST调节态
ADJUST旋转 → 修改当前所选参数
ADJUST按压 → SELECT选择态
无操作1.8秒 → 隐藏
隐藏态直接旋转 → 进入VOL调节并立即改音量
~~~

按压不会直接循环参数，也没有当前实现的“长按退出”承诺。状态隐藏后所选项不必自动归零；按压呼出可能仍选中上一项。拍摄每一段操作以屏幕SELECT/ADJUST和参数名为准，不按记忆盲转。顶层 `ec2_control_enable` 要求媒体已挂载、Boot结束、未消隐、扩展动作就绪；消隐时先完成唤醒，再调参数。

| 参数 | 取值、默认与步长 | 主片应呈现的非默认值和恢复对比 |
|---|---|---|
| VOL | 0～255，步长16，默认200，边界饱和 | 例如200→184，OSD和声音同变 |
| BRI | 0～4，对应0.25/0.5/0.75/1/1.25倍，默认3 | 2026-10-21封版已在最终合成像素路径统一校正，播放画面、MV、封面、OSD与启动图均参与；拍摄锁定曝光 |
| CON | 0～4，对应0.5/0.75/1/1.25/1.5倍，默认2 | 图像对比变化；按实际素材选择明显画面 |
| ROT | 0关闭，1/2/3/4/5为2/3/5/10/20秒，默认2 | OSD档位变化；真实轮播在浏览页、DIP2开启才发生 |
| WSL | 0～4为0/25/50/75/100%安全调色板亮度，默认4 | 两路灯带同档变化；0档只关灯，不关闭电机 |

75～102秒展示恢复默认时，先留下非默认值，再按母板KEY2或红外F2，拍到回到 `VOL200/BRI3/CON2/ROT2/WSL4`。若画面原本全是默认值，按一下不能证明恢复动作。102～107秒演示KEY12/KEY10可改变策略标识或输出而不修改这五项参数，适合保留参数停变计时窗口。

## 5. 母板控件、保存与重启恢复

依据：[扩展集成与母板输入](../../../src/io/expansion_integration.v)、[参数持久化](../../../src/io/ui_param_persistence.v)、[Flash记录](../../../src/io/w25q64_param_store.v)、[顶层](../../../src/top_tf_hdmi_audio.v)。

| 母板控件 | 当前功能 | 拍摄与证据 |
|---|---|---|
| KEY1 / rst_n | 全局硬件复位 | 与断电是不同操作；复位不证明上电配置Flash已正确固化 |
| KEY2 / B2 | 五参数恢复默认；提交默认记录并清理旧槽 | 先拍非默认值，后拍默认值；等待忙结束，不把它当临时恢复 |
| KEY3 / B1 | 手动保存五参数快照 | 必须先改参使dirty，拍母板LED2灭→保存后亮 |
| KEY4 / C1 | 静音/恢复，媒体时间继续 | 声音消失，进度仍走；再次恢复原音量 |
| SW1 / C8 | 数码管总使能 | 关/开显示不影响播放；非主片必拍项 |
| SW2 / C7 | 启动500ms保护窗结束后采样一次，决定Boot旁路 | 运行时拨动不重演Boot；可补录不同启动策略 |
| SW3 / C6 | 参数停止更新5秒后自动保存 | 修改后不再调参；忙灯结束、已保存灯亮才是事务证据 |
| SW4 / C5 | 可产生拨动反馈音；未发现当前告警门控连线 | 旧手册“告警总开关”不纳入当前主片功能 |
| 硬件SW5 | 母板蜂鸣器回路通断 | 不占FPGA输入；需实物接通才听得到反馈 |

`ui_param_persistence` 的自动保存条件包含 `auto_enable && dirty && idle_ms>=5000`，且Flash可用、不忙、没有新的参数更新/维护请求。KEY10和DIP6不修改五项参数；EC2、播放音量键和红外音量会更新参数并重新开始等待。因此108秒红外音量减应在前面恢复/自动保存已完成后执行，形成新的dirty，109秒E6再明确演示手动保存。

恢复默认本身会排队提交默认记录，不依赖SW3开启；所以若75～102秒已触发恢复默认，102～107秒可能观察到的是默认记录事务或已保存状态，而非一笔新自动保存。**不能把这个等待窗口必然解说为自动保存发生。** 若主片需要证明5秒自动保存，应在102秒之前完成一次新的非默认参数修改，并在原片标出最后改参时刻；若无法在排练中同时保持主脚本既定动作，则把“自动保存5秒机制”作为代码说明，另补录独立分支。手动保存按108/109秒明确展示，重启恢复按主脚本后段执行。

Flash事务时长不固定。低层具有上电等待、WEL/WIP检查、擦除/编程、回读及提交等阶段；不可用“等1秒”替代状态确认。断电前必须确认母板LED3忙灭、LED2已保存亮。若记录未完成或报故障，这一条素材不得宣称保存成功。

本系统保存的只有五项参数，不保存播放位置、当前曲目、暂停状态、背景选择、转场模式、灯效模式或EOF策略。所选方式重启后在OSD重新打开VOL看到已保存非默认值，结合母板LED1恢复指示，是主片核心证据；不能口播“断电续播”。

## 6. 六位DIP与门控条件

拨码逻辑使用消抖后“上拨=1”电平。引脚参见 [pin.adc](../../../constraints/pin.adc)；行为参见 [ui_command_router](../../../src/io/ui_command_router.v) 和 `expansion_integration`。

| DIP/引脚 | 作用 | 主片安排/补录 |
|---|---|---|
| DIP1 / L3 | 在场/动作声明；经过输入稳定后放行扩展事件 | 拍摄前开启；关闭动作输入分支补录。不是所有输出的电源总开关 |
| DIP2 / J3 | 浏览封面自动轮播 | 0～26秒展示后关闭，避免抢走选曲。条件：挂载、显示有效、不在播放、曲目数>1、ROT非0 |
| DIP3 / J4 | 扩展4个业务LED总使能 | 主片开启；关闭全灭可补录 |
| DIP4 / H4 | 60秒无有效操作自动消隐 | 112～172秒真实等待；关闭会清自动计时。主片等待前必须开启 |
| DIP5 / K14 | 红外业务使能 | 主片开启；关闭业务拒绝分支补录，不声称接收头停止电气接收 |
| DIP6 / L12 | 两路WS2812总使能，关闭补发黑帧 | 主片保持开启；补录可短关/开，电机不因此停 |

扩展按键约8ms消抖、编码器相位约1ms稳定；在场重新使能还需输入稳定窗口。上电KEY2/KEY3/KEY4等维护输入另受500ms保护窗约束。实际操作停留至少能被镜头看清，不追求毫秒级连击。

| E31CFF00 | 等效KEY2：确认/暂停恢复 | 等价入口 |
| BD42FF00 | 等效KEY9：转场模式 | 等价入口 |
| B54AFF00 | 等效KEY11：播放背景 | 等价入口 |

红外仅两个5秒Seek允许repeat，最短150ms一次，250ms无新帧后结束连发。无先导repeat、非白名单码和反码错误不执行业务。当前未发现独立红外KEY8视窗、KEY10灯效或KEY12 EOF策略映射，不能依据旧文案补造按键。

手动消隐期间第一次普通业务动作只唤醒、不同时执行切曲/Seek/参数操作；唤醒后再做动作。内部维护脉冲中的保存、默认、静音和重启仍可直接执行，因此演示“首键只唤醒”应选普通确认/方向动作。手动黑屏不能代替60秒自动黑屏的拍摄证据。源码依据为router的 `wake_only`、组合命令门控及内部维护脉冲分支。

## 8. 唱针、电机、双灯带的因果关系

依据：[vinyl_playback_effects](../../../src/io/vinyl_playback_effects.v)、[ws2812_effects](../../../src/io/ws2812_effects.v)、顶层 `u_pcm_tap`。

~~~text
电机使能 = 复位释放 && 已进入播放 && 未暂停 && 唱针输入为低
唱片灯带运行 = 上述播放/唱针条件 && DIP6开启
J2 VU灯带 = DIP6开启 && VU模式 && 最终混音包络；另受WSL亮度缩放
~~~

| 操作/状态 | 音频/媒体时间 | 电机 | 唱片灯带 | J2 VU灯带 |
|---|---|---|---|---|
| 播放、唱针闭合到地 | 推进 | 使能 | 彩色相位效果 | 随混音包络 |
| 抬针 | 继续推进 | 关闭 | 清黑 | 仍可随音乐 |
| 暂停 | 消费位置冻结 | 关闭 | 清黑 | 音频包络退落后灭 |
| 恢复 | 从当前位置继续 | 针闭合时使能 | 针闭合且DIP6开时恢复 | 音频恢复后律动 |
| 静音 | 时间继续、输出音量0 | 不因此关闭 | 不因此关闭 | 包络退落后灭 |
| KEY10切全灭 | 不变 | 不变 | 不变 | 清黑 |
| DIP6关闭 | 不变 | 不变 | 清黑 | 清黑 |
| WSL=0 | 不变 | 不变 | 亮度0 | 亮度0 |
| 返回浏览/停止播放 | 不再播放当前曲 | 关闭 | 清黑 | 视最终音源包络变化，不以此判断停止状态 |

电机输出是外部驱动的逻辑使能，不能口播为FPGA引脚直接驱动电机。DIP6、静音和WSL不是电机停机条件。唱针也不直接暂停音频，抬针演示应保留声音，清楚呈现机械与音频的区别。

两路灯带均为8灯、约20ms刷新；唱片灯相位约125ms推进。J2 VU具有快升慢降，最大幅度释放约640ms量级，加上包络自身衰减，静音后不要求一个像素周期立刻全灭。当前代码未让转盘转速跟音量或歌曲节拍变化，不作此宣传。

## 9. LED、数码管和蜂鸣器：不要拍错证据

### 9.1 扩展板LED，低有效，受DIP3控制

依据：[led_business_driver](../../../src/io/led_business_driver.v) 的最终 `led_n=~{fault|heartbeat,ir,mv,business}`，以此为准。

| 逻辑LED | FPGA引脚 | 当前含义 | 镜头证据 |
|---|---|---|---|
| LED1/bit0 | H3 | 接受业务动作后亮80ms | 按键/旋钮动作响应，不是“播放状态常亮” |
| LED2/bit1 | H5 | MV显示激活 | KEY8切MV/封面后随状态变化，不是“暂停灯” |
| LED3/bit2 | F3 | 合法红外业务接收后亮80ms | 遥控动作时闪，不是MV灯 |
| LED4/bit3 | E2 | 正常1Hz心跳；故障时常亮 | 正常运行闪烁，不能将每个亮周期说成故障 |

### 9.2 母板LED，高有效

| LED | 当前含义 | 保存/复电怎么读 |
|---|---|---|
| LED1 | 本次启动接受有效Flash参数恢复 | 冷启动后亮，配合OSD值确认恢复 |
| LED2 | 当前五参数已持久保存 | 改参变脏后灭，保存完成后亮 |
| LED3 | Flash启动/事务忙 | 等其熄灭后才考虑断电演示 |
| LED4 | Flash故障或媒体错误 | 正常拍摄不应以它的亮作为“保存成功” |

依据 `ui_param_persistence.led_status` 和顶层 `led=nvm_led_status|媒体错误位`。母板和扩展板LED的编号含义完全不同。

### 9.3 数码管

依据：[seg_business_mux](../../../src/display/seg_business_mux.v)、顶层 `u_seg_business_mux`。固定格式为 `MM-SS 空白 NN`，浏览显示所选曲总时长，播放显示已消费样本时间；曲号从01起。暂停冻结、Seek跳变、重播回起点都可辅助证据。SW1使能关闭只熄显示，不停止播放器。旧手册“状态码/诊断页切换”不属于当前固定业务显示。

### 9.4 蜂鸣器

依据：[buzzer_feedback](../../../src/io/buzzer_feedback.v)、`expansion_integration.sound_events_q`。当前反馈覆盖按键、拨码、编码器步进/按压、红外新帧及自动轮播确认；母板蜂鸣器与EXT1同源，其他EXT输出保持安全值。总参数默认开启，母板SW5必须物理接通。物理事件反馈音并不等于业务已完成：例如KEY6可有按键音，但没有歌词动效连线。不要用“有滴声”单独判定保存成功、歌词切换成功或媒体读完。

## 11. 拍摄前最终排练核对

1. 核实镜头中的实际固件身份、板卡、TF卡与歌曲素材；文件存在或代码映射正确不代表该实物当前烧录了相同版本。
2. 先把DIP1/3/4/5/6及母板SW1/3设置到主脚本要求；DIP2只在前段轮播演示开启。SW2选好本次启动策略，之后不把运行时拨动当Boot动作。
3. 逐个核对实体遥控器的BB/BF、F8/EA方向，E6保存与F2默认；旧文档和实体印字不能替代屏幕时间/音量值。
4. 测量MV首帧、背景资源就绪、保存完成、断电重启的真实等待时长，确定T预算。背景未就绪时延长该段或补录，不通过连续按键伪装。
5. 112秒前确认正在播放且未暂停、唱针符合结尾机械效果、DIP4开启、声音输出、MV有效；KEY8翻转须提前完成并确认；最后E6为计时锚点。
6. 112～172秒保留真实无人操作连续素材，4×只用于前58秒，最后2秒恢复1×并明确标识；黑屏后用普通键先唤醒，再做业务。
7. 断电前确认保存事务已完成；复电后同时拍恢复LED和已保存非默认参数。正常演示中的恢复不能延伸为保存中断电可靠性验收。
8. 片尾文案使用“展示主要功能链路及参数恢复”，不写“所有功能与全部异常测试完成”。EOF三分支、60秒原片及独立自动保存分支按清单补齐或注明未纳入主片。

## 12. 旧《产品交互.md》明确错误清单

旧文档是背景资料，不作为本次操作指令。以下以当前代码核对结果取代：

- KEY1/3播放态为切曲，KEY4/5为音量，KEY6没有当前歌词动效业务。
- EC2按压在SELECT/ADJUST之间切换，参数由SELECT旋转选择，1.8秒无操作隐藏。
- BB为后退5秒、BF为前进5秒；F8减音量、EA加音量；红外左右为切曲，不是±2秒。
- E6已接手动保存、F2已接恢复默认，不能继续标“预留”。
- SW2已是启动旁路；SW4没有当前告警门控证据。
- 扩展LED1动作、LED2 MV、LED3 IR、LED4心跳/故障；母板LED另按NVM含义解释。
- 当前没有独立红外播放模式键映射证据；KEY12可改变EOF策略并显示图标，不据旧句子补造遥控功能。
- 数码管是固定时间与曲号，不再按旧阶段切换诊断页；UART生产输出保持高，不展示不存在的实时日志流。

这些是文档口径修正，本轮没有修改硬件行为。若实物与本表不一致，应先核实实际烧录版本与排线/按键编号，再决定使用哪个版本的拍摄说明。
