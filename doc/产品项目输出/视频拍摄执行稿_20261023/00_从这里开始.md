# VinylFPGA 视频拍摄执行包

编制日期：2026-10-23。用途：完整展示作品、竞赛评审介绍、后期剪辑与现场补拍。

## 建议拍一套素材，制作两条片

**主稿为13分钟完整版，另提供严格180秒精简版。** 你这次希望充分展示全部功能，所以不沿用旧稿把所有操作塞进三分钟的安排。十三分钟包含60秒真实无人操作、三种真实曲尾结果、参数保存与冷启动恢复，以及 Media Studio 离线制作链。真正拍摄按机位分批完成，预计准备、排练、拍摄与回看合计半天；成片顺序与现场拍摄顺序分别给出。

你已确认：**可以准备多部手机、三脚架，有人协助，没有HDMI采集卡，可以录制屏幕原声，计划后期TTS配音，暂无硬性时长上限。** 本稿按两部手机固定拍摄＋可选第三部细节机＋助手执行，电脑仅录离线工具和报告。13分钟是剪辑目标，优先让功能看清楚，必要时可延长到14—15分钟；不需要为本片购买采集卡。如果后续提交渠道另有限制，再使用180秒版。

## 先解决三个会影响全片的问题

1. **确定实际固件。** 旧冻结版已有用户人工验收记录；最新KEY6版新增“五行／当前句专注”，报告仅放行到bitstream，尚无新增行为的实板验收记录。若拍新功能，先做核验卡中的实机检查，整片固定用这一版，不混用两个固件。
2. **确认冷启动。** SRAM下载和配置Flash固化是两回事。断开下载器和可能反供的连接后，真实断电再供电进入可操作界面，才可在视频里说“上电自启”。本次没有替你烧录或操作板卡。
3. **核对实体控件。** 当前RTL与旧图解存在明确差异。左右切曲、上下调音量、EC2选择/调节，以及遥控四个加减方向，按本稿和实物结果核对。图解可辅助定位物理位置，不直接作为当前功能证据。

## 全片的中心表达

> VinylFPGA是一台基于安路FPGA的唱片主题本地音乐画屏。它把本地曲目、歌词、MV、实体操作和灯光组织成一套完整的桌面听音体验。

评委首先看清作品形态，其次看到每个输入与结果，最后理解同一片FPGA如何协调媒体读取、缓存、音视频时间和控制。主片不按RTL目录念模块名。技术细节用少量图示和报告卡解释，实机效果承担主要叙事。

## 使用的技能

已读取并应用：项目内 `fpga-demo-video`（功能证据与拍摄流程）、`Presentations`（读取所附PPT内容及备注）、`verification-before-completion`（交付前检查时间轴、来源、链接与覆盖）。也检查了已有 `video-scriptwriting` 的适用范围，它明确排除实拍电影/传统脚本，因此不强行套用其程序视频YAML与长问卷；`video-production`、`video-storyboard`适合后续实际制作程序视频或图像分镜，本次没有生成视频/分镜图需求，未让这些流程代替实拍计划。

文档中的拍摄建议与例子作为参考材料使用，没有把附件里的“必须三分钟”“五段顺序不能乱”等语句当作你的新指令。保留了有用的五段逻辑，并按你要求扩展时长。
