# 开拍前核验与补拍卡

## 一页开拍卡

- [ ] 实际固件版本：A原冻结 / B KEY6；bit哈希、烧录来源、日期写进场记。不要只认同名bit。
- [ ] 若拍B版，五行→专注→五行，滚动、暂停、Seek、切歌、回浏览再进、复位回五行均已实机核对。未通过用A版替换稿。
- [ ] 实际板卡型号拍清，器件为EG4S20BG256。配置Flash与用户参数Flash用途分清。
- [ ] 无下载器/其他线反供时，真实断电再供电能进入可操作界面；不是仅按复位或E9。
- [ ] TF卡媒体与当前ROM一致，四曲都能正常启动；已有旧卡与Studio新重建镜像不混用。
- [ ] EC1浏览/Seek和按压正确；KEY1/3播放切曲、KEY4/5调音量；EC2 SELECT/ADJUST已排练。
- [ ] 遥控BB后退、BF前进、F8减音量、EA加音量、B9重播、E6保存、F2默认逐个核对并贴临时标签。
- [ ] 蜂鸣器物理回路接通，操作声、保存三音、告警声实际能被录到；HDMI音乐也已回放确认。
- [ ] 手机横屏、焦点/曝光/白平衡锁定，读得清歌词、数码管和LED；亮度对照不自动补曝光。
- [ ] A机能同时看到操作与结果；B若有则录真实HDMI。电脑离线预览不补成板卡输出。
- [ ] 核验卡完成才录正式条；未确定的字段保持空白，不提前写“通过”。

### 普通功能拍摄的默认开关

| 控件 | 建议起始状态 | 为什么 |
|---|---|---|
| 扩展DIP1 | 开 | 扩展业务输入在场 |
| DIP2 | 关 | 除轮播镜头外避免抢切封面 |
| DIP3 | 开 | 扩展反馈灯可见 |
| DIP4 | 关 | 普通功能讲解避免中途自动黑屏；S31前改开 |
| DIP5 | 开 | 遥控可用 |
| DIP6 | 开 | 两路灯可见 |
| 母板SW1 | 开 | 数码时间/曲号可见 |
| 母板SW2 | 关旁路 | 初次冷启动拍Logo；启动时采样，运行时拨动不能重演Boot |
| 母板SW3 | 关 | 参数演示避免意外自动保存；仅S24单独开 |
| 母板SW4 | 正常主体可关，故障拍摄再开 | 保留清楚的告警门控对照；并非播放总开关 |
| 蜂鸣器硬件开关 | 接通 | 收操作音与完成音 |
| 唱针 | 闭合/落针 | 让正常播放时转盘与唱片灯工作 |

拨码“开”按消抖后逻辑上拨=1理解；实体位置拍前核对。关闭DIP1后的事件门控与重新使能有稳定等待，给至少几秒观察，不把它当外设电源总开关。

## 母板与扩展灯别标错

| 灯 | 当前含义 |
|---|---|
| 母板LED1 | 本次启动接受有效Flash配置恢复 |
| 母板LED2 | 当前五参数已保存；改脏后灭，保存完成亮 |
| 母板LED3 | Flash初始化或擦写忙 |
| 母板LED4 | Flash故障或叠加媒体错误 |
| 扩展LED1 | 接受业务操作后短亮约80ms |
| 扩展LED2 | MV显示激活 |
| 扩展LED3 | 合法红外接收后短亮约80ms |
| 扩展LED4 | 正常心跳闪烁，故障时常亮 |

不要沿用图解中的“LED1播放、LED2暂停、LED3 MV”文字。数码管固定为时间和曲号，浏览看所选曲总时长，播放看已播时间；关SW1只熄显示。

## 每条拍完5秒回看

- [ ] 开始状态看得清，按哪个控件看得清。
- [ ] 结果至少有一项能被观察：图、字、时间、音、灯、运动或真实记录。
- [ ] 动作和结果之间没有错接另一条、漏拍等待或遮挡。
- [ ] 原声录到了，旁白/BGM不会盖住关键证据。
- [ ] 效果稳定落定后仍留几秒，方便剪辑。
- [ ] 文件名、take、版本和异常写入场记，保留原片。
