# VinylFPGA竞赛答辩与产品收尾材料

> 整理日期：2026-10-19。服务于已完成开发和完赛作品的学习、写作、产品表达、证据归档及后续展示。用户目标为争取今年国一；本套材料帮助提高准备质量，不预测评审结果。团队信息和现场实测项目均按真实情况回填。

## 1. 这套材料可以直接拿来做什么

- 写报告：中英文摘要、章纲、完整技术段落、图表规划、规格与指标表。
- 做答辩：12页/5分钟彩排稿、40个技术问答、6项工程贡献的论证材料。
- 学项目：29项源码事实索引、8项白板练习与答案、5张核心设计示意图。
- 做产品资料：说明书、快速操作卡、不同长度介绍、六区展板文案。
- 整理成果：36项证据台账、版本卡、性能空白表、原片/成片与归档建议。
- 准备现场：180/90/30秒演示、软重启与断电分支、故障解释和材料自查。

这里提供Markdown内容底稿和图示源码。PPT脚本尚未排成PPTX，展板尚未生成海报，照片、录像和实测数据需使用真实材料。可以引用现有成果，不需要把已完成工作重新开发一遍。

## 4. 第一轮整理建议

### 第一步：定下统一主张

作品名：VinylFPGA——基于安路EG4S20的唱片主题音画交互终端。

一句话：用FPGA把本地音乐、画面、歌词与实体交互组织成一次完整的唱片式播放体验。

技术重点：实际样本消费推进媒体时间、共享存储与事务边界、完整帧后提交。其他功能围绕这条产品和技术主线展开，完整贡献论证见06。

### 第二步：把现有证据填入10

优先归集实际固件身份、媒体/ROM对应、实物照片、原声录像、保存恢复记录和已完赛成果。填已有文件与原片时间码，未知项保持待填。把理论换算、已有归档和现场测量分列。

### 第三步：学习后用自己的话重写

打开02沿源码走一遍，暂时合上资料，完成05的白板练习。把自己说不清楚的问题回到04查证。然后将08底稿改写成本人能够解释的语言，保留源码和证据入口。

### 第四步：做短讲并回看

用03彩排5分钟版本，用11练实际演示。录下讲解后检查：有没有把所有模块名串读、有没有先宣布成功再等画面、有没有说了无法指出证据的量化结论。每次只修一两个最影响理解的问题，再重复讲一遍。

## 5. 本轮统一的事实基线

| 项目 | 使用口径 |
|---|---|
| 平台 | EG4S20BG256，工程TD版本6.2.168116；实物板卡型号由真实标识佐证 |
| 产品 | 本地音乐画屏/音画交互终端，当前固定格式功能原型 |
| 规格 | 最多4曲；48kHz/16-bit/单声道裸PCM；MV320×240 RGB565LE 10fps；640×480显示画布 |
| 文本 | 当前标题、艺人、歌词与字形为编译期ROM |
| 扩展 | 字幕/图层、转场、亮度对比度与OSD、波形可对应相关方向；任意分辨率缩放未接入活动设计 |
| 用户记忆 | 仅VOL、BRI、CON、ROT、WSL五参数；软重启恢复、断电自启和参数恢复分别说明 |
| 技术边界 | 波形与FFT、裸PCM与通用编解码、参数恢复与续播分别按实际实现命名 |
| 工程结果 | 指定固定归档的资源、时序、仿真记录；本轮只读核对，不声称重跑 |
| 现场结果 | 使用真实照片、录像、记录及其固件/媒体版本 |
