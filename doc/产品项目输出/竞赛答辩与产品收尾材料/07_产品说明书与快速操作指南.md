# 07｜VinylFPGA 产品说明书与快速操作指南

> 整理日期：2026-10-19。适用对象：当前 VinylFPGA 竞赛展示工程。用途：现场操作卡、产品说明书底稿、交接和学习。
> 本文依据当前 RTL 与既有工程分析编写；没有重新运行仿真、构建、烧录或实板验证。用户已完成开发并完赛；实物所用固件、接线与媒体卡版本由使用者在交付卡中登记。

## 1. 产品是什么

**VinylFPGA 是基于安路 FPGA 的唱片主题本地音乐画屏原型。** 用户浏览 TF 卡中的预置曲目，启动播放后可听到音频，并查看封面、歌词、播放进度、PCM 波形或 MV。旋钮、按键、遥控、灯带和转盘主题反馈共同构成操作体验。

适合个人桌面音乐展示、竞赛演示和 FPGA 多媒体教学。唱片主题描述视觉与实体交互，不代表读取模拟黑胶唱片。当前为固定媒体规格的工程原型，媒体导入需要配套工具和版本管理。

## 2. 当前支持规格

| 类别 | 当前规格 | 使用时注意 |
|---|---|---|
| 核心器件/工具 | 安路 EG4S20BG256；TD 6.2.168116 工程 | 对外可简称“安路 FPGA”；实物板卡型号另填 |
| 曲目数 | 最多 4 曲 | 曲目 ID、索引、ROM 内容必须对应 |
| 音频源 | 48 kHz、16-bit signed、little-endian、单声道裸 PCM | 不是直接播放任意 WAV/MP3/AAC；左右输出映射自同一单声道样本 |
| 封面/BMP | 按工程约定准备的 640×480、24-bit、未压缩 BMP | 无任意尺寸自动缩放承诺 |
| MV 源 | 320×240、RGB565LE、top-down、10 fps 原始帧 | 每帧 153,600 bytes、300 个 512B 扇区；按索引放在连续 LBA 区域 |
| 显示画布 | 640×480，HDMI 输出链 | MV 源分辨率/帧率与显示画布/刷新时序不是同一概念 |
| 文本 | 标题、艺人、歌词与字形由编译期 ROM 提供 | 仅替换 TF 卡上的 LRC 不会自动替换当前播放页文字 |
| 音频可视化 | PCM 幅度波形、电平反馈 | 不称 FFT 频谱 |
| 控制 | 双编码器、扩展按键/DIP、母板维护键、NEC 红外 | 同编号母板键和扩展键的用途不同 |
| 参数记忆 | VOL、BRI、CON、ROT、WSL 共五项 | 不保存曲目位置、当前曲目或暂停状态 |
| 主题输出 | 两路各 8 灯 WS2812 相关控制；外部电机驱动逻辑使能 | FPGA 输出不是电机功率驱动 |
| 文件系统范围 | FAT32 的项目所需子集 | 根目录扫描范围受限；不是通用文件管理器 |

## 3. 第一次使用：从开机到听歌

### 3.1 开机前准备

1. 使用与固件对应的媒体卡；确认封面、PCM、MV、索引与 ROM 文字的对应关系。
2. 按既有板卡接线连接 HDMI、声音输出、扩展控件和外部驱动；记录供电方案。
3. 扩展 DIP1 开启以放行业务动作；需要遥控时开启 DIP5；需要灯带时开启 DIP6。第一次学习可关闭 DIP2 自动轮播，保持封面稳定。
4. 母板 SW1 控制数码管显示，SW3 控制五参数自动保存。是否开启按本次演示需要决定。SW2 是启动策略输入，运行时拨动不等同重新执行 Boot。
5. 只有实物已固化上电配置并有自启证据，才按“直接供电自启”的方式交付说明；否则登记当前加载方式。

### 3.2 最短操作路径

| 步骤 | 操作 | 应观察到的结果 |
|---|---|---|
| 1 | 按既定方式上电/加载，等待 Boot 与媒体装载 | 浏览页出现有效封面；不能只凭 Logo 退出就判断所有素材已就绪 |
| 2 | 转动 EC1 选择曲目 | 封面/选中曲目改变；顺时针下一项、逆时针上一项 |
| 3 | 按 EC1，或按扩展 KEY2 | 进入播放，声音与播放页出现，进度推进 |
| 4 | 再按 EC1/扩展 KEY2 | 暂停；再按恢复，媒体时间从当前位置继续 |
| 5 | 播放时转 EC1 | 每格向曲尾或曲首定位 2 秒；给系统留出排空和重新取数时间 |
| 6 | 播放时按扩展 KEY3/KEY1 | 下一曲/上一曲；与 EC1 旋转定位的语义不同 |
| 7 | 按扩展 KEY7 | 退出播放回曲目浏览 |

声音不存在时，先确认播放已启动、未暂停、未静音、音量非零，以及显示设备有相应音频输出能力；抬针本身不应暂停音频。

## 4. 认清两组 KEY：扩展板负责业务，母板负责维护

### 4.1 扩展板 KEY1～KEY12

| 扩展键 | 浏览态 | 播放态/其他行为 |
|---|---|---|
| KEY1 | 上一封面 | 上一曲 |
| KEY2 | 确认播放 | 暂停/恢复；消隐时普通首键只唤醒 |
| KEY3 | 下一封面 | 下一曲 |
| KEY4 | 上一封面 | 音量增加 16，边界饱和 |
| KEY5 | 下一封面 | 音量减少 16，边界饱和 |
| KEY6 | 没有当前有效业务映射 | 不以反馈音推断存在歌词动效 |
| KEY7 | 按当前状态机处理 | 退出播放回浏览 |
| KEY8 | 不作为浏览主控 | 在封面/波形视窗与 MV 之间切换；资源需实际可用 |
| KEY9 | 循环选择直切/横向擦入/淡变 | 浏览页用切封面观察；不把播放页当作相同转场证明 |
| KEY10 | 不作为选曲键 | J2 灯带 VU/全灭切换，不关闭唱片灯带或电机 |
| KEY11 | 不作为返回键 | 切换播放背景：灰底、歌曲虚化、艺术图等；未装载时可回退 |
| KEY12 | 不作为选曲键 | 切换曲终策略；图标选中不等于已演示曲终动作 |

曲终策略默认列表下一曲，按键循环为“列表下一曲 → 播完暂停 → 单曲重播 → 列表下一曲”。若需要向观众证明三种策略，应分别等到真实曲终或定位到接近结尾后等待自然结束。

### 4.2 母板 KEY 与 SW

| 母板控件 | 当前用途 | 与扩展板容易混淆之处 |
|---|---|---|
| KEY1 / rst_n | 全局硬件复位 | 不是上一曲，也不是断电 |
| KEY2 | 五参数恢复默认，并排队持久化默认记录 | 不是暂停键；不会只做临时默认 |
| KEY3 | 手动保存五参数快照 | 不是下一曲 |
| KEY4 | 静音/恢复 | 不是音量增加；静音不冻结媒体时间 |
| SW1 | 数码管总使能 | 关闭只熄数码管 |
| SW2 | 启动 500ms 保护窗后采样的 Boot 旁路选择 | 不是运行中一拨就跳 Boot |
| SW3 | 五参数停止更新 5 秒后的自动保存使能 | “5 秒”是请求资格，不是保证整个擦写事务在 5 秒完成 |
| SW4 | 当前有拨动反馈；未发现告警总门控连线 | 不沿用旧文案的“告警总开关” |
| 硬件 SW5 | 母板蜂鸣器回路通断 | 非 FPGA 输入业务参数 |

## 5. EC2 参数面板：先选择，再调整

~~~text
隐藏态：按压 → SELECT（选择参数）
SELECT：旋转 → 切换 VOL / BRI / CON / ROT / WSL
SELECT：按压 → ADJUST（调整当前参数）
ADJUST：旋转 → 改变当前参数
ADJUST：按压 → SELECT
无操作约 1.8 秒 → 隐藏
隐藏态直接旋转 → 立即进入 VOL 调整并改变音量
~~~

以调亮度为例：按 EC2 呼出 → 确认 SELECT → 转到 BRI → 按压进入 ADJUST → 旋转到目标值 → 按压回 SELECT。不要把隐藏态旋转当成只浏览选项；它会改音量。读取五参数作恢复对比时，以屏幕参数名和状态为准，操作间隔避免超过 1.8 秒；超时后先重新按压呼出。

| 参数 | 档位/范围 | 默认 | 作用 |
|---|---|---:|---|
| VOL | 0～255，每次 16，边界饱和 | 200 | 播放输出音量；数值不是 dB，也不是线性主观响度百分比 |
| BRI | 0/1/2/3/4 → 0.25/0.5/0.75/1/1.25 倍 | 3 | 图像亮度；后级文字叠加不必同倍率变化 |
| CON | 0/1/2/3/4 → 0.5/0.75/1/1.25/1.5 倍 | 2 | 图像对比度 |
| ROT | 0 关闭；1/2/3/4/5 → 2/3/5/10/20 秒 | 2 | 浏览页自动轮播间隔，另需 DIP2 开启 |
| WSL | 0/1/2/3/4 → 0/25/50/75/100% 调色板亮度 | 4 | 两路灯带亮度；不是总机功率百分比，也不控制电机 |

依据：[EC2 控制器](../../../src/io/ec2_param_controller.v)、[参数 CSR](../../../src/io/ui_param_csr.v)，顶层实际实例化 PARAM_COUNT=5。

## 6. 五参数保存：看状态，不猜等待秒数

### 6.1 手动保存

1. 先将至少一项改为非默认值，记下当前五参数。
2. 按母板 KEY3，或发出红外 E619FF00。
3. 观察母板 LED3 忙状态；完成后应忙灭、LED2 已保存亮，无故障指示。
4. 再执行所选重启方式，打开 OSD 核对五参数。推荐记录一组容易区分的值，例如 168/2/3/1/2。

如果当前值本来已保存，再按保存键未必产生新擦写事务；不能据此展示一次“由脏变已保存”的过程。LED2 与 OSD 值一起使用比只听按键反馈音更有说服力。

### 6.2 自动保存

开启母板 SW3，修改参数后停止继续改参。源码在参数稳定且 dirty 达 5 秒、Flash 可用且空闲等条件满足时提交保存。后续擦除、编程、回读、提交仍需时间，以忙状态结束和已保存状态确认结果。

### 6.3 恢复默认

母板 KEY2 或红外 F20DFF00 将五参数恢复为 VOL200/BRI3/CON2/ROT2/WSL4，并排队写入默认记录、清理旧槽。它不是“本次暂时恢复、下次仍恢复旧参数”。默认操作后也应等待事务完成。

### 6.4 只保存五参数

当前持久化不包含曲目 ID、播放位置、暂停状态、背景、转场、EOF 策略或灯效模式。“保存参数后重新开机”应称“参数恢复”，不写“断电续播”。

依据：[持久化管理](../../../src/io/ui_param_persistence.v)、[用户 Flash 双槽记录](../../../src/io/w25q64_param_store.v)。

## 7. 四种恢复方式的准确含义

| 方式 | 如何触发 | 能说明什么 | 需要额外确认什么 |
|---|---|---|---|
| 软重启 | 红外 E916FF00，立即请求软复位，无二次确认 | 软复位后的启动流程和参数恢复 | 不能证明供电移除或 FPGA 配置 Flash 自启 |
| 硬件复位 | 母板 KEY1/rst_n | 硬件复位后的恢复 | 不等于真正断电 |
| 断电再供电 | 镜头内移除并恢复实际供电 | 对本次实物与版本可观察的冷启动、参数恢复 | 上电配置需已固化；供电是否真正移除按实物记录 |
| 重新加载 bit | 使用既有下载方法重新配置 FPGA | 新配置后的运行 | 不等于脱离下载器上电自启 |

**断电演示流程：** 改成非默认参数 → 保存完成 → 记录 OSD → 断电 → 重新供电 → 等浏览可用 → 查看五参数 → 再主动选曲播放。不能把最后一次重新播放称为自动续播。正常保存后的断电恢复，也不是保存过程中任意时刻掉电的可靠性验证。

## 8. 消隐、静音、暂停、抬针各影响什么

| 操作 | 画面 | 声音/媒体时间 | 唱片电机 |
|---|---|---|---|
| 暂停 | 保持播放页，进度冻结 | 暂停消费，恢复后继续 | 停止 |
| 静音 | 播放画面继续 | 输出静音，媒体时间继续 | 不因静音停止 |
| 手动/自动消隐 | RGB 输出纯黑 | 音频与媒体时间可继续 | 不因消隐本身停止 |
| 抬针 | 播放页继续 | 音频和媒体时间继续 | 关闭使能；唱片灯带清黑 |
| WSL=0 或 DIP6 关闭 | 主画面不变 | 音频和媒体时间不变 | 不因此停止 |

DIP4 开启时，60 秒无有效操作会自动消隐；遥控 F609FF00 可手动消隐。黑屏后第一次普通业务动作只唤醒，不兼做切曲/暂停；保存、默认、静音、重启属于维护脉冲，不能全部归为相同的首键吞入行为。学习或演示首键唤醒可用扩展 KEY2，然后第二次再按暂停。

电机使能条件为播放激活、未暂停、唱针闭合到地和复位释放。唱针输入没有连接为音频暂停命令，不能按黑胶唱机的习惯推断其行为。

## 9. DIP 快查

| 扩展 DIP | 开启后的作用 |
|---|---|
| DIP1 | 在场/动作就绪，经过输入稳定后放行业务 |
| DIP2 | 浏览页自动轮播；另需媒体有效、曲目多于一首、ROT 非 0 |
| DIP3 | 扩展业务 LED 总使能 |
| DIP4 | 60 秒无有效操作自动消隐 |
| DIP5 | 红外业务使能 |
| DIP6 | 两路 WS2812 总使能；关闭补发黑帧，不关闭电机 |

## 11. 状态灯与显示如何读

| 位置 | LED1 | LED2 | LED3 | LED4 |
|---|---|---|---|---|
| 母板 | 本次启动接受有效参数恢复 | 当前五参数已保存 | Flash 忙 | Flash 或媒体错误 |
| 扩展板 | 接受业务动作闪约 80ms | MV 显示激活 | 接受合法红外闪约 80ms | 正常心跳/故障常亮 |

母板与扩展板灯的含义不同。母板 LED3 忙灭不能单独证明保存成功，需结合 LED2、错误状态和恢复值。数码管固定显示“MM-SS 空白 NN”：浏览为所选曲总时长，播放为已消费时间，曲号从 01 开始；它不是当前 UART 诊断界面。

## 12. 常见现象与定位入口

| 现象 | 先看什么 | 正确处理思路 |
|---|---|---|
| 按键有声但未见功能 | 是否 KEY6、是否消隐首键、DIP1 和启动状态 | 蜂鸣仅代表物理事件反馈，不能当业务完成证据 |
| 播放无声 | 暂停、静音、VOL、显示器音频能力、媒体错误 | 用已知可用素材和声路定位，不反复切曲掩盖问题 |
| 旋钮一转改了音量 | EC2 是否已隐藏 | 按压呼出 SELECT，再选参数 |
| ROT 已改却不轮播 | 是否浏览态、DIP2、ROT 是否 0、曲目数 | 参数值和轮播准入条件需同时满足 |
| 切背景还是灰色 | 背景数据是否实际加载、当前曲是否具备该资源 | 灰色可为回退状态，不代表已展示所有背景 |
| MV 迟迟不出现 | 媒体索引、MV 存在、预取/完整帧准备 | 不把 KEY8 的一次切换当加载成功 |
| 黑屏后按一次不暂停 | 是否普通首键只唤醒 | 第二次按才执行普通业务 |
| 保存后恢复成默认 | 实际固件身份、保存是否完成、是否按过恢复默认 | 先登记真实五参数和灯状态，再复现；不直接改写媒体或 Flash |
| 换 LRC 文字没变化 | 当前歌词来自编译期 ROM | 同步文本生成与固件版本，不只换卡文件 |

## 13. 内容更新与维护

媒体更新应使用现有[音频/索引打包工具](../../../tools/vinyl_packer.py)、[MV 工具](../../../tools/mv_pack.py)、[背景工具](../../../tools/pack_backgrounds.py)和[歌词准备工具](../../../tools/prepare_s3_lyrics.py)的适用流程。文件布局或 LBA 改变后同步生成索引，不能继续套用旧物理地址。

文字、字形、歌词时间或曲目 ID 改动涉及 ROM 时，要按既有工程流程生成对应固件。一个发布包至少包含源码/ROM 身份、bit 身份、索引/媒体包身份、实际接线、操作卡和演示记录。详细规则见[交付维护手册](../25_交付维护与证据归档手册.md)。

## 14. 打印版一页操作卡

> **选曲：** 浏览态转 EC1；按 EC1 或扩展 KEY2 播放。  
> **暂停：** 按 EC1/扩展 KEY2；再次恢复。  
> **切曲：** 扩展 KEY1 上一曲、KEY3 下一曲。  
> **定位：** 播放态 EC1 每格 ±2 秒；遥控 BB/BF 为 −5/+5 秒。  
> **调参：** EC2 按压呼出 SELECT → 旋转选项 → 按压 ADJUST → 旋转修改。  
> **画面：** KEY8 切 MV/封面视窗；KEY11 背景；浏览时 KEY9 选转场。  
> **音量：** 扩展 KEY4/5 加减；母板 KEY4 是静音。  
> **保存：** 母板 KEY3 或红外 E6；看忙结束与已保存灯。  
> **默认：** 母板 KEY2 或红外 F2；默认也会持久化。  
> **重启：** 红外 E9 立即软重启；断电是另一条真实供电流程。  
> **记忆范围：** 仅五参数；不包含断电续播。  
> **实体标识：** 全部 KEY 操作先看“母板/扩展板”，两组编号不可混用。
