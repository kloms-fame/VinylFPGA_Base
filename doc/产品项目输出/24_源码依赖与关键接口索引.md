## 1. 入口和依赖识别方法

[VinylFPGA.al](../../prj/VinylFPGA.al) 指定 module top、EG4S20BG256、TD 6.2.168116。顶层定义在 [top_tf_hdmi_audio.v](../../src/top_tf_hdmi_audio.v)，既显式调用工程登记文件中的模块，也通过 include 汇入其他 RTL。

本轮抽取 .al 的 File Path 条目，并从这些 Verilog 文件递归检查 include，依次按文件所在目录、src 和 src/include 解析。检查发现：

- 工程文件条目 59 个，其中 Verilog 57 个，约束 2 个；登记路径缺失 0 个。
- 登记文件与文本 include 的联合可达文件 126 个；include 引用边 87 条，未解析 include 0 条。
- src 下 Verilog 文件 130 个、去除注释后的明文 module 声明 131 个；共 40,910 个物理文本行，含生成 ROM、厂商和历史代码，不能当作原创手写代码量。
- sim 主目录 125 个 tb_*.v；递归含子目录、旧版本与归档副本 158 个；递归 results.json 75 个。文件数不等于独立用例数或通过数。

## 3. 关键接口的单位和完成语义

| 接口/信号组 | 数据单位 | 必须保持的契约 |
|---|---|---|
| SD raw_req/raw_lba、raw_valid/raw_byte_index、raw_done/raw_error | LBA=512B 扇区号；byte_index=扇区内字节位置 | 请求接受、收到字节、事务完成和错误分别检查；不能中途切换 owner |
| audio_prefetch_sdram 的 start_lba/total_sectors | 起始扇区号/扇区数 | 只发布接收完整且校验通过的扇区；会话清理不得把旧返回当成新数据 |
| client_req/client_valid/client_byte/client_done | 播放器所需的缓存扇区字节流 | client_done 是该层事务结束，不能当作 PCM 输出完毕 |
| wav_stream_player 的 valid_samples/skip_samples | 样本数/首扇区内跳过样本数 | 保护文件尾真实长度和 Seek 偏移；1 个 16-bit 样本=2 字节 |
| sample_tick/sample_ready/sample_consumed | 计划采样节拍/接收能力/实际有效取样 | 实际消费推进媒体时间；欠载静音本身不推进有效样本计数 |
| timebase_48k 的 sample_count/cur_time_ms | 累计样本数/毫秒 | 48 个有效样本=1ms；load/restart/暂停按当前 RTL 优先级处理 |
| MV request_toggle/request_lba/request_bank | 一帧请求事件/首扇区号/目标 bank | payload 保持到事务完成；固定300扇区/帧，不能套用SDRAM字数 |
| MV write_ack/write_finish_toggle/done_toggle | 写通道授权/存储写完/帧任务完成 | 最后SD字节不等于写完；提交显示还要等 frame_start |
| SDRAM App 地址与 write_len | 当前用户接口的32-bit字地址/字数 | 1个解包后的像素占1个32-bit字；不要把字地址当字节地址 |
| RGB、DE、HS/VS、X/Y | 像素与位置/同步信息 | 运算增加的寄存延迟应同时作用于有关坐标/有效信息 |
| CSR 参数 bundle | 五项参数快照 | CDC 分支负责运行消费者；同域 Flash 保存不经过视频域再绕回 |
| NVM busy/saved/error | 应用参数存储事务状态 | 与FPGA配置下载、媒体卡写入、播放位置保存相区别 |

接口以 [音频预取](../../src/audio/audio_prefetch_sdram.v)、[PCM 播放器](../../src/audio/wav_stream_player.v)、[MV 读取器](../../src/video/mv_stream_player.v)、[帧读写](../../src/SD/frame_read_write.v) 和顶层接线为依据。表中语义用于阅读，不替代完整端口协议。

## 4. 时钟与复位索引

| 时钟 | 当前配置 | 主要用途 |
|---|---:|---|
| clk | 50 MHz | 用户交互、CSR、参数持久化 |
| sd_card_clk | 100 MHz | SD/FAT32、扇区流、音频写侧、MV 搬运控制 |
| ext_mem_clk | 125 MHz | SDRAM 用户口、DMA 与帧存储仲裁 |
| ext_mem_clk_sft | 125 MHz，180°移相 | SDRAM IP 相关采样 |
| video_clk | 25 MHz | PCM 消费、媒体时基、像素与图层 |
| hdmi_5x_clk | 125 MHz | HDMI 串行相关逻辑 |

依据：[sys_pll](../../src/IP/sys_pll.v)、[video_pll](../../src/IP/video_pll.v)、[timing.sdc](../../constraints/timing.sdc)。100 MHz 是 SD 内部控制域频率，不等于卡引脚 SPI SCLK。当前约束将若干组按异步处理，不能据此免除 CDC 结构检查。

复位需同时检查全局 rst_n、PLL lock、软重启、媒体复位、域内同步释放。一次逻辑切歌、一次媒体故障重挂载和整机硬复位具有不同影响范围。

## 5. SDRAM 地址与字节通道

以下为当前 RTL 的逻辑字地址范围，末地址采用包含式。它描述 21-bit、32-bit 用户地址窗口的分配，不替代外部器件原理图和控制器映射。

| 区域 | 起始字地址 | 结束字地址 | 字数 | 来源 |
|---|---:|---:|---:|---|
| 封面0 | 0 | 307,199 | 307,200 | 顶层 BUF0 / FRAME_PIXELS |
| 封面1 | 307,200 | 614,399 | 307,200 | BUF1 |
| 封面2 | 614,400 | 921,599 | 307,200 | BUF2 |
| 封面3 | 921,600 | 1,228,799 | 307,200 | BUF3 |
| MV bank0 | 1,228,800 | 1,305,599 | 76,800 | MV_ADDR0 |
| MV bank1 | 1,305,600 | 1,382,399 | 76,800 | MV_ADDR1 |
| MV bank2 | 1,382,400 | 1,459,199 | 76,800 | MV_ADDR2 |
| 歌曲背景缓存 | 1,459,200 | 1,766,399 | 307,200 | background_cache_loader SONG_ADDRESS |
| 艺术背景缓存 | 1,766,400 | 2,073,599 | 307,200 | ART_ADDRESS |

21-bit 地址窗口最多 2,097,152 个字；以上图像区域末端之后理论剩余 23,552 个字地址。这个数字不是已验证可随意分配的产品空间，新增区域仍需核查控制器和所有读写客户端。

**音频字节另按 lane 叠加：** 音频 cache 的第 slot、offset 字节映射到字地址 slot×512+offset 的低8位，slot 是0–1023的环形缓存槽号，不是卡上LBA或原文件的绝对扇区号。图像写入保护低字节，音频写入保护高24位。因此音频与部分封面共享物理字地址，而非另占一块上述表之外的普通连续区域。

卡上 MV 一帧是153,600B；解包后占76,800个32-bit SDRAM字，物理字跨度为307,200B。两种容量对应不同格式。
