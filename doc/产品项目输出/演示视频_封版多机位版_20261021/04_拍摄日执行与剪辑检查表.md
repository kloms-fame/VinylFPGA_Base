# 拍摄日执行与剪辑检查表

## 1. 当天只准备这些

- 封版设备、匹配媒体卡、显示和实际声音输出、遥控器、现有供电开关。
- A全景固定设备，B/C细节设备及支架；已有音频采集方案可继续使用。
- 柔和稳定的现有补光，整洁桌面；线缆从后侧固定，不挡控件和机构。
- 本目录分镜、功能清单、纸质镜号卡和记录笔。
- 电量/存储空间足够，关闭拍摄设备中断录制的通知；所有拍摄设备记录设置一致或明确登记。

继续使用已验收固件与卡，不在拍摄日重建、烧录或修改代码。实际卡型号、板卡编号、摄像设备与收音方式登记在拍摄日志，已有验收信息可以直接引用。

开始大多数功能条前，沿用已经验收的接线与常用状态：DIP1输入就绪、DIP3指示灯、DIP5红外、DIP6灯带开启，DIP2轮播先关。拍IDLE01时打开DIP4自动消隐；拍AUTOSAVE01时打开母板SW3自动保存，数码管需要时开SW1。轮播、灯带门控和默认恢复的专门镜头分别准备状态，完成后再进入下一条。

## 2. 开始前录一条画质样片

1. 用真实播放画面确定全景，确认屏幕、按键、转盘、灯带、保存指示都能辨认。
2. 锁定屏幕机位的焦点、曝光和白平衡，录制同一画面亮度前后变化，再回看原文件。
3. 录“播放—暂停—恢复—静音—恢复”短片，确认设备原声在文件里清楚可辨。
4. 检查反光、滚动条纹、灯带过曝和数码管可读性，调整现有灯光/角度/录制设置后固定。
5. 每条开始拍镜号卡、报镜号和条次；用一次清楚拍手对齐多机位，进入功能段前留余量。

这是录像设置和动作排练，不重新进行功能验收。画质和声音合格后再批量开拍。

## 3. 按布景批量拍摄的顺序

| 批次 | 一次完成 | 主机位 | 素材编号 |
| --- | --- | --- | --- |
| 1：漂亮运行画面 | 整机、板卡接口、转盘、双灯带、四曲各一段歌词/MV | A/B/C | HOOK01 / PLATFORM01 / TRACK01～04 / END01 |
| 2：浏览与显示 | 选图、轮播、两种转场、MV/封面、全部背景 | A持续、B屏幕 | BROWSE01 / TRANSITION01 / VISUAL01 |
| 3：操作联动 | 暂停恢复、针起落、定位、切曲、重播、返回浏览、手动息屏与静音 | A持续、B屏幕、C机构/手 | LINK01 / CONTROL01 / BLANK01 / IR01 |
| 4：参数和外设 | VOL/BRI/CON/ROT/WSL、默认恢复、VU/双灯带/数码管门控 | B固定曝光，A/C补充 | PARAM01 / LIGHT01 / DEFAULT01 / GATE01 / STATUS01 |
| 5：保存恢复 | 自动保存独立条、手动保存、同轮断电复电、五项恢复 | A连续，B面板，C母板灯 | AUTOSAVE01 / NVM01 / POWER01 / RESTORE01 |
| 6：曲终分支 | 三个策略各自从近曲尾自然播完 | A/B | EOF01 / EOF02 / EOF03 |
| 7：无操作与附件 | 完整60秒消隐和唤醒、其他已有验收资料的展示补充 | A连续，B同步 | IDLE01 / BOOT02 / INPUT02 |

每条按“开始前状态→一个主动作→清楚结果→停留→结束”的顺序。动作前留2～3秒，结果后留3～5秒，后期有选择空间。一次失败或遮挡就另录新条次，保留原文件。

保存恢复要记录真实参数值，拍摄默认恢复、门控和曲终策略后，下一条开始前准备好所需状态。不同功能条可以采用不同状态，剪辑按章节说明。

## 4. 现场短口令

```text
统筹：LINK01，第2条。A/B/C开始，报号拍手。
摄影：画面、原声正常。
统筹：播放状态留三秒。放针。停。暂停。停。恢复。停。抬针。
主操：按口令执行，动作后撤手，不边操作边解说。
统筹：结果再留五秒。结束，登记可用条次。
```

IDLE01期间停止所有有效输入；拍摄和录音继续。POWER01由指定人操作实际设备电源，其余人不碰控件。完整开机过程保留在同一连续原片中，主片中段等待的取舍交给后期。

## 6. 剪辑规则与顺序

1. 先备份原片，按镜号/条次分类并同步A/B/C，核对设备原声音轨。
2. 按主片CSV搭178秒粗剪；保留输入前后和结果，不急着加花字。
3. B/C特写优先来自同一条次同步画面；切到不同功能条时用清楚段落或功能字幕说明。
4. 歌词、波形、参数、转盘动作各留足观察时间，重要数字至少停约1～2秒，按回看可读性调整。
5. M12使用真实IDLE01：计划前56秒8×、最后4秒1×、黑屏后2秒1×，合计13秒。实际消隐边沿按原片重定位，变速标记持续可见。
6. 启动/缓存等中间等待允许省略；在相应切点显示“省略启动等待/完整过程见原片”等准确提示。输入、断电灯灭、结果本身保持原速。
7. 按真实画面录分段旁白，保留每段前后余量；先用设备原声剪对比，再调整旁白电平。
8. 最后加功能标签和旁白字幕。技术数据引用本目录封版事实表。时间与参数取实际素材值，旧T20字幕不直接导入。
9. 从同一批素材建立360秒完整功能版；F11保留完整原速等待区间，补齐主片未展开的功能。
10. 导出后在普通播放器从头回看，再用手机回看字体、声音和整体节奏。

M12中的8×声音不用于音质判断，原片完整保留；主片可降低这段变速声，黑屏后的2秒保留同期实际设备声。暂停、静音和音量变化处也以同期音轨为准。

## 7. 完片检查

- [ ] 名称、FPGA型号、视频版本和封版bit身份一致。
- [ ] 主片178秒计划已按实际剪辑复核，总时长满足实际提交上限；完整片按实际用途命名。
- [ ] 开场8秒能看懂作品形态，前1分钟出现实际音视频和主要扩展效果。
- [ ] 手部动作和结果有对应画面；字幕不遮参数、歌词、时间、保存灯和唱针。
- [ ] 听得到设备真实音乐，暂停/静音与黑屏继续播放的声音关系正确。
- [ ] 转场来自设备，调BRI/CON时拍摄曝光固定；作品画布保持原比例。
- [ ] 自动消隐有完整无操作原片，主片变速标记和计时对应实际区间。
- [ ] 保存前后五参一致；恢复默认、自动保存、手动保存分别使用正确片段。
- [ ] 三种曲终实际结果在完整功能版或明确附件中有位置。
- [ ] 资源数据来自当前routed报告；技术说明与镜头测量区分清楚。
- [ ] 导出建议采用横屏1920×1080、MP4/H.264，帧率按素材和剪辑工程一致设置；最终格式/大小服从提交通知。
- [ ] 原片、原声、剪辑工程、字幕、成片、事实表和素材索引分别归档。
