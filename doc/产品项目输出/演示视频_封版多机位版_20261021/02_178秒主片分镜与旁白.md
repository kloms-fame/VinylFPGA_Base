# 178秒主片分镜与旁白

## 1. 使用方法

本版允许多机位、多人配合和分段剪辑。下面的时间是**成片时间**，不是要求操作者在同一条录像里按秒完成。A全景保留关键功能段的连续原片，B/C提供同期屏幕、手部、转盘与灯带特写。

总长178秒，共16镜。片头片尾已经包含在预算内，30fps时为5,340帧；实际工程帧率按录制素材设置。另有360秒完整功能版覆盖细分分支。

每个镜头标明素材编号。文件尚未拍摄，条次与实际入出点在《功能覆盖与素材清单.csv》中登记。若等待超过预算，清楚标注省略区间，再按实际素材重排；不加速关键输入与结果。

## 3. 逐镜执行

### M01｜00:00–00:08｜产品开场

- **画面与机位：** A全景 / C转盘灯带 / B歌词。素材 `HOOK01`，实物/实屏/同期声。
- **操作与成功判据：** 保持实际播放；屏幕、转盘和两路灯带同框。
- **画面字幕：** VinylFPGA｜唱片主题音乐画屏。
- **旁白：** “这是VinylFPGA，一台唱片主题音乐画屏。”
- **声音与节奏：** 前6秒短旁白，末2秒作品原声。

### M02｜00:08–00:16｜平台与本地媒体

- **画面与机位：** A全景 / C板卡接口。素材 `PLATFORM01`，实物/实屏/同期声。
- **操作与成功判据：** 拍板卡、TF卡与HDMI连接，再回到实际显示。
- **画面字幕：** EG4S20BG256｜TF本地媒体｜HDMI音视频。
- **旁白：** “TF卡提供媒体，FPGA完成HDMI音视频输出。”
- **声音与节奏：** 低旁白，保持本次原声。

### M03｜00:16–00:30｜浏览与自动轮播

- **画面与机位：** A操作结果同框 / B封面。素材 `BROWSE01`，实物/实屏/同期声。
- **操作与成功判据：** EC1前后选图；DIP2开启后出现一次自动换图并关闭。
- **画面字幕：** 旋钮选曲｜自动轮播。
- **旁白：** “旋转主旋钮选择曲目，打开轮播后，封面按设定间隔自动切换。”
- **声音与节奏：** 实际操作音可辨。

### M04｜00:30–00:40｜硬件转场

- **画面与机位：** B屏幕 / A小窗。素材 `TRANSITION01`，实物/实屏/同期声。
- **操作与成功判据：** KEY9选择后实际换封面；保留擦入和淡变各一次完整过程。
- **画面字幕：** 水平擦入｜淡出淡入。
- **旁白：** “切换封面时，可以选择水平擦入或淡出淡入。”
- **声音与节奏：** 设备转场过程原速。

### M05｜00:40–00:54｜音乐与显示图层

- **画面与机位：** B屏幕 / A小窗。素材 `PLAY01`，实物/实屏/同期声。
- **操作与成功判据：** 确认播放；歌词、时间、进度、波形与实际音乐共同出现。
- **画面字幕：** 歌词｜进度｜PCM波形｜MV。
- **旁白：** “歌词与画面，跟随音频播放位置更新。”
- **声音与节奏：** 前6秒旁白，后8秒设备原声。

### M06｜00:54–01:08｜唱针与暂停联动

- **画面与机位：** A全景 / C机械 / B时间。素材 `LINK01`，实物/实屏/同期声。
- **操作与成功判据：** 针落播放→暂停→恢复→抬针；分别观察声音、进度、电机和唱片灯带。
- **画面字幕：** 暂停：声音与进度停止｜抬针：转盘停止、音乐继续。
- **旁白：** “暂停时，声音和进度一起停住。抬起唱针，转盘停下，音乐继续。”
- **声音与节奏：** 动作后留原声，旁白避开暂停前后比较。

### M07｜01:08–01:22｜定位、切曲、重播

- **画面与机位：** A控件与屏幕 / B时间。素材 `CONTROL01`，实物/实屏/同期声。
- **操作与成功判据：** EC1定位；按键切换曲目；红外重播后时间回到开头。
- **画面字幕：** 每步±2秒定位｜切曲｜红外重播。
- **旁白：** “旋钮定位、按键切曲，遥控也能让当前歌曲从头播放。”
- **声音与节奏：** 每次结果保持可读。

### M08｜01:22–01:34｜MV封面与背景

- **画面与机位：** B屏幕 / A操作小窗。素材 `VISUAL01`，实物/实屏/同期声。
- **操作与成功判据：** KEY8切换MV/封面；KEY11展示两种清楚可辨的背景。
- **画面字幕：** MV / 封面｜背景图层。
- **旁白：** “播放画面可以在MV和封面之间切换，并选择不同背景。”
- **声音与节奏：** 切换稳定后再进入下一画面。

### M09｜01:34–01:52｜音量、全局亮度与对比度

- **画面与机位：** B固定曝光屏幕 / C编码器。素材 `PARAM01`，实物/实屏/同期声。
- **操作与成功判据：** EC2分三段调整VOL、BRI、CON；每段保留调整前后与面板值。
- **画面字幕：** 音量｜全局亮度｜对比度。
- **旁白：** “第二个旋钮负责参数。音量、全局亮度和对比度，都能边看边调。”
- **声音与节奏：** 音量变化保留实际声音，不让配音填平差异。

### M10｜01:52–02:02｜轮播间隔与双灯带

- **画面与机位：** C双灯带 / B参数 / A。素材 `LIGHT01`，实物/实屏/同期声。

- **声音与节奏：** 先数值后实物，结果原速。

### M11｜02:02–02:12｜手动息屏与静音

- **画面与机位：** A全景 / B进度。素材 `BLANK01`，实物/实屏/同期声。
- **操作与成功判据：** 手动息屏后音乐继续；唤醒；静音时进度继续，再恢复声音。

- **旁白：** “息屏可以继续听歌，静音时播放进度仍然前进。”

### M12｜02:12–02:25｜自动消隐

- **画面与机位：** A连续全景 / B同步画面。素材 `IDLE01`，实物/实屏/同期声。

- **画面字幕：** 真实60秒无操作｜前56秒8×｜末4秒及黑屏原声1×。
- **旁白：** “没有操作时，屏幕会自动熄灭，音乐继续播放。”

### M13｜02:25–02:34｜保存非默认参数

### M14｜02:34–02:44｜真实断电与上电

- **画面与机位：** A供电动作 / B启动 / C板灯。素材 `POWER01`，实物/实屏/同期声。
- **操作与成功判据：** 连续原片拍实际断电灯灭、复电、自启；成片如省略中间等待则明示。
- **画面字幕：** 真实断电｜上电自启｜启动等待已省略（仅发生省略时）。

## 4. 三个剪辑关键点

**M12是真实无操作素材的压缩呈现。** 连续原片保留最后一次有效输入、完整等待、自然消隐及普通键唤醒。主片计划用前56秒8×占7秒，最后4秒1×和黑屏后2秒1×，共13秒。计时由原片定位，标签明确区分加速与原速；完整功能版使用原速区间。原片中实际边沿若偏移，剪辑按真实边沿校准。

**M13到M15使用同一轮保存恢复。** M13先拍普通键只唤醒，再拍保存前的非默认参数与完成指示；M14拍实际断电灯灭、复电和自启；M15在SELECT中逐项查看，数字与保存前一致。主片可省略启动中间等待并标注，连续原片保留全过程。画面中的具体参数值直接来自本次录像。

**字幕与旁白在素材选定后对齐。** 上面是分段录音稿，口播以约每秒3～4个汉字的清晰语速作起点；英语、数字和停顿以实际回听为准。M05末8秒、M11关键静音对比、M12黑屏后2秒等原声窗口优先保留。没有把实际音频、画面和录音对齐前，不生成看似最终准确的SRT。

## 5. 最终画面信息量

每镜通常保留一条功能标签和最多两行旁白字幕。参数、歌词和设备指示本身就是证据，不再用大字覆盖。M16可只用作品名和“本地媒体 / 音画联动 / 实体交互”，完整资源表放入六分钟片或答辩附件。

可在成片说明写“分段实拍，多机位剪辑；等待段按标注压缩，关键操作原速”。这符合本次灵活拍摄要求，也准确说明视频的组织方式。
