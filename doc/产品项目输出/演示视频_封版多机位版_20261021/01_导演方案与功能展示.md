# 导演方案与功能展示

## 1. 作品表达

**VinylFPGA：基于安路FPGA的唱片主题音乐画屏。** 视频从正在工作的实物开始，让观众先看见声音、画面与实体操作怎样关联，再理解内部技术。

开场先放“作品运行最好看的一刻”：转盘转动、两路灯带、清楚的MV/歌词和实际音乐。随后回到选曲、操作、调节、保存恢复的流程。开场画面是同一封版作品的播放片段，主片采用分段展示，不暗示整片为同一次连续实时操作。

观众需要记住的是：这台设备能完整播放本地媒体；操作时画面、声音和实体反馈有明确对应；用户设置能够保存和恢复。把PLL、缓存容量、CDC和完整资源表留给功能片及答辩附件，在可见结果上用一句简洁技术说明辅助理解。

## 2. 两版组织

主片178秒共16镜。采用五个叙事任务：开场认识实物，核验基础链路，展示扩展效果，在一次用户体验中串联操作与记忆，最后回到作品整体。任务可以自然交叠，不重复表演同一轮功能。

完整功能版360秒共14章，加入主片没有充分时间解释的四曲、全部背景、默认恢复、5秒自动保存、三种实际曲终和外设门控。同一批素材分别剪成两版。

拍摄素材按功能段独立录制，允许重拍和更换机位；关键“动作—反馈”要在一份连续全景原片中成立。跨机位剪辑取同一条素材的同步时刻。不同条次可以用在不同功能段，文件名与记录表要能分清。

## 3. 机位与构图

| 机位 | 主要画面 | 推荐构图 | 承担的证据 |
| --- | --- | --- | --- |
| A：主全景 | 屏幕、板卡、主控件、转盘、两路灯带 | 前上方约30～45度；屏幕在上，控件和机构在下，接线从后方走 | 操作与反应同框；暂停、针起落、消隐、断电等重要段持续拍 |
| B：屏幕 | 歌词、进度、波形、MV、参数 | 屏幕尽量正对；保持640×480画面比例，避免反光；固定曝光/白平衡 | 文字和参数可读、全局亮度/对比度变化、曲终结果 |
| C：细节 | 编码器、按键、IR、唱针、转盘、灯带、母板保存指示灯 | 斜侧近景，手从侧面进入；一次突出一个对象 | 手部动作、机构反馈、灯光细节、保存与断电指示 |
| 可选D：真实HDMI采集 | 设备原生输出 | 仅已有并兼容的采集链路通过实录检查后使用 | 高清屏幕细节；与A机同一次操作、音画时间一致 |

这表示三种机位职责，不要求三台新设备。两台设备可以固定A，另一台分批承担B/C。只有一台设备时，关键段用A完整录下，再拍独立的产品细节展示，剪辑时保持各段状态与说明一致。

拍摄高分辨率可以为后期裁切留下余量，以现有设备能稳定录制的模式为准。重点是对焦、屏幕与实体同时可读，以及持续录音；不以4K标签替代实际画质。

## 4. 多人分工

| 角色 | 负责 | 操作边界 |
| --- | --- | --- |
| 统筹/导演 | 报镜号、确认画面、登记条次与片段、控制节奏 | 每次开拍前说清本条唯一主要结果 |
| 主操 | 选曲、旋钮、按键、红外、唱针 | 操作后撤手，让结果停留；同一镜不要两人同时输入 |
| 摄影/收音或辅操 | B/C机位、声音监听、必要时真实供电动作 | 在统筹口令后行动；自动保存/无操作段保持无输入 |

两人可以合并统筹与摄影；供电控制者在冷启动段按明确口令操作。录制时不需要现场长篇解释，后期旁白单独配。

## 5. 让功能“看得见”的拍法

| 功能 | 镜头怎么做 | 关键结果 |
| --- | --- | --- |
| 选曲/切曲 | A见旋钮/按键，B见标题与封面；切换后停一下 | 控件输入与曲目确实改变 |
| 轮播 | 先显示当前间隔，DIP2开后等待一次自动变化 | 停手时自动换图；ROT和实际轮播区分清楚 |
| 转场 | 屏幕大画面，主全景小窗；设备效果完整保留 | 擦入和淡变的真实过程 |
| 音频/歌词/MV/波形 | 选已验收、歌词清楚、声音起伏明显的播放片段 | 一段至少6～8秒无旁白原声，信息可读 |
| 暂停/恢复 | A全景，B局部时间；动作前后均有原声 | 声音、进度和转盘暂停/恢复 |
| 唱针 | C见针动作，A小窗继续见屏幕；音乐轨连续 | 抬针后转盘/唱片灯带停，音乐仍继续 |
| Seek | 时间文本在跳转前后都读得到，再看歌词/MV落稳 | 实际播放位置变化；不只拍手在转 |
| 亮度/对比度 | 同一画面、固定手机曝光；每次改变一项参数 | 当前最终合成图层连同OSD的实际变化 |
| 灯带 | C拍两路同档变化，A保留电机上下文 | WSL调两路；KEY10只控制J2 VU；DIP6是灯带门控 |
| 静音/息屏 | 静音后进度继续；息屏后原声继续 | 两个控制独立、真实声音可辨 |
| 保存/恢复 | B拍保存前非默认值，A/C拍忙与完成；同轮重启后B逐项比对 | 五项参数与保存前一致，镜头能读到数字 |
| 曲终策略 | 每个策略独立一条，提前用正常定位接近曲尾，再原速播完 | 实际暂停、同曲重来、下一曲；图标另作模式说明 |

歌词使用当前ROM，声源为预置PCM；对外准确称“歌词随播放位置呈现”“PCM波形”“参数恢复”。

## 6. 视觉与声音风格

用作品屏幕、唱片和灯带自身形成视觉风格。桌面干净、板卡有柔和补光、屏幕不过曝，转盘轮廓可辨。可在片头和段落标题采用白字、深色底条与一种从实物灯带取出的强调色。

设备自己的擦入/淡变作为功能展示时，剪辑使用干净直切，完整保留设备效果。其他段落可以在手部动作结束或稳定画面处切到同步特写，不需要频繁加入软件转场。

声音以真实设备输出为主体。开播、暂停、静音、抬针后继续、黑屏后继续、重启后播放各留可听窗口。旁白简短分段，避开这些对比；没有必要叠加额外背景音乐。

## 7. 完成状态怎么标

- 功能与最终验收：**用户确认已完成**。
- 封版产物身份/资源/时序：**本轮只读核对，来源明确**。
- 新拍摄脚本、镜头表：**拍摄计划**。
- 录制条次、素材入出点、实测视频时长：**录制后填写**。

完整功能清单中的23类都有位置或附件归属。已完成验收不等于已经录制；记录素材状态即可，保持封版工程不动。
