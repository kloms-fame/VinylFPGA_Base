# 阶段三B 静态图片背景实施计划

> 按 writing-plans 使用独立计划审查、任务实现及规格/质量审查。用户已批准正式阶段三方案，确认3A板级通过，授权提交与继续3B；直接在main开发，3B验收前不提交。

**Goal:** 接入随歌曲变化的静态封面模糊背景和共用蓝紫艺术背景，保留清晰封面/MV、音频优先与整帧切换。

**Architecture:** PC离线生成五张640×480 RGB565 LE图片，写入新FAT32镜像中的连续BG.BIN；在INDEX.BIN保留头字段记录起始LBA，保留v1/v2兼容。低优先级客户端逐扇区扩展RGB888，借用已有写FIFO每次写256词，扇区间释放给MV。尾部两个SDRAM槽缓存当前歌曲及艺术背景。读口逐像素按坐标选择清晰媒体或背景，复用原读FIFO，绘制层只在已就绪图片模式透传背景。

**Tech Stack:** Python/Pillow、FAT32、Verilog-2001、TD/SynthPilot MCP、Icarus；SD100MHz、SDRAM125MHz、video25MHz。
