# Audio SDRAM Prefetch Implementation Plan

> Approved by the user on 2026-10-16. Execute the approved low-byte-plane design; no additional approval is required for implementation or builds. Use subagent-driven-development for independent module implementation/review.

**Goal:** Deliver a complete-product, timing-checked bitstream with a 512 KiB PCM prefetch ring in SDRAM byte lane 0, preserving the existing output FIFO and RGB lanes.

**Architecture:** A single dual-clock BRAM32K stages one producer sector and one consumer sector. SD-domain sector/session logic exchanges held-data toggle mailboxes with a memory-domain short-burst DMA. A registered memory lock blocks both existing graphics burst starters, waits for drain, routes read returns by owner, and yields between chunks. Playback waits for preload and first delivered sector; restart drains old transactions before reusing staging.

**Tech Stack:** Verilog, EG4S20BG256, TD 6.2, SynthPilot MCP, Icarus and available vendor simulation libraries.

DMA fixed interface (all addresses refer to 32-bit SDRAM word addresses):

```verilog
audio_sdram_dma #(BURST_WORDS=32,DRAIN_CYCLES=16,YIELD_CYCLES=16,WATCHDOG_BITS=18)
input mem_clk, rst_n;
input write_request_toggle; input [9:0] write_sector;
output write_ack_toggle; output [7:0] write_error;
input read_request_toggle; input [9:0] read_sector;
output read_ack_toggle; output [7:0] read_error;
output stage_en, stage_we; output [9:0] stage_addr;
output [7:0] stage_din; input [7:0] stage_dout;
input video_read_busy, video_write_busy, controller_busy, refresh_active;
input mem_read_valid; input [31:0] mem_read_data;
output access_lock, read_owner;
output mem_wr_en; output [20:0] mem_wr_addr;
output [31:0] mem_wr_data; output [3:0] mem_wr_mask;
output mem_rd_en; output [20:0] mem_rd_addr;
```

Mailbox sector remains stable from request-toggle change until acknowledgment. Sector address = `{2'b00,sector[9:0],9'b0}`. Write reads staging addresses 0..511; read fills 512..1023. `read_owner` must remain false while waiting for old video returns, and true for all audio read returns. Acknowledge only after all 512 bytes complete and the controller drains. On timeout, acknowledge a nonzero error and release without silently publishing data. Lock is registered, blocks new video read/write bursts, and is released between chunks to grant graphics service.

Stage fixed interface:

```verilog
audio_prefetch_stage(input a_clk,a_en,a_we,input [9:0] a_addr,
 input [7:0] a_din,output [7:0] a_dout,
 input b_clk,b_en,b_we,input [9:0] b_addr,
 input [7:0] b_din,output [7:0] b_dout);
```

The behavioral flag is `VINYL_AUDIO_CACHE_SIM`; production uses `EG_PHY_BRAM32K`. Reads are synchronous with one-cycle latency and enabled by the corresponding `*_en`.
