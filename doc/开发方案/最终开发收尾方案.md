# VinylFPGA 最终执行开发方案（极低资源·分阶段闭环版）

## 一、 核心设计准则与您确认的 8 项决策锁定

当前 EG4S20BG256 已交付基线的 Slice 占用率为 **`9399 / 9800 (95.91%)`**，仅余 **401 个 Slice**；BRAM9K 已满（`64 / 64`）。因此，本方案以 **“严控 Slice 增长、0 BRAM 消耗、由简入繁、每阶段独立编译与上板验收”** 为最高铁律，并将您确认的全部细节锁定如下：   

1. **遥控器 6 个新增键属性**：`F3/A1/BD/B5/E6/F2` 均为同一张遥控器上的实体按键，阶段 0 先用诊断固件核对 32 位帧码，阶段 3 正式合入译码。   
2. **故障琵琶音报警与 SW4 门控**：需要覆盖“无卡 / 挂载失败 / 播放欠载”全部故障；为极致节省资源，**不新增独立蜂鸣分频器**，直接复用 `buzzer_feedback.v` 现成的双音阶交替通道（`EV_DIP` 高低双音），总开销仅 **6 LUT**。   
3. **KEY2 参数复位与存储作用域**：
   - **Flash 存储范围**：仅保存 `50 MHz` 域的 5 项 OSD 参数（`VOL/BRI/CON/ROT/WSL`）以确保 **0 额外跨时钟域回写开销**（若把跨在 `100 MHz` 和 `25 MHz` 的转场/结束策略/背景也塞进 NVM，需增加双向 CDC 握手，多耗约 45 Slice，性价比极低）。   
   - **KEY2 复位范围**：短按 `KEY2` 除恢复 5 项参数默认值并擦除 Flash 外，同时发出一个单拍复位脉冲将 **背景模式 (`background_mode`)、转场模式 (`effect_mode`)、结束策略 (`end_mode`)** 一并恢复为开机默认状态（仅需 3 个或门，0 额外寄存器）。   
4. **SW3 自动保存默认状态**：出厂及常态测试默认将 `SW3` (`C6`) **拨上（开启 5 秒自动保存）**。   
5. **KEY6 歌词动效**：本次明确**不开发**，保持零消费者状态，节省宝贵的 Slice 余量。   
6. **扩展板 LED1~4 vs 主板 LED1~4**：
   - **J2 扩展板 `exp_led_n[3:0]`**：保持现有 `led_business_driver.v` 的“动作脉冲 / IR / MV / 故障+心跳”语义及**低电平点亮**不变（0 改动）。   
   - **主板 `led[3:0]` (`A4/A3/C10/B12`)**：按《产品交互.md》实现“系统心跳 / TF挂载就绪 / 播放活动 / 故障告警”语义，物理电路为共阴极**高电平点亮**。   
7. **开发推进顺序**：严格按 **阶段 0（基线清理）$\to$ 阶段 1（0 资源改默认值）$\to$ 阶段 2（~40 LUT 主板控件与静音）$\to$ 阶段 3（~55 LUT 红外升级）$\to$ 阶段 4（~110 LUT Flash 存储）** 推进。   

## 二、 极致省资源架构优化清单（从预估 330 LUT 压降至 ~205 LUT）

通过对您最新上传的 `expansion_integration.v`、`buzzer_feedback.v`、`ui_param_csr.v`、`ec2_param_osd.v` 源码逐行分析，我们在原修订方案基础上进一步砍掉了近 40% 的逻辑开销：   

| **功能模块**           | **常规写法开销**                                             | **最终极简复用写法（本方案采用）**                           | **实际净增资源**     |
| ---------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | -------------------- |
| **主板 LED1~4 驱动**   | 复制 `led_business_driver`（104 LUT / 23 FF）                | 复用 `expansion_integration` 内的 `ui_tick_1ms`，仅用 **1 个 10-bit 计数器 `hb_cnt[9:0]`**（`hb_cnt[9]` 即 ~1Hz 方波）驱动 4 路组合逻辑 | **16 LUT / 14 FF**   |
| **SW4 故障琵琶音**     | 在 `buzzer_feedback` 新增独立音型分支（~35 LUT）             | 复用 `buzzer_feedback.v` 现成的 `EV_DIP` 双相位高低音通道（第 102~106 行 `dip_second_phase`），将故障脉冲受 `SW4` 门控后并入 `dip_change_any` | **6 LUT / 2 FF**     |
| **OSD 静音提示**       | 重写字符渲染区显示 `"MUTE"` 或数码管加 2FF 跨时钟域（~25 LUT） | 在 `ec2_param_osd.v` 第 175 行 `PARAM_VOL` 数值显示区，利用现成的 `text_slot == 3'd4` 空位显示 `'M'`（即静音时显示 `200 M`），**既能看清原音量 200 未丢，又有醒目 M 静音标志**；同时接通 `u_ws2812_effects.mute(mute_active)` | **2 LUT / 0 FF**     |
| **NVM 保存完成提示音** | 在 `buzzer_feedback` 新增 `EV_NVM` 分支                      | 将 `nvm_save_done_pulse` 直接或入 `expansion_integration.v` 第 308 行的 `slideshow_beep_event`（触发 `EV_AUTO`：4kHz 12ms 清脆短音） | **1 LUT / 0 FF**     |
| **Flash SPI 物理层**   | 手写 SPI bit-bang 移位状态机                                 | 直接例化 `src/SD/spi_master.v`，外围仅包一个 5 字节指令序列状态机，挂在独立 GPIO 的 `U33 (W25Q64)` 上 | **~110 LUT / 85 FF** |
| **全工程总计增量**     | 约 330~370 LUT                                               | **全阶段累计仅约 205 LUT / 125 FF（约占 110~140 Slices，远低于 401 Slices 警戒线）** | **0 BRAM / 0 DSP**   |

- **Task 2.5：实现 `SW4` (`C5`) 系统故障琵琶音告警总控（极简 6 LUT 方案）**

    - 新发故障边沿：`wire fault_trig = (osd_err_valid && (osd_err_code != 8'd0)) || underrun_pulse;`
    - 持续无卡/挂载失败周期提醒：当 `(err_code != 8'd0)` 持续存在时，利用下文的主板 LED 毫秒计数器每 **2.048 秒** 产生一个单拍提醒脉冲 `fault_periodic_pulse`；
    - 门控并入双音通道：`wire fault_alarm_pulse = board_sw_level[3] && (fault_trig || fault_periodic_pulse);`

- **Task 2.6：实现主板 `LED1~LED4` (`A4/A3/C10/B12`) 高电平状态驱动**

  - 在顶层将 `play_active_sd` 和 `paused_sd` 经 2FF 同步到 `50 MHz clk` 域（`play_active_clk`, `paused_clk`）；   
  - 利用 `ui_tick_1ms` 驱动一个 11-bit 毫秒计数器 `hb_cnt[10:0]`（`hb_1hz = hb_cnt[9]`，`blink_4hz = hb_cnt[7]`）：
    - `led[0]` (`A4` 系统心跳)：`(sys_pll_lock & video_pll_lock) & hb_1hz`；   
    - `led[1]` (`A3` TF卡就绪)：`media_ready_clk_sync[1] ? 1'b1 : (!boot_active_clk_sync[1] & blink_4hz)`（挂载完成常亮，扫描中 4Hz 快闪，失败灭）；   
    - `led[2]` (`C10` 播放活动)：`play_active_clk ? (paused_clk ? hb_1hz : 1'b1) : 1'b0`（播放常亮，暂停 1Hz 闪烁，浏览态熄灭）；   
    - `led[3]` (`B12` 故障告警)：`(|fault_flags_clk) || (media_err_code_clk != 8'd0)`（有故障点亮，正常熄灭）。

### 🔴 阶段 4：板载 SPI Flash (`U33 W25Q64`) 参数存储记忆系统（难度：★★★★☆ | 新增资源：约 110 LUT / 85 FF，0 BRAM）

#### 1. 阶段开发内容

复用现有的 `src/SD/spi_master.v` 驱动主板上独立挂在普通 GPIO 的 **`U33 (W25Q64)`** Flash 芯片（避开 `U39` MSPI 专用配置脚约束风险），实现上电自动读取恢复 5 项参数、`KEY3` 手动保存、`SW3`（默认拨上开启）参数停变 5 秒自动保存 + 蜂鸣器短鸣、以及 `KEY2` 短按一键恢复默认参数（含重置背景/转场/结束策略）并擦除 Flash。   

#### 2. 具体开发任务

- **Task 4.1：顶层 Flash 引脚端口与 `constraints/pin.adc` 约束**

  - 选用主板 `U33 (W25Q64)`（《开发板手册》第 17 页图 2-17，板上 `WP/HOLD` 已接 3.3V 或可通过输出常高固定）：   

    Tcl

    ```
    set_pin_assignment { nvm_cs_n } { LOCATION = P8; IOSTANDARD = LVCMOS33; DRIVESTRENGTH = 8; PULLTYPE = PULLUP; }
    set_pin_assignment { nvm_sclk } { LOCATION = M9; IOSTANDARD = LVCMOS33; DRIVESTRENGTH = 8; PULLTYPE = NONE; }
    set_pin_assignment { nvm_mosi } { LOCATION = P7; IOSTANDARD = LVCMOS33; DRIVESTRENGTH = 8; PULLTYPE = NONE; }
    set_pin_assignment { nvm_miso } { LOCATION = N8; IOSTANDARD = LVCMOS33; PULLTYPE = PULLUP; }
    ```

- **Task 4.2：定义 5 字节紧凑存储帧格式（扇区首地址 `24'h000000`）**

  - `Byte 0`：`8'hA5`（魔数 Magic，区分空扇区 `8'hFF`）；   
  - `Byte 1`：`VOL[7:0]`（音量 `0~255`）；   
  - `Byte 2`：`{2'b00, WSL[2:0], ROT[2:0]}`（灯带亮度 + 轮播周期）；   
  - `Byte 3`：`{2'b00, CON[2:0], BRI[2:0]}`（对比度 + 亮度）；   
  - `Byte 4`：`Byte0 ^ Byte1 ^ Byte2 ^ Byte3`（8-bit 异或校验和，仅耗 8 个 XOR 门，0 BRAM）。   

- **Task 4.3：升级 `src/io/ui_param_csr.v` 支持外部加载与一键复位**

  - 新增接口：`input wire load_valid`、`input wire [19:0] load_params`、`input wire reset_defaults`：   
    - 当 `reset_defaults == 1'b1`（按下主板 `KEY2`）时，将 5 项寄存器恢复为阶段 1 默认值（`VOL=200, BRI=3, CON=2, ROT=3, WSL=4`）并拉高 `param_update <= 1'b1`；同时将 `key2_fall_pulse` 同步至 `effect_mode`、`end_mode`、`background_mode` 使其一并归位为默认状态；   
    - 当 `load_valid == 1'b1`（上电 Flash 校验通过）时，将 `{WSL, ROT, CON, BRI, VOL}` 覆写进寄存器并拉高 `param_update <= 1'b1`。   

- **Task 4.4：编写 `src/io/param_nvm_controller.v`（复用 `spi_master.v`）**

  - 例化 `spi_master`（`clk_div = 16'd6` 即 3.125MHz，`CPOL=0, CPHA=0`）；   
  - **上电自动恢复 (`ST_BOOT_READ`)**：`exp_rst_n` 释放后延迟 10ms（待 Flash 上电稳定），发送 `03h + 24'h000000` 读回 5 字节；若 `Byte0 == 8'hA5` 且异或校验等于 `Byte4`，发出 `load_valid` 覆写 CSR；否则保持默认值（即使拔掉或不焊 Flash 也不会卡死）；   
  - **SW3 5 秒防抖自动保存计时器**：
    - 监测用户调节导致的 `param_update_csr` 脉冲（排除上电 `load_valid` 自身触发），置位 `dirty <= 1'b1` 并重载毫秒倒计时器 `timer_ms <= 13'd5000`（若 5 秒内再次调节参数，则重新装载 `13'd5000` 重新计时 5 秒）；   
    - 当 `board_sw_level_clk[2] == 1'b1`（`SW3` 拨上）且 `dirty == 1'b1` 且 `timer_ms == 13'd0` 时，自动启动 `ST_SAVE`；   
  - **KEY3 手动保存与 KEY2 擦除复位**：
    - 按下主板 `KEY3 (B1)`：无论 `SW3` 状态与倒计时如何，立即清零 `dirty` 并启动 `ST_SAVE`（`06h` 写使能 $\to$ `20h` 4KB 扇区擦除 $\to$ `05h` 轮询 `WIP==0` $\to$ `06h` 写使能 $\to$ `02h` 写 5 字节 $\to$ `05h` 轮询 `WIP==0`）；   
    - 保存完成时输出单拍脉冲 `nvm_save_done_pulse`，在 `expansion_integration.v` 中或入 `slideshow_beep_event`，**触发蜂鸣器“滴”短鸣一声**；   
    - 按下主板 `KEY2 (B2)`：清零 `dirty`，触发 `reset_defaults`，并启动 `ST_ERASE`（`06h` $\to$ `20h` 擦除扇区 $\to$ `05h` 轮询完成），彻底清除 Flash 中的旧参数。
