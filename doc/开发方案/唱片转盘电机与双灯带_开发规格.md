# 唱片转盘电机与双灯带开发规格

## 目标

播放期间唱针开关置 ON 时，驱动减速直流电机，并让原理图新增的 8 颗 WS2812B 灯带显示 8 色循环跑马灯。暂停、停止、浏览和复位时，电机关闭、新灯带熄灭。保留工程现有 J11 灯带效果。DIP6 是两条 WS2812 灯带的总使能。

## 已确认需求

| 项目 | 规格 |
| --- | --- |
| 播放条件 | `play_active && !paused` |
| 唱针条件 | 机械开关 ON；干接点；不做消抖 |
| 电机条件 | 播放条件且唱针有效时全速开；其他情况关；复位时关 |
| 电机驱动 | G11 只控制 AO3400A 栅极，不直接驱动电机 |
| 新灯带 | 8 颗串接 WS2812B，颜色整组循环移动 |
| 移动速度 | 每个位置停留 125 ms，完整循环约 1 s |
| 颜色顺序 | 红、橙、黄、绿、青、蓝、紫、品红 |
| 亮度 | 90% |
| WS 总使能 | DIP6 关闭时两条灯带均熄灭；打开后 J11 保留原效果，新增灯带按唱针条件运行 |
| 新增引脚 | GPIOA_0 / D14：新 WS 数据；GPIOA_1 / G11：电机使能；GPIOA_2 / G12：唱针输入 |

## 当前工程基线

- 工程器件为 EG4S20BG256，系统输入 `clk` 为 50 MHz。
- `play_active_sd` 和 `paused_sd` 位于 `sd_card_clk` 域；目前通过两级同步跨到 `video_clk`，但还没有跨到扩展板 50 MHz `clk` 域。
- `expansion_integration` 运行在 50 MHz `clk` 域，已有 `ws_enable`（DIP6）和一条 `exp_ws2812_data` 输出。
- 现有 `ws2812_effects` 已实例化 8 像素 WS2812 驱动，刷新周期为 20 ms；KEY10 控制全灭/VU 模式，DIP6 关闭时会补发黑帧后停止刷新。
- 当前 `exp_ws2812_data` 约束在 J11。新增 D14 尚无顶层端口和引脚约束。因此新灯带必须是独立输出，不能把现有 J11 输出改接成 D14，否则会丢失原灯带。
- 当前顶层没有唱针输入和电机输出端口。现有播放/暂停状态及 WS 总使能可直接复用。

## 推荐架构

### 状态同步和控制条件

在 50 MHz `clk` 域对 `play_active_sd`、`paused_sd`、G12 唱针输入各使用两级同步器。唱针不添加计数型消抖器，遵照用户要求。用同步后的状态形成：

```text
play_run       = S5_PLAY_ENABLE && play_active_sync && !paused_sync
needle_on      = !needle_sense_sync       // 按原理图上拉、开关闭合接地的接法
motor_request  = rst_n && play_run && needle_on
vinyl_led_run  = ws_enable && play_run && needle_on
```

`motor_request` 不受 DIP6 影响；DIP6 只控制两条 WS2812 灯带。该划分符合“DIP6 控制 WS2812 总使能”和电机由播放/唱针条件控制的要求。若原理图开关实际为 ON 输出高电平，只需反转 `needle_on` 的极性定义。

### 新增灯带灯效

- 保留 J11 现有 `ws2812_effects` 实例和行为。
- 新增独立 D14 灯带控制实例，复用已有 `ws2812_driver` 的串行时序模块，采用 `STREAMING=1`，组合生成当前像素颜色，不存储 8×24 位帧缓存。
- 复用 `expansion_integration` 现有 1 ms `ui_tick_1ms`。新增 7 位计数器计满 125 个毫秒节拍后递增 3 位颜色相位；8 个相位循环回绕。无需新增 6,250,000 周期的 23 位自由运行计数器。
- 对 LED 索引 0..7 生成颜色序列，帧内固定相位，下一次相位步进后整组颜色向数据链索引递增方向移动。板上若要求顺时针，WS 串接顺序应与该方向一致。
- RGB 颜色分量按 90% 亮度缩放（满量程上限约 230/255），在送入现有驱动前按驱动要求转换为 GRB 字节序。
- 新灯带建议保持现有 20 ms 帧刷新节奏。`vinyl_led_run` 变低或 DIP6 关闭时，先发送一帧全黑，再停止刷新；复位后也先确保灯带收到黑帧。

### 顶层和引脚接入

顶层增加三个具名端口并接入 `expansion_integration`：唱针输入、`vinyl_motor_en` 输出、新 WS 数据输出。`constraints/pin.adc` 新增 D14、G11、G12 的 LVCMOS33 管脚分配。保留已有 `exp_ws2812_data` 到 J11 的约束。G11 仅接 MOSFET 栅极网络；按原理图检查栅极串联电阻和下拉电阻仍在位。G12 使用原理图外部上拉，不再启用内部上拉以免重复改变电气条件。

## 资源估算

本功能不需要 PLL、RAM、乘法器、PWM 或高频分频时钟。新增状态主要为：播放/暂停/唱针同步寄存器约 6 个触发器、3 位颜色相位、7 位毫秒计数、少量条件译码；另增加一个 WS2812 序列器实例（FSM、位/像素索引和时序计数器）。8 个颜色使用常量译码，不构建 LUT/RAM 帧存储。实际 LUT/寄存器增量须在实现后由 TD 综合报告确认。

## 验收条件

1. 上电、复位时 G11 为低，电机不启动。
2. 未播放、暂停或浏览时，无论唱针开关位置如何，G11 为低且 D14 灯带最终全灭。
3. 已播放且未暂停时，唱针 OFF 不启动电机、不点亮 D14；唱针 ON 后 G11 拉高并运行 D14 跑马灯。
4. 跑马灯每 125 ms 移动一个 LED 位置，约 1 s 完成一圈，颜色顺序和 90% 亮度符合规格。
5. 停止/暂停/唱针 OFF/DIP6 OFF 后，电机按条件关闭；D14 发送黑帧并熄灭。
6. DIP6 OFF 时 J11 与 D14 两条灯带都熄灭；DIP6 ON 后 J11 原有 VU/KEY10 行为不变，D14 仅在播放且唱针 ON 时运行。
7. 新功能不改变现有播放、暂停、选曲、J11 灯效、音频、HDMI 和 SD 数据路径。

## 实施前的硬件核对

- 确认 G12 的机械 ON 状态确实闭合到 GND；原理图的 10 kΩ 上拉对应低有效输入。
- 核对新增 WS2812B 的 VDD 实际电压、该器件版本的 VIH 门限和 3.3 V FPGA 数据输出裕量。原理图显示 WS 电源由 +5 V 经 SS14 到达，不能只凭“3.3 V 通常可用”判断逻辑高裕量。
- 核对电机额定电压/启动电流与 CN1 电源、AO3400A、D2 续流路径相符；确认 G11 连接的是栅极电阻网络，不是电机电源端。
- 物理灯带索引 0 的位置决定视觉转向；如果 LED 顺序未沿目标方向布置，逻辑索引递增可能表现为反方向，应通过交换相位步进方向适配，不改变硬件引脚。

## 后续实施边界

这是需求/架构规格，不是 RTL 补丁。需求已达到明确的信号、跨域、时序和验收粒度。进入 RTL 前应先建立 WS2812 帧/相位和播放条件的参考波形基线，再实现、定向仿真和综合，最后核对管脚报告与板上行为。现有工作区有其他未提交改动，后续实施必须仅在相关代码和约束上做窄范围修改，不清理或覆盖这些改动。
