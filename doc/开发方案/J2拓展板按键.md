### 一、 FPGA 开发板主板交互控件

| 丝印    | **控件名称**   | **硬件标识 / 端口** | **FPGA 引脚** | **功能说明**                                                 |
| ------- | -------------- | ------------------- | ------------- | ------------------------------------------------------------ |
| KEY1    | **系统复位键** | `RESET` / `rst_n`   | **`A2`**C8    | 全局硬件复位（低电平复位，重置 PLL、SDRAM、音视频引擎及 UI 状态） |
| KEY2    | 参数复位       | key2                | B2            | 系统参数恢复默认配置，清除存储数据                           |
| KEY3    | 暂定           |                     | B1            |                                                              |
| KEY4    | 一键静音       | key4                | C1            | 全局音频快速静音，音量关闭，再按下恢复原音量                 |
| DIG/LED | 不使用         |                     | 硬件线路      |                                                              |
| BUZ_SW  | 蜂鸣器开关     | (物理刀闸开关)      | H11           | **板载物理硬开关**：通断蜂鸣器供电回路（不占 FPGA 引脚）     |
| SW1     | 数码管总控     | sw1                 | C8            | 8位数码管显示总使能（拨上=1点亮扫描，拨下=0熄灭关闭）        |
| SW2     | 板载调试开关1  | sw2                 | C7            | 系统辅助调试开关                                             |
| SW3     | 暂定           |                     | C6            |                                                              |
| SW4     | 暂定           |                     | C5            |                                                              |
| LED1    | 板载指示灯1    | led[0]              | A4            | 系统运行/时钟锁定心跳指示（低电平点亮）                      |
| LED2    | 板载指示灯2    | led[1]              | A3            | 媒体/TF 卡挂载就绪指示（低电平点亮）                         |
| LED3    | 板载指示灯3    | led[2]              | C10           | 音频播放活动指示（低电平点亮）                               |
| LED4    | 板载指示灯4    | led[3]              | B12           | 故障/错误状态告警指示（低电平点亮）                          |
| BUZZER  | 反馈音效       |                     | H11           |                                                              |
| 数码管  | 反馈显示       |                     | 8位数码管     | 8位动态扫描数码管，展示曲号、播放时间                        |



### 二、 J2 扩展板交互控件（通过 IDC40 排线接入）

#### 1. 旋转编码器（EC1 与 EC2）

| 丝印 | **控件名称**            | **硬件标识 / 端口** | **FPGA 引脚** | **J2 排针** | **功能说明**                                                 |
| ---- | ----------------------- | ------------------- | ------------- | ----------- | ------------------------------------------------------------ |
| SW1  | **左编码器 EC1 - A相**  | `exp_enc1_a`        | **`P4`**      | J2.1        | 选曲/进度微调：浏览态旋转切歌；播放态旋转快进/快退（±2s）    |
| SW1  | **左编码器 EC1 - B相**  | `exp_enc1_b`        | **`N4`**      | J2.2        | 正交判相：配合 A 相识别旋转方向与脉冲步进                    |
| SW1  | **左编码器 EC1 - 按键** | `exp_enc1_sw_n`     | **`N3`**      | J2.3        | 下按键：浏览态确认选中播放；播放态暂停 / 恢复播放            |
| SW2  | **右编码器 EC2 - A相**  | `exp_enc2_a`        | **`M5`**      | J2.4        | 参数调节：音量(VOL)、亮度(BRI)、对比度(CON)、轮播周期(ROT)、灯带亮度(WSL)增减 |
| SW2  | **右编码器 EC2 - B相**  | `exp_enc2_b`        | **`M3`**      | J2.5        | 正交判相：配合 A 相识别旋转方向与脉冲步进                    |
| SW2  | **右编码器 EC2 - 按键** | `exp_enc2_sw_n`     | **`M4`**      | J2.6        | 下按键：呼出/关闭参数浮窗，循环切换当前调节的参数项          |

#### 2. 独立按键（KEY1 ~ KEY12）

| 丝印 | **控件名称**   | **硬件标识 / 端口** | **FPGA 引脚** | **J2 排针** | **功能说明**                                                 |
| ---- | -------------- | ------------------- | ------------- | ----------- | ------------------------------------------------------------ |
| SW4  | **按键 KEY1**  | `exp_key_n[0]`      | **`N1`**      | J2.13       | **左方向键**：选歌界面向左切歌；播放界面快退                 |
| SW5  | **按键 KEY2**  | `exp_key_n[1]`      | **`M2`**      | J2.14       | **中间确定**：选歌界面确认播放；播放界面暂停/继续播放        |
| SW6  | **按键 KEY3**  | `exp_key_n[2]`      | **`M1`**      | J2.15       | **右方向键**：选歌界面向右切歌；播放界面快进                 |
| SW7  | **按键 KEY4**  | `exp_key_n[3]`      | **`L1`**      | J2.16       | **上方向键**：选歌界面曲目向前滚动；播放界面上翻行           |
| SW8  | **按键 KEY5**  | `exp_key_n[4]`      | **`H2`**      | J2.17       | **下方向键**：选歌界面曲目向后滚动；播放界面下翻行           |
| SW9  | **按键 KEY6**  | `exp_key_n[5]`      | **`H1`**      | J2.18       | **歌词动效切换**：歌词滚动与逐字高亮动效切换                 |
| SW16 | **按键 KEY7**  | `exp_key_n[6]`      | **`G1`**      | J2.19       | **退出播放键**：播放态独占返回选歌浏览界面                   |
| SW17 | **按键 KEY8**  | `exp_key_n[7]`      | **`G3`**      | J2.20       | **播控视窗键**：切换左侧视窗显示内容（静态封面图 $\leftrightarrow$ 动态 MV 视频） |
| SW18 | **按键 KEY9**  | `exp_key_n[8]`      | **`L4`**      | J2.21       | **切歌动效切换**：切换图片转场特效模式（淡入淡出 / 百叶窗 / 直切） |
| SW19 | **按键 KEY10** | `exp_key_n[9]`      | **`L5`**      | J2.22       | **WS灯效切换**：WS2812 灯带模式切换（全灭关闭 $\leftrightarrow$ 音频电平 VU 律动） |
| SW20 | **按键 KEY11** | `exp_key_n[10]`     | **`J12`**     | J2.31       | **播放背景切换**：循环切换播放界面 4 模态背景（磨砂灰/彩色虚化/艺术图1/艺术图2） |
| SW3  | **按键 KEY12** | `exp_key_n[11]`     | **`K11`**     | J2.32       | **播放模式切换**：循环切换播放结束策略（单曲暂停 $\to$ 单曲循环 $\to$ 列表自动下一首） |

#### 3. 拨码开关（DIP1 ~ DIP6，上拨为 1 / 下拨为 0）

| 丝印 | **控件名称**  | **硬件标识 / 端口** | **FPGA 引脚** | **J2 排针** | **功能说明**                                                 |
| ---- | ------------- | ------------------- | ------------- | ----------- | ------------------------------------------------------------ |
| SW10 | **拨码 DIP1** | `exp_dip_n[0]`      | **`L3`**      | J2.7        | 扩展板业务总开关（拨下屏蔽扩展板控制输入）                   |
| SW11 | **拨码 DIP2** | `exp_dip_n[1]`      | **`J3`**      | J2.8        | **自动轮播开关**：拨上开启封面幻灯片自动轮播，拨下关闭       |
| SW12 | **拨码 DIP3** | `exp_dip_n[2]`      | **`J4`**      | J2.9        | **扩展LED总控**：拨上使能扩展板 4 颗 LED 显示，拨下强制熄灭  |
| SW13 | **拨码 DIP4** | `exp_dip_n[3]`      | **`H4`**      | J2.10       | **屏幕消隐开关**：拨上60s自动 HDMI 画面黑屏消隐（音频不停），拨下恢复显示 |
| SW14 | **拨码 DIP5** | `exp_dip_n[4]`      | **`K14`**     | J2.33       | **红外使能开关**：拨上允许接收红外遥控命令，拨下屏蔽红外信号 |
| SW15 | **拨码 DIP6** | `exp_dip_n[5]`      | **`L12`**     | J2.34       | **WS灯条总控**：拨上使能 WS2812 彩灯输出，拨下强制清屏断开数据流 |
