# MV 三缓冲调度（阶段三，2026-10-18）

MV 的 SDRAM 空间已按三块完整帧分配：当前显示区、另一块帧区和第三块帧区。原调度器在帧写入完成后仍把 `busy` 保持到下一个显示帧边界，导致写入端最多只有“显示+写入”两块并行，第三块不能在垂直同步等待期间承接下一帧。

调度器现将完成写入的帧登记为待显示区，完成确认后立即释放写入端，并在第三块空闲区启动下一帧。显示区只在 `frame_start` 更新；分配器明确避开当前显示区和待显示区。若音频时间已越过排队帧，则优先提交最新的已完成目标帧，旧待显示帧可被跳过。首帧保持原顺序，确保启动后显示第一个已就绪帧。

没有增加帧 RAM，沿用 3×76,800 个 32-bit SDRAM 字的现有容量。本阶段只做静态差异检查，未运行仿真/综合/板上验收；三缓冲调度改动需要纳入用户最后的全体验收。
