## 实际发现与修改

1. 保留 R5 的 512 KiB SDRAM 低字节环、960 扇区预填、1008 高水位、现有 4K×16 FIFO、单 BRAM32K staging、32 word DMA 分段和 DQM 语义。恢复的 8 个 RTL 见交接 manifest。
2. `audio_sdram_dma.v`：新增读返回超时后的隔离排空。旧实现 watchdog 后释放 owner；新增测试先复现该断言失败，再验证修复。失败扇区不会发布/写入消费 staging，所有已发读返回和安静尾部排空前不接新 mailbox。永久丢失返回时保持隔离，需协调复位 SDRAM 控制器和两侧 mailbox；不宣称这种物理故障能够无复位自愈。
3. `fat32_file_streamer.v`：首簇和 FAT 后续簇统一经过 `ST_CLUSTER_DELTA`；独立 always 中 CE 仅依赖本地状态。每个有效簇转换增加一拍，范围/链路错误不发数据请求。14 个定向事务用例和原碎片链测试通过。
4. `song_index_db.v`：寄存 entry/field/lane 与对应输入 byte，独立字段 bank 写入；增加 `P_FLUSH`，排空字段写入后校验。CRC 也正确计入与 in_done 同拍的最后一个有效字节。新增 8 轮所有字段 byte lane、插空、重载与末字节 done 测试；旧实现同拍 done 用例报 CRC 错，修改后通过。既有 magic/CRC/count/cluster/stream error 和背景扩展测试保留。
5. `background_cache_loader.v`：将慢变 art2 capability 与 source base 同步寄存，断开全局 index valid 经 art_changed/start_art 到地址 CE/状态的路径。只增加 1 位寄存器，不改缓存配置或调度协议。
6. WAV flow 测试的交接 oracle 预期 3584；指定基线生产 RTL 实际阈值是 3072（3/4）。保留原失败日志，修正测试规格为准确的 3072，保留精确高水位、15 扇区顺序/指针环绕/末尾 drain 检查，未修改生产 FIFO 阈值。
7. 回归 runner 增加独立输出目录和逐输入哈希，拒绝覆盖已有目录。TD phase runner 拒绝覆盖脚本、日志、DB；逐阶段校验快照输入、完成标记和新产物，不只依赖退出码。vendor runner 保留独立 WLF、run.do/wave.do 和本地 ModelSim library mapping。

- 新 mailbox 的 payload 在 request 前发布、ack 前保持；两级 toggle 同步后采样。BRAM 两半分别归 producer/consumer，取消/媒体软复位等待在途，失败读返回保持 owner 隔离。原 Gray FIFO、reset_sync 及全局复位异步断言/各域同步释放保持。永久丢失读返回需要协调硬复位，不能仅用媒体软复位强行释放 owner。
- 继承的 async clock groups、reset/synchronizer false paths、HDMI max_delay、shifted-clock 例外保持原值；video/hdmi_5x 同源同步路径继续分析。CDC 协议仿真不等价于形式化穷尽 CDC 或 MTBF 厂商签核。
- 33 个无 input delay：机械/编码器/IR/SW 等异步同步输入，外部 rst_n，以及 sd_miso、HDMI_DDC_SDA。38 个无 output delay：SD SPI、HDMI/DDC、WS2812/UART 和数码管/LED/蜂鸣器/扩展输出。同步接口还缺外部器件窗口、板延迟和采样相位；异步 UI 不能机械套同步 0ns 延迟。没有虚设 I/O delay 或通过 false path/multicycle 清零。

因此发布 manifest 明确 `internal_sta_pass=true`、`external_io_signoff_complete=false`、`hardware_acceptance=pending`。本轮结论是**现有约束下内部时序与 bitgen 通过的人工验收候选**，不是所有外部接口/板级条件已正式签核。

## 用户人工上板验收

1. 只烧录本记录指定 RELEASE 文件；先用 Get-FileHash 核对完整 SHA-256，记录文件名、卡型号/镜像、曲目和播放模式。
2. 记录长播起止时刻、串口欠载/扇区指标和异常时刻；新版本尚无上板长播结果，不能沿用 R5 的历史反馈。
3. 检查暂停/继续、快速切歌、首尾 Seek/重播、短曲/EOF、MV/背景并发、正常媒体失效与恢复。区分正常起播预填、有限缓存耗尽和真正不可恢复停机。
4. 512KiB 是有限储备；本轮事务测试覆盖约4.90秒零新供数预算，不保证任意长无输入或长期平均吞吐低于96kB/s仍不断音。

允许交给用户人工烧录验收；本轮没有执行任何开发板连接、编程或烧录。RTL/模型仿真、内部 STA/bitgen、用户上板验收三个层次的状态保持明确区分。
