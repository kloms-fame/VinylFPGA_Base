# 产品收尾审查与优化计划（2026-10-18）

> 本轮最终范围已按用户最新要求收口为“确保生成 bit”。BMP 优化实验因打包、路由或时序结果不满足保留条件，全部撤销；最终保留 a63d681 的生产 RTL、area_prior / seed 6，从 r0 已完成路由的数据库生成匹配当前输入的新候选。以下优化方向作为后续讨论材料，本轮不再执行。最终产物见《收尾优化记录_20261018.md》。

## 3. 时序问题的定位方法

优化前最差路径位于 `fat32_media_loader` 的像素计数反馈：`pixel_count[13] -> pixel_count[15].ce`，8 级 LUT，数据路径 12.802 ns，其中连线 10.217 ns（80%）。不是单个加法器的延迟问题。

| 时钟域 | r0 SWNS | 优先级和说明 |
|---|---:|---|
| sd_card_clk，100 MHz | -3.082 ns | P0；342 个 setup 违例端点，先消除像素反馈宽比较，再跟踪 INDEX/扇区控制路径 |
| ext_mem_clk，125 MHz | -0.114 ns | P0；2 个 setup 违例端点，检查 FIFO/burst/地址路径 |
| clk，50 MHz | +0.319 ns | 余量小，暂不增加 UI/NVM 功能 |
| video_clk，25 MHz | +7.190 ns | 时序有余量，适合评估显示路径的资源压缩 |
| hdmi_5x_clk，125 MHz | +1.597 ns | 每轮复核，防止拥塞变化带来新违例 |

r1 的像素改法虽然节省 36 Slice，却使最差路径迁移到 song_index_db，SWNS 恶化到 -5.239 ns。因此每轮必须同时看 WNS、TNS、违例端点和所有时钟域，不能只消掉上一条最差路径。

后续时序修改优先使用已有协议空闲拍拆开选择、比较、算术和状态更新；必要流水需证明数据、valid、done、错误优先级及握手同步对齐。不能随意给仍为单拍反馈的逻辑添加 multicycle/false_path，也不通过降低时钟宣称原频率时序闭合。

## 4. 资源优化候选

以下为 r0 层次报告的定位数据，lut 列是层次逻辑 LUT，不含单列 ripple；不能与总 LUT 18241 混为同一口径。表内父模块包含其子模块，不可重复求和。

| 模块 | LE | 逻辑 LUT | seq | 主要关注点 |
|---|---:|---:|---:|---|
| sd_card_bmp_m0 | 4200 | 3721 | 3331 | 扫描、INDEX、流控、元数据和加载数据路径 |
| u_expansion_integration | 1978 | 1692 | 963 | 多路消抖/计时、事件路由；用户交互敏感，放在媒体路径之后 |
| HDMI transmitter wrapper | 1765 | 1527 | 1464 | 厂商协议核，先保留，不作为首轮重写目标 |
| playback page | 1271 | 1210 | 372 | 字形、区域判定、重复选择和 ROM 映射 |
| frame_read_write_m0 | 831 | 633 | 482 | 读写地址、FIFO credit、burst 控制 |
| u_lrc_window_controller | 742 | 715 | 573 | 六行宽 glyph 缓存及滚动搬移，是面积候选 |
| playback progress | 605 | 576 | 391 | 数字格式化和图标选择；保留当前显示功能 |
| ui_param_persistence | 600 | 576 | 260 | NVM 调度及其子模块，原子保存保护必须保留 |

建议按以下顺序逐项测量，成功一项再叠加下一项：

1. **媒体像素计数反馈**：本轮实验已撤销；下轮必须结合整体布局密度重新设计，不能只重试已失败的局部替换。
2. **INDEX 选择和校验**：检查选条目多路器与范围比较之间是否可借用既有 P_FLUSH/P_CHK 空间分级。保留 32 位 FAT 簇地址、CRC、4 首和坏索引回退能力；不盲目缩位或同时加四套宽比较器。
3. **SDRAM 写路径**：frame_fifo_write 仍有 `burst_cnt + write_cnt + App_wr_en < write_len_latch` 及 FIFO credit 宽加法/比较。评估剩余长度或预先算定 burst credit，但必须覆盖非整 burst、上层 padding、取消、hold、刷新、读写仲裁和翻转地址，不能只测 128 字单 burst。
4. **歌词和播放页**：评估重复选择、无效位裁剪、glyph 缓存搬移；环形行索引属于多模块结构改动，须先测等价和面积。保持六行、滚动、Seek、首尾边界与所有字形。优先换取可放置空间，再复核高速域布线。
5. **存储映射**：BRAM32K 尚有余量，可评估大 ROM/缓存迁移是否降低逻辑开销；同步读延迟、端口数、ROM 初始化和实际映射必须验证。BRAM9K 已满，不直接新增该类块。

不预先承诺节省多少 Slice。每个方向都须用最终 route 面积报告验证；必要时撤销导致打包或时序恶化的实验。

## 5. 约束与物理告警

r0 check_timing：no clock=0、clock definition=0、invalid constraint=0、combinational loops=0。PLL 检查目录中的 `(2)` 是两个 PLL 对象；详细项均为 0 个缺失约束、0 个频率不匹配，不是两个 PLL 错误。

仍需核对：

- **no input delay=37、no output delay=49**：机械按键、IR 和编码器是异步输入，应检查同步器；SD MISO、Flash、SDRAM、HDMI 等接口要根据外设时序、板上走线和采样关系建立模型。不能把所有端口统一填 0 ns 来消除报告。
- **dummy node 的三个 primitive 分类**：报告列出映射后 slice 的未用引脚以及常量/输出 PAD 等对象。逐项结合网表和 IP 文档分类，不凭目录计数判定功能错误，也不批量改 RTL 清零。
- **PHY-7002**：SDRAM 初始位置未被保留，工具在放置中移动；复核 ADC 和硬 IP 合法位置。
- **PHY-5079**：移位 SDRAM 时钟有局部线提示；依据硬 IP 的实际时钟/IO 路径检查。不能因为出现 clock 字样就强制全部走全局网。
- **异步时钟组和 `*/s1` 例外**：现有约束依赖 RTL 中同步器、Gray FIFO 或 bundled-data/toggle 握手。最终需逐类核对 CDC，尤其多位参数、media reset、flush 和软重启，不以跨域路径被例外切掉当作 CDC 通过。
- **同步器属性不一致**：`reset_sync.v`、`sync_2ff.v` 的 s1/s2 已标记 async_reg；`src/io/sync_bit.v` 的 meta/sync 虽有两级结构，却没有相同属性。后续应核对 TD 识别、级间物理距离和首级约束，再单独补齐属性并比较实现结果；不在本轮已冻结快照之后临时修改。

## 6. 功能边界和文档整理

- FAT32 扫描器明确只扫描根目录首簇。最终说明书应给出制卡/打包步骤和已支持的资源布局；暂不增加通用目录遍历功能。
- Flash 保存 VOL、BRI、CON、ROT、WSL。播放模式、曲目、位置和静音不在该版本保存范围；是否扩展另行讨论。
- 主板 LED 当前为 NVM 状态，与早期心跳/播放/TF 计划不同。以《阶段4_SPI_Flash参数持久化_交付与验收.md》的实际定义和用户验收为准。
- 发布说明只保留一张当前遥控映射表。历史计划和阶段报告保留当时基线、日期与未放行结论，避免把旧 WNS、旧 seed 或旧 bit 当作当前结果。
- 顶层部分注释仍称“重启确认”，而 a63d681 已改为红外直接软重启。属于注释一致性收尾，不应据此恢复旧确认状态机。
- 跟踪中的锁文件和 back_annotation 以及新仿真输出造成工作区噪声。本轮不把这些生成物或用户资料并入功能提交；后续单独评估仓库忽略规则，不清理现存 Runs。

## 7. 最终放行和人工验收

正式收尾应依次满足：当前输入哈希与快照一致；area_prior/seed/ADC/SDC 一致；综合、place、route 完成；setup 和 hold 的 WNS 非负、TNS=0、违例端点=0；资源可放置且最终无未处理路由冲突；BitGen 和参数导出完成；记录 bit 哈希；最后完成上板验收。正式发布脚本 `tools/release_verified_round.py` 继续保留时序检查。

构建工具还有一项版本兼容待处理：当前 `snapshot_audio_timing.py` 将快照工程路径写成 `src/...`，并把 VinylFPGA.al 一并纳入 inputs.sha256.json；旧 `release_verified_round.py` 的工作区集合比较和工程路径还假定旧格式。该脚本需补齐新旧快照格式校验及对应回归后，才能作为本轮快照的自动正式发布入口。不能通过删除输入清单里的工程项或取消哈希/时序检查规避问题。本轮测试候选的独立生成器逐项核对快照哈希、工作区源码/约束哈希和工程模板哈希，保留 candidate_only 标记。

本轮人工回归建议：

1. 冷启动和 SW2 跳过 Boot，四张封面预加载无错误；反复上一首/下一首和重新播放，检查最后一行像素、颜色、撕裂与卡死。
2. 连续播放，Seek 前进/后退，暂停/继续、三种自然 EOF 行为；MV、背景与歌词并行，无新断音、误告警或进度异常。
3. KEY4 静音期间转动播控编码器、调音量、Seek 和切歌；播放继续，恢复声音后参数保持。
4. 红外音量 +/−、E9 软重启、E6 保存、F2 默认值；包括息屏时和 Flash 忙时操作。软重启后重新加载，保存后复位恢复，默认值持久化，未改变原方向/确认按键。
5. J1/J2 亮度统一，暂停/唱针/DIP6 对灯带和电机符合既有行为。
6. 手动/自动保存、保存中调参、CRC/断电回退按既有 NVM 验收清单复核；确认没有把保存提示误当成事务完成。

上板通过用于确认产品行为；仍有负 setup 的实验 bit 只可记录为测试候选，不能标记时序闭合的最终稳定固件。
