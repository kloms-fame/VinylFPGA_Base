# 阶段三 A：播放背景基础与 KEY11 人工验收

日期：2026-10-13。正式方案见同目录《阶段三_播放背景正式开发报告_20261013.md》。本阶段在 main 开发，等待板级验收后提交。

## 1. 本阶段交付和预期

播放页默认中等灰柔和渐变；KEY11 改为切换背景，KEY7 继续停止并返回选歌。封面/MV 清晰窗口、布局、数字时长、歌词位置、进度条及波形沿用阶段一二。

| 从复位后播放开始 | 内部模式 | 3A 可见结果 |
|---|---:|---|
| 未按 KEY11 | 0 | 中等灰，媒体附近较亮、远处略暗 |
| 第一次按 KEY11 | 1 | 灰底；当前歌曲模糊图接口预留 |
| 第二次按 KEY11 | 2 | 灰底；通用蓝紫艺术图接口预留 |
| 第三次按 KEY11 | 3 | 近黑底，RGB 08080C |
| 第四次按 KEY11 | 0 | 回到中等灰 |

模式 1/2 的图片读取属于 3B，所以前三个模式暂时同为灰底，属于本阶段预期。无需修改现有 SD 卡内容，无需重新打包资源。灰底模式歌手/时间为 D0D4D8，非当前歌词为 B0B4BC；近黑沿用原配色。当前歌词金色、标题白色、已播放白色/未播放浅灰色进度保持。

## 3. 烧录准备和操作

1. 保留已验收的 SD 卡；关闭正在访问开发板的其他下载工具。
2. 开发板上电、插入原卡，连接现有下载线与 HDMI/音频设备。
3. 在 TD 下载界面按原有方法连接，确认目标为 EG4S20BG256，选择上述本轮 `.bit`。
4. 先用 JTAG/SRAM 下载进行验收，下载后复位启动。暂时不需要写入配置 Flash。
5. 初始应进入熟悉的选歌页；选一首已验收歌曲进入播放。

本次任务不自动下载或操控开发板。JTAG/SRAM 固件断电后不会保留；需要重载固件才能继续验收。

## 4. 必测项目

### A. 默认背景与显示完整性

- [ ] 播放页有效区域为灰底，渐变轻微、没有明显突变条带；清晰封面/MV 四周边界正确。
- [ ] 歌曲标题、歌手、左右时长可读，数字没有乱码，右边显示剩余时长。
- [ ] 标题/歌手尾部不出现重复字或残留；歌词现有五行正常，当前行保持金色。
- [ ] 已播放白色、未播放浅灰色进度条连续正常；波形可见，位置保持。
- [ ] 清晰封面和 MV 颜色、细节没有被背景灰化。

### B. KEY11 四模式循环

- [ ] 按上表连续操作四次 KEY11；第三次近黑、第四次灰色。
- [ ] 每次按下只推进一次，释放不再推进。建议先以每次间隔 0.5～1 秒操作，便于计数。
- [ ] 再连续按几轮，确认始终每四次回到起点。
- [ ] 切换整帧完成，没有持续闪烁、上半屏/下半屏背景不同或撕裂。
- [ ] 音频不停止、不跳曲，播放进度连续；模式 1/2 不发起新 SD 背景读取。

### C. 模式记忆与按键兼容

- [ ] 设置近黑后用原切歌方式切换歌曲，背景仍近黑；歌曲内容正常更新。
- [ ] 近黑时按 KEY7，返回选歌且音频停止；再确认播放，仍近黑。
- [ ] 停在选歌页按 KEY11 两次，再进入播放，仍保持先前模式；浏览页 KEY11 不改变背景请求。
- [ ] 暂停/继续、音量调节、Seek、重播、KEY8 现有可视化切换均正常；背景模式不被媒体重启清零。
- [ ] 视频复位或重新上电并重载本轮固件后，首次播放恢复默认灰底。

### D. 边界和持续播放

- [ ] 至少两首不同长度的歌分别检查标题末尾、左右时长、封面边缘、歌词区域。
- [ ] 播放至少 3 分钟，期间切换背景、暂停/继续、切歌、返回再播放，无音频杂音、卡住或 HDMI 失步。
- [ ] 临近曲尾检查剩余时间、进度以及原曲尾策略，行为与阶段一二相同。
