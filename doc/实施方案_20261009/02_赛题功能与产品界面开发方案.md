# VinylFPGA 赛题功能与产品界面开发 Implementation Plan

> **For agentic workers:** REQUIRED: Use `superpowers:executing-plans`，按[总览门禁](00_执行总览与阶段门禁.md)逐项执行。本方案只在O6优化版人工验收通过后启动；每项需要独立候选与人工验收，不得整体恢复历史UI分支。

**Goal:** 完成赛题一基础与全部五项扩展，形成具有EC2浮窗、统一播放页、五行歌词和正常滚动效果的稳定播放器。

**Architecture:** 保持现有媒体链，新增唯一参数CSR和可靠跨域快照；画质采用少量移位加法档位，文字首版编译时生成，多行显示共享字库，缩放优先装载期规范化。界面使用常量深色底和现有媒体窗口，不增加整页图像加载器。

**Tech Stack:** Verilog-2005、Python参考模型与资源生成器、Icarus、TD/SynthPilot、640×480视频、真实消费PCM时基。

## Chunk 1: 设计合同与基础缺口

### 1. 最终功能边界

终态必须具有：手动/自动切图、48kHz音频演示、Flash自启稳定运行、实时BRI/CON、歌词、转场、FPGA真实缩放、PCM可视化。产品增强包含五参数EC2面板、可读播放页和五行滚动。

首版不包含通用WAV/MP4解码、FFT、倍速、动态多背景、通用UIRES、Flash参数记忆、无限曲库。现有PCM是48kHz/16bit/单声道/小端连续裸数据；MV是320×240/RGB565/10fps连续帧，不改变合同。

五参数终态：`VOL / BRI / CON / ROT / WSL`。其中ROT控制图片轮播周期，WSL仅控制保留的VU亮度，不恢复WS进度模式。

**时序合同：**

| 数据 | 源 / 消费域 | 提交规则 |
|---|---|---|
| 净化按键/IR/EC2 | 50MHz控制域 | 用现有路由输出，唤醒首键按原规则吞掉 |
| 音量 | CSR50MHz → 音频gain消费域 | req/ack可靠传输，合法样本边界采用，沿用PCM淡入/淡出 |
| BRI/CON、面板状态 | CSR50MHz → video25MHz | payload稳定直到ack，帧起点原子采用 |
| ROT/轮播使能 | 50MHz → SD100MHz | 可靠快照，空闲调度；手动操作优先 |
| WSL | 50MHz → WS50MHz | 不跨域，WS发送帧起点锁存 |
| song/time/total/generation | 现有播放域 → video25MHz | 同一代次的完整快照；不能只各bit同步后拼接 |
| 歌词行/动画 | video25MHz | 消隐准备，下一帧生效；暂停/跳转明确处理 |

CSR快照忙时保存“最新待发送值”，收到ack后再发；允许中间数值合并，但**最后一个值和activity不得丢失**。目标复位后恢复传输；ack表示目标已采纳，不以源端发送成功充当画面生效。

## Chunk 2: EC2、画质与浮窗

### 3. EC2操作与参数合同

| 操作 / 参数 | 冻结行为 |
|---|---|
| 隐藏时转EC2 | 首次事件打开面板并快速调VOL一格；未实现面板的D3可先通过听感/状态测试观察 |
| 隐藏时按EC2 | 打开SELECT，默认选VOL |
| SELECT旋转 | 在已开放参数中循环选择，不改变数值 |
| SELECT按压 | 进入ADJUST |
| ADJUST旋转 | 增/减当前值，达到边界不回绕，仍计activity |
| ADJUST按压 | 返回SELECT |
| 无活动1800ms | 隐藏；activity与timeout同拍，activity优先 |
| KEY/IR改音量 | 写同一VOL，显示VOL短浮窗；无双份寄存器 |
| 播放Seek | 仍由EC1执行；EC2永不产生Seek |
| VOL | u8，默认200，步进16、饱和0～255；0静音。保留默认200，因此不宣称它是从0起均匀17档 |
| BRI | 五档1/4、1/2、3/4、1、5/4，默认1；超过255饱和，可真正提高亮度 |
| CON | 五档1/2、3/4、1、5/4、3/2，默认1；相对128中心，有符号算术与饱和 |
| ROT | OFF/2/5/10/20秒，默认5秒；DIP2仍是总使能，OFF优先关闭 |
| WSL | 0/25/50/75/100%，默认100%；100%对应现有安全颜色上限，DIP6总禁用优先 |

资料中“17档”与旧默认200/最小32并不一致，首版采用上表明确合同；如需严格17档，应在D0另冻包含默认值的查表，而不是在实现中临时混用。

所有事件先经过消抖/IR使能/唤醒过滤。方向编码沿当前 `ev_aux[0]`：0递增、1递减；`ev_aux[1]`区分EC1/EC2。EC2同样使用累计count差重放或等价可靠消费，不能只用最新方向把合并的多步当一步。

以下数值是“超出便需复查”的阶段预警预算，不是综合预测或独立模块最终面积。相对**直接父accepted的final**测量；不同模块共享/裁剪/布局相互作用导致不能机械相加。

| 阶段 | 新增LUT预警 | 新增Slice预警 | 新增BRAM9K预警 | 重点 |

### 7. 人工停点和故障处理

每项发给用户的验收包至少含：具体bit/卡hash、5～10步操作、期望画面/声音、上一accepted回退入口。D10a等算法项也必须有可见观察途径，不能只发内部波形让用户批准。

失败只修本项：EC2误Seek检查路由；画质花屏检查signed/延迟；歌词旧新混合检查generation/快照；滚动跳回检查单次触发；缩放断音检查512B在途与FIFO余量。保持上一accepted可运行，不跨到下一功能“顺便修”。

计划执行时按适用技能路由：需求/时序合同→必要Python参考→安路代码设计→testbench/仿真→项目/综合→布局布线→bitstream。SynthPilot配合同配置报告与关键路径分析，不能把gate面积或未完成place当最终验收。
