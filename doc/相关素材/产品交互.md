# VinylFPGA 全系统交互控件与引脚/红外映射手册

### 一、 FPGA 开发板主板交互控件

| **丝印**    | **控件名称**        | **硬件标识 / 端口**    | **FPGA 引脚** | **功能说明**                                                 |
| ----------- | ------------------- | ---------------------- | ------------- | ------------------------------------------------------------ |
| **KEY1**    | **系统复位键**      | `RESET` / `rst_n`      | **`A2`**      | 全局硬件复位（低电平复位，重置 PLL、SDRAM、音视频引擎及 UI 状态） |
| **KEY2**    | **参数复位**        | `key2`                 | **`B2`**      | 系统参数恢复默认配置，清除存储的配置数据                     |
| **KEY3**    | **OSD参数保存**     | `key3`                 | **`B1`**      | **OSD 参数手动保存**（触发快照保存当前用户配置到非易失存储） |
| **KEY4**    | **一键静音**        | `key4`                 | **`C1`**      | 全局音频快速静音，再次按下恢复原音量                         |
| **BUZ_SW**  | **蜂鸣器开关**      | *(物理刀闸开关)*       | —             | **板载物理硬开关**：通断蜂鸣器供电回路（不占 FPGA 引脚）     |
| **SW1**     | **数码管总控**      | `sw1`                  | **`C8`**      | 8 位数码管显示总使能（拨上=1 点亮扫描，拨下=0 熄灭关闭）     |
| ****k*SW2** | **开机动画**        | `sw2`                  | **`C7`**      | 跳过开机动画效果                                             |
| **SW3**     | **自动保存OSD参数** | `sw3`                  | **`C6`**      | 用户配置自动保存总开关（超时自动写 Flash）                   |
| **SW4**     | **系统告警总开关**  | `sw4`                  | **`C5`**      | 故障告警总控（无 SD 卡或系统故障时发出琵琶音警告）           |
| **LED1**    | **配置加载指示**    | `led[0]`               | **`A4`**      | 阶段4：本次启动成功恢复有效 Flash 配置后保持点亮，高有效     |
| **LED2**    | **参数已保存指示**  | `led[1]`               | **`A3`**      | 阶段4：当前五项参数已持久化；改参后熄灭，保存完成后点亮      |
| **LED3**    | **Flash 忙指示**    | `led[2]`               | **`C10`**     | 阶段4：初始化或擦写事务进行中点亮，高有效                    |
| **LED4**    | **Flash 故障指示**  | `led[3]`               | **`B12`**     | 阶段4：ID、写使能/保护、超时或回读校验失败，保持到复位       |
| **BUZZER**  | **反馈音效驱动**    | `board_buzzer_n`       | **`H11`**     | 操作反馈音效驱动端口（按键反馈短音、琵琶音报警）             |
| **数码管**  | **反馈显示**        | `seg_sel` / `seg_data` | *(专用总线)*  | 8 位动态扫描数码管，展示当前曲号、播放时间（分-秒）及状态码  |

阶段4从 `093efe7` 的主板 LED 固定熄灭状态接入以上持久化提示，复用已有灯而不增加显示或蜂鸣模块。KEY3 保存 VOL/BRI/CON/ROT/WSL；SW3 上拨后参数停变 5 秒自动保存；KEY2 在运行默认值生效后提交默认记录并清理旧槽。持久化成功以忙灯熄灭且 LED2 点亮为准。详细断电行为、候选固件与验收步骤见《阶段4_SPI_Flash参数持久化_交付与验收.md》。

OSD 调参中的 **WSL** 统一控制 J1/D14 唱片灯带和 J2/J11 VU 灯带：0/1/2/3/4 分别为各自原调色板的 0/25/50/75/100%。0 档只关灯，不关闭电机；DIP6 仍为两路总使能，KEY10 仍只切换 J2 灯效。KEY3 或 SW3 保存的 WSL 在重启后同时作用于两路，KEY2 将其恢复到 4 档。

播放页进度条下方、左右时间之间显示当前播完策略图标：暂停双竖线=播完暂停，带数字 1 的循环箭头=单曲循环，普通循环箭头=列表循环。KEY12 或红外对应播放模式键切换后，图标在帧边界更新；手动暂停不改变策略图标，复位默认列表循环。图标仅在播放页显示，不改变原有按键、红外或播完动作。

### 三、 NEC 红外遥控按键与编码映射表

> **解码协议说明**：
>
> 遥控器采用标准 NEC 协议，格式为 `[31:24] Addr` + `[23:16] ~Addr` + `[15:8] Cmd` + `[7:0] ~Cmd`。   
>
> 本遥控器的命令区恒为 `Cmd = 0xFF, ~Cmd = 0x00`，**判键需以高 8 位地址字节（`Addr`）为准**。   

| **遥控器功能**         | **32 位完整码 (HEX)** | **地址码 (Addr)** | **反码 (~Addr)** | **状态 / 联动系统说明**                                      |
| ---------------------- | --------------------- | ----------------- | ---------------- | ------------------------------------------------------------ |
| **上一首**             | `BA45FF00`            | `8'hBA`           | `8'h45`          | 触发上一曲切歌（同 KEY4 向上）                               |
| **重播**               | `B946FF00`            | `8'hB9`           | `8'h46`          | 播放进度清零并重新开始播放（Replay）                         |
| **下一首**             | `B847FF00`            | `8'hB8`           | `8'h47`          | 触发下一曲切歌（同 KEY5 向下）                               |
| **进度－**             | `BF40FF00`            | `8'hBF`           | `8'h40`          | 播放进度快退 5 秒（长按 REPEAT 连续快退）                    |
| **进度＋**             | `BB44FF00`            | `8'hBB`           | `8'h44`          | 播放进度快进 5 秒（长按 REPEAT 连续快进）                    |
| **暂停 / 播放**        | `BC43FF00`            | `8'hBC`           | `8'h43`          | 翻转播放与暂停状态（同 KEY2 确定键）                         |
| **音量－**             | `EA15FF00`            | `8'hEA`           | `8'h15`          | 系统主音量减小（步进调节，联动 OSD 浮窗）                    |
| **音量＋**             | `F807FF00`            | `8'hF8`           | `8'h07`          | 系统主音量增大（步进调节，联动 OSD 浮窗）                    |
| **息屏**               | `F609FF00`            | `8'hF6`           | `8'h09`          | 切换 HDMI 纯黑消隐模式（待机黑屏，保持音频）                 |
| **重启**               | `E916FF00`            | `8'hE9`           | `8'h16`          | 触发系统软复位与重新加载流程                                 |
| **静音**               | `F30CFF00`            | `8'hF3`           | `8'h0C`          | 全局音频快速静音 / 恢复（同主板 KEY4）                       |
| **上 (方向)**          | `E718FF00`            | `8'hE7`           | `8'h18`          | 菜单向上移动 / 选歌向前滚动                                  |
| **主界面**             | `A15EFF00`            | `8'hA1`           | `8'h5E`          | 退出播放态，返回选歌浏览界面（同 KEY7）                      |
| **左 (方向)**          | `F708FF00`            | `8'hF7`           | `8'h08`          | 选歌向左切换 / 播放快退 2 秒（同 KEY1）                      |
| **确定**               | `E31CFF00`            | `8'hE3`           | `8'h1C`          | 选歌确认播放 / 播放暂停切换（同 KEY2）                       |
| **右 (方向)**          | `A55AFF00`            | `A5`              | `8'h5A`          | 选歌向右切换 / 播放快进 2 秒（同 KEY3）                      |
| **转场特效**           | `BD42FF00`            | `8'hBD`           | `8'h42`          | 切换封面切换动效（同 KEY9）                                  |
| **下 (方向)**          | `AD52FF00`            | `8'hAD`           | `8'h52`          | 菜单向下移动 / 选歌向后滚动                                  |
| **播放界面背景**       | `B54AFF00`            | `8'hB5`           | `8'h4A`          | 循环切换播放背景模式（同 KEY11）                             |
| **``**手动保存参数**** | `E619FF00`            | `8'hE6`           | `8'h19`          | **手动保存参数**：将当前五项参数保存到 Flash，供下次开机恢复 |
| **恢复默认并保存**     | `F20DFF00`            | `8'hF2`           | `8'h0D`          | **恢复默认并保存**：恢复五项默认参数，同时写入 Flash 默认记录、清理旧槽 |
