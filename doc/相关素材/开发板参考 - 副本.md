## 一、图片本身的分析

- **图片类型**：开发板正面布局线稿，不是原理图，也不是现场实拍。
- **可辨认区域**：上边缘有 HDMI、供电、USB-JTAG、USB-UART、VGA 等接口；左右两侧是扩展排针；中央是 FPGA 和 8 位数码管；底边是按键和拨码开关。
- **适合做什么**：在接口、按键、数码管、LED 上加编号和简短说明，用作说明书中的“主板功能索引”。
- **不适合直接当作依据的内容**：器件编号、细小丝印和部分接口名称。图中有重复或难辨的编号，个别标签也可能与实板不符。GPIO 排针更不能仅凭位置推断每个针脚的项目功能。

建议给标注加三类状态：

- **项目使用**：当前固件确实连接并使用。
- **板载接口**：开发板具备，但当前作品没有对应功能。
- **需实物核对**：图上的名称或方向无法由工程代码确认。

例如：本项目有一个 HDMI 音视频发送链路；代码没有第二路 HDMI 输出或 VGA 显示链路。USB-UART 对应的 `uart_tx` 在当前集成中固定为高电平，不能标成“串口调试输出”。USB-JTAG 可标作下载/调试接口，但它不是音乐播放的用户交互功能。上述判断可对照[顶层模块](D:/Data_Backup/VinylFPGA_Workspace_Base/VinylFPGA/src/top_tf_hdmi_audio.v)和[引脚约束](D:/Data_Backup/VinylFPGA_Workspace_Base/VinylFPGA/constraints/pin.adc)。

## 三、控制扩展板上的功能清单

你的产品除了图片中的开发板，还使用控制扩展板和唱片扩展电路。说明书应把它们另画一张图，不要把扩展板功能挤进这张主板线稿。

### 旋钮

- **左旋钮 EC1**：浏览时切换曲目；播放时快进或快退约 2 秒；按下可确认播放或暂停/恢复。
- **右旋钮 EC2**：按下打开/关闭参数浮窗并切换调节项目；旋转调整当前项目。

### 扩展板 KEY1–KEY12

| 按键        | 功能                                       |
| ----------- | ------------------------------------------ |
| KEY1        | 浏览时切换曲目；播放时快退                 |
| KEY2        | 确认播放；播放时暂停/恢复                  |
| KEY3        | 浏览时切换曲目；播放时快进                 |
| KEY4 / KEY5 | 上翻 / 下翻曲目列表；播放时滚动歌词        |
| KEY6        | 切换歌词动效：滚动或逐字高亮               |
| KEY7        | 退出播放，返回浏览选曲                     |
| KEY8        | 切换封面图与 MV 画面                       |
| KEY9        | 切换封面转场效果                           |
| KEY10       | 切换控制扩展板灯带效果：关闭或 VU 音量律动 |
| KEY11       | 切换播放页面背景                           |
| KEY12       | 切换曲目播放结束策略                       |

### 扩展板 DIP1–DIP6

| 拨码 | 功能                                        |
| ---- | ------------------------------------------- |
| DIP1 | 扩展板按键、旋钮等输入总门控                |
| DIP2 | 打开/关闭封面自动轮播                       |
| DIP3 | 扩展板状态 LED 总门控                       |
| DIP4 | 开启/关闭 60 秒无操作自动消隐；音频继续播放 |
| DIP5 | 红外遥控器接收总门控                        |
| DIP6 | 两路 WS2812 灯带的总门控                    |

### 扩展板 LED 和灯带

- **扩展板 LED1**：业务操作反馈脉冲。
- **扩展板 LED2**：MV 模式指示。
- **扩展板 LED3**：有效红外信号指示脉冲。
- **扩展板 LED4**：运行心跳；故障时也会点亮。
- **扩展板 LED 总门控**：受 DIP3 控制。
- **J2/J11 灯带**：8 颗 WS2812，可显示音频 VU 律动；KEY10 控制其效果。
- **唱片灯带**：独立 8 灯 WS2812 数据输出，与唱针、电机状态联动。
- **灯带亮度 WSL**：两路灯带共同使用 0%、25%、50%、75%、100% 五档；DIP6 可同时关闭两路。

扩展板 LED 的实际含义应以当前的[LED 驱动 RTL](D:/Data_Backup/VinylFPGA_Workspace_Base/VinylFPGA/src/io/led_business_driver.v)为准。

## 四、唱针、转盘和唱片扩展功能

- **唱针开关**：检测唱针位置。
- **电机控制**：由 FPGA 控制板上的电机驱动电路启停；作品交互文档描述为播放且未暂停、唱针处于播放位置时转动。
- **唱片灯带**：独立灯带输出；播放时显示跑马效果，并由 WSL 调节亮度。
- **唱针/电机/灯带与音频关系**：抬起唱针会影响实体转盘和灯带，不应在说明图中画成“静音键”。静音和唱针操作是两种不同交互。
- **扩展接口和供电**：唱片板原理图包含 GPIO、5V/3.3V/GND、电机 MOSFET 驱动、唱针输入和 WS2812 串灯。要做用户版图片，重点解释“输入/输出功能”，不需要把电阻、电容和每根走线都标出来。

## 五、显示交互的全部内容

项目显示由开机、选曲、播放和参数浮窗等界面组成。这里列的是当前工程结构和交互设计中的页面内容，方便你制作屏幕功能注释图。

### 1. 开机画面

- 上电后显示片内 Logo 启动画面。
- 支持在允许的启动时间窗口内跳过开机画面。
- 主板 SW2 在启动时选择是否跳过 Logo。

### 2. 浏览选曲画面

- 屏幕中央显示当前曲目的大幅封面。
- 方向按键或 EC1 切换选中曲目。
- 下方信息区域显示曲号、标题、歌手和时长。
- 可通过 DIP2 开启封面自动轮播，轮播周期由 ROT 参数调节。
- 选中曲目后按确认进入播放。

### 3. 播放画面

播放页是说明图中最值得拆分标注的区域：

- **左侧视窗**：静态封面或动态 MV。
- **曲目信息**：歌曲标题和歌手。
- **歌词区**：显示随播放位置更新的歌词；支持滚动和逐字高亮效果。
- **进度信息**：已播放时间、剩余时间和进度条。
- **波形区**：随 PCM 音频变化的音频波形显示。
- **背景**：可切换四种播放背景模式。
- **播放结束图标**：显示曲尾行为策略，区分播完暂停、单曲循环、列表循环。
- **亮度/对比度效果**：作用于最终合成画面。

### 4. 参数浮窗

EC2 可打开参数浮窗，查看并调整：

- **VOL**：音量。
- **BRI**：亮度。
- **CON**：对比度。
- **ROT**：自动轮播周期。
- **WSL**：两路灯带亮度。

浮窗还显示当前选择/调整状态及数值。文档记录的亮度、对比度、轮播周期和灯带亮度选项，可在[参数 OSD 模块](D:/Data_Backup/VinylFPGA_Workspace_Base/VinylFPGA/src/display/ec2_param_osd.v)中核对。

### 5. 消隐和静音状态

- **自动消隐**：DIP4 开启后，60 秒无操作自动黑屏，音频继续。
- **手动息屏**：红外遥控器可切换 HDMI 黑屏，音频继续。
- **首次操作唤醒**：消隐期间，普通操作首先唤醒画面。
- **静音**：音频静音但播放位置继续推进；它和息屏、暂停是三种不同状态。

### 6. 切歌和曲尾状态

- 选曲、切曲会播放当前选择的转场效果。
- KEY12 切换曲尾策略。
- 播完暂停、单曲循环、列表自动下一首是三种曲尾行为。
- 手动暂停和“播完暂停策略”不是同一状态；说明图应分别标注。

### 7. 当前内容范围提示

歌词、歌曲标题和字体目前来自随固件构建的内容，不能据此声称播放器能从 TF 卡读取任意歌曲歌词。对外说明更适合写“播放预置曲目并同步显示对应歌词”。

主板数码管同时提供简化状态反馈：显示播放时间和曲目编号；播放时使用当前播放位置，浏览时显示选中曲目的时长。

## 六、附上的 `产品交互.md` 与当前 RTL 有几处不一致

这些差异会直接影响你添加功能注释，建议先修正图注依据：

1. **主板 SW4**：交互文档写“系统告警总开关”，但当前 RTL 没有发现 SW4 控制故障告警的业务路径。它被消抖并纳入拨码变化反馈，建议暂标“当前项目未分配明确功能”，不要标成告警门控。
2. **扩展板 LED1–LED4**：文档里的“播放/暂停/MV/故障”描述与当前 LED 驱动不一致。RTL 映射是：LED1 操作反馈、LED2 MV、LED3 红外接收脉冲、LED4 心跳/故障。
3. **遥控器 100+ / 200+**：文档把部分按键列为预留，但当前事件路由代码已将地址 `E6`、`F2` 分别接到手动保存和恢复默认请求。应核对实体遥控器按键后更新图注。
4. **遥控器音量正负键**：文档按键表与 RTL 常量名称对调。由于后续事件还经过按键编号映射，最终应以封版设备上实际按下后的音量变化为准。
5. **部分 RTL 注释仍是历史描述**：例如母板 KEY3、板载 SW1 的旧注释与目前保存、数码管控制的接线不完全一致。制作图注时不要单独依据旧代码注释。

交互手册对照 RTL 时可从[按键路由模块](D:/Data_Backup/VinylFPGA_Workspace_Base/VinylFPGA/src/io/ui_command_router.v)、[扩展板输入与状态集成](D:/Data_Backup/VinylFPGA_Workspace_Base/VinylFPGA/src/io/expansion_integration.v)和[顶层连接](D:/Data_Backup/VinylFPGA_Workspace_Base/VinylFPGA/src/top_tf_hdmi_audio.v)继续核查。
