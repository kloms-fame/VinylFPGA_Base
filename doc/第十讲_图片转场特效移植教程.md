> 本讲最终位流：`prj/VinylFPGA_lecture10_transition_final.bit`

## 一、本讲目标

本讲对应完赛系列：

```text
第十讲：图片转场特效
```

在第九讲 OSD 工程基础上增加两类图片切换效果：

```text
KEY1 手动下一张：先淡出到全黑，切换图片，再从黑淡入新图
自动轮播：新图从左到右揭示
```

转场像素处理位于 `video_delay` 黑屏屏蔽之后、OSD 之前：

```text
video_delay
  -> display_valid 黑屏屏蔽
  -> video_transition_apply
  -> osd_overlay_24
  -> video_rgb_to_axis_640x480
  -> HDMI
```

OSD 仍然位于视频链路最上层，不参与淡入淡出。

本讲保留以下既有功能：

```text
KEY1 短按下一张
KEY2 短按自动轮播开关
KEY2 长按上一张
自动轮播
切图音效
HDMI 音频
FAT32 文件系统扫描
四 bank 帧缓存
第九讲状态 OSD
Flash 上电自启接口
```

## 二、移植原则

本讲没有重写现有 `sd_card_bmp` 四 bank 调度和媒体状态机，而是采用最小侵入
方式：

```text
KEY1 外部消抖
  -> video_fade_transition
  -> 淡出到全黑
  -> fade_next_event
  -> sd_card_bmp 执行原有下一张切换
  -> S_HOLD 等待图片编号变化
  -> 淡入新图
```

自动轮播仍由原 `sd_card_bmp` 发起。顶层检测 `state_code` 图片编号变化，
在下一个 `frame_start` 生成 `index_commit`，转场模块进入从左到右 Wipe。

现有 `KEY2` 短按、`KEY2` 长按、自动轮播计时和四 bank 加载仲裁没有改写。

## 三、新增文件

### 3.1 `src/display/video_fade_transition.v`

作用：跨时钟域转场控制器。

主要接口：

```verilog
module video_fade_transition #(
    parameter integer FADE_FRAMES = 0
) (
    input  wire       ctrl_clk,
    input  wire       ctrl_rst_n,
    input  wire       next_event_in,
    output wire       next_event_out,
    output wire       fade_busy,

    input  wire       pix_clk,
    input  wire       pix_rst_n,
    input  wire       player_active,
    input  wire       frame_start,
    input  wire       index_commit,
    input  wire [1:0] active_index,
    output wire [7:0] alpha_out,
    output wire       fade_active,
    output wire       wipe_active,
    output wire [4:0] ramp_out,
    output wire [1:0] transition_kind
);
```

状态机：

```text
S_IDLE  正常显示，alpha=255
S_OUT   淡出中，alpha 从 255 递减到 0
S_HOLD  全黑保持，等待图片编号提交
S_IN    淡入中或 Wipe 揭示中
```

手动切图：

```text
IDLE -> OUT -> HOLD -> IN -> IDLE
```

自动轮播：

```text
IDLE 收到 index_commit -> IN（Wipe 模式）-> IDLE
```

### 3.2 `src/display/video_transition_apply.v`

作用：像素域应用 alpha 淡入淡出和 Wipe 坐标选择。

核心代码：

```verilog
wire [15:0] red_mul   = {8'd0, rgb_in[23:16]} * alpha;
wire [15:0] green_mul = {8'd0, rgb_in[15:8]}  * alpha;
wire [15:0] blue_mul  = {8'd0, rgb_in[7:0]}   * alpha;

wire [23:0] faded_rgb = {
    red_mul[15:8],
    green_mul[15:8],
    blue_mul[15:8]
};

wire [10:0] wipe_boundary = wipe_ramp * WIPE_STEP;
wire        show_new      = (pixel_x < wipe_boundary);

assign rgb_out = wipe_active ?
                 (show_new ? rgb_in : 24'd0) :
                 faded_rgb;
```

这里必须先把 8 位颜色零扩展到 16 位再乘 `alpha`。普通 Verilog 中
`8位 * 8位` 的结果宽度只有 8 位，直接相乘会截断高位，导致 `alpha=255`
时画面仍然接近全黑。

### 3.3 `src/display/frame_blend.v`

这是完赛教程附带的通用双帧混合模块，本讲已加入工程源文件列表，但当前
单读端口 SDRAM 架构没有实例化它。

### 3.4 `sim/tb_video_fade_transition.v`

## 四、修改文件

### 4.1 `src/SD/sd_card_bmp.v`

新增：

```verilog
input  wire next_event,
output reg  switch_abort_toggle
```

原下一张条件扩展为：

```verilog
if ((key_next_press || next_event) &&
    scan_done_eff && (img_found_count > 3'd0))
    next_req_pending <= 1'b1;
```

顶层不直接把 KEY1 送入 `sd_card_bmp`，而是让转场控制器在淡出完成后通过
`next_event` 触发下一张。这样不会破坏原有加载仲裁、预加载和自动轮播。

手动切图加载失败且重试耗尽时，`switch_abort_toggle` 翻转。顶层同步后给
转场状态机一个释放脉冲，避免转场一直停在黑场。

### 4.2 `src/top_tf_hdmi_audio.v`

新增 KEY1 外部 20 ms 消抖：

```verilog
key_press_debounce #(
    .CLK_FREQ_HZ (100_000_000),
    .DEBOUNCE_MS (20)
) u_key_next_transition (
    .clk         (sd_card_clk),
    .rst         (~sdcard_rst_n),
    .button_in   (key1),
```

## 五、单读端口适配说明

完赛教程的 Wipe 理想效果是：

```text
边界左边：新图
边界右边：旧图
```

本工程当前 SDRAM 读端口一次只能读取一路视频。如果同一像素周期同时读取
旧图和新图，需要增加第二读端口、双 SDRAM 或大容量帧缓存，会触碰已验证的
高带宽存储链路。

因此本讲按教程的单读端口说明做最小适配：

```text
边界左边：新图
边界右边：黑场
```

随着 Wipe 边界从左向右移动，新图片逐步从左向右揭示。手动 KEY1 切换仍
严格使用教程的“淡出到全黑 -> 切换 -> 从黑淡入”效果。
