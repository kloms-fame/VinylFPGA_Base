# D1 三秒轮播与自动切图提示音实施计划

> **执行方式：** 在当前 main 工作区按顺序完成；保留所有既有用户修改。RTL 静态检查和 SynthPilot `opt_gate` 综合是本次工程验证；不生成 bit。

**目标：** 自动轮播周期调整为 3 秒；每次自动 bank 选择被确认后播放 4 kHz、12 ms 的一次短音；复用蜂鸣器既有计数器，自动音具有最高优先级。

**设计：** `cover_navigation` 标记自动事务来源并在 `select_req && select_ack` 时输出确认；100 MHz SD 域以 toggle 跨到 50 MHz；`buzzer_feedback` 用已有计数器播放新音调。完整设计见 `docs/superpowers/specs/2026-10-10-d1-three-second-auto-beep-design.md`。

## 步骤

1. **调整轮播周期**：把 `slideshow_controller` 默认周期和顶层配置改成 3000 ms，保留已有使能、手动抢占、pending、busy 与重计时规则。
2. **给自动导航事务加来源标记**：修改 `cover_navigation`，让人工操作清除待处理自动来源；只有自动事务选择得到 bank ack 才产生单拍确认事件。
3. **跨域并接入声音**：在顶层用 toggle + `sync_2ff` + 差分脉冲传递事件；扩展 `expansion_integration` 和 `buzzer_feedback`，使用既有音调/时长计数器播放 4 kHz、12 ms，设置最高事件优先级。
4. **更新 D1 记录**：修改轮播范围、人工验收单和构建指标记录，说明 3 秒周期、蜂鸣时序、冲突行为及 SynthPilot 构建边界。
5. **检查工程并评估**：检查 RTL 端口连接、计数值、`.al` 文件源引用和 Git diff；从当前主工程建立独立 SynthPilot 快照，运行至 `opt_gate`，记录面积与预布线时序相对 D1 基线的变化。不运行 bitgen。
6. **提交并交付人工验收**：使用简体中文提交说明；保留工作区原有无关修改；向用户给出详细板上验收步骤与当前综合报告限制。

## 验收重点

- 切图节拍为每 3 秒一次；自动关闭、单图、媒体未就绪、缩略图和播放模式门控维持既有行为。
- 每次自动选择 ack 严格产生一声；手动导航不产生自动音；自动音按确认规则抢占重叠声音。
- SynthPilot `opt_gate` 成功且无新增 black box；报告资源、时序和原有约束警告，不把预布线结果描述为布局布线签核。
- 人工验收单涵盖 100 次轮播、蜂鸣器听感/节拍、手动操作、忙时 pending、DIP2、播放/缩略图门控和拔插卡。
